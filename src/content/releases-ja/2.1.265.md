- Claude apps gateway 経由で Claude Desktop と Cowork が送るテレメトリに、ターミナルセッションと同様に `user.email` と `user.groups` を追加
- `--plugin-dir` にプラグインのフォルダを指すディレクトリを指定できる機能を追加。マニフェストを持つ各子フォルダが読み込まれ、実行中に追加・削除された子フォルダも反映される
- ディスクに保存されるツール結果に 1 GB の上限を追加。会話内のプレビューには、保存されたファイルが切り詰められた場合にその旨が表示される
- フォアグラウンドで起動したサブエージェントを再開すると、そのツールリストとシステムプロンプトのプレフィックスが変化し、そのエージェントのプロンプトキャッシュが再利用できなくなっていた問題を修正
- エージェントのチームメイトや再開されたサブエージェントが、後続のターンで SubagentStart フックのコンテキストと事前読み込みされたスキルをプロンプトのプレフィックスから外してしまい、プロンプトキャッシュが再利用できなくなっていた問題を修正
- ツール実行中に前のプロセスが終了した後の再開を修正。最後のプロンプトが書き換えられなくなり、中断されたツール呼び出しは中断済みとして保持される
- `/model opusplan[1m]` が「Model not found」で拒否されていた問題を修正
- 権限プロンプトやメッセージ内のシンタックスハイライトされたコードで、Ruby の `?`、Erlang の `$`、Perl の `$` シジルの直後の文字が省略されることがあった問題を修正
- スラッシュコマンドや @ファイルの候補リストが開閉するたびに、フルスクリーンのトランスクリプトが 1 行ずれていた問題を修正
- バックスラッシュを含むプラグインのパスが、macOS と Linux でのシンボリックリンク封じ込めチェックを回避できていた問題を修正
- 名前がドット 2 つで始まるプラグインディレクトリが、プラグインルートの外にあると誤って拒否されていた問題を修正
- トークンの更新中にセッションが閉じられた場合、VS Code と SDK のセッションが再ログインを要求することがあった問題を修正
- リモートコントロールのセッションが、返信の最後のメッセージより前にターン終了シグナルを送信しており、Claude アプリ上で最後の部分が届く前に返信が完了したように表示されることがあった問題を修正
- アイドルタイムアウト直前にメッセージが届いた場合、バックグラウンド(`--bg`)セッションがターンの途中で終了させられることがあった問題を修正
- Claude Code 自身の git status/diff のプローブが、作業ツリー内のネストしたリポジトリで設定された clean フィルタを実行してしまっていた問題を修正
- アドバイザーツールとその指示が、リクエストのモデルごとにリクエストのたびに再決定されていた問題を修正。現在は一度だけ決定され、変更があった場合は会話内で通知される
- artifact の公開が、コネクタが実際には公開していないツール名を受け入れてしまっていた問題を修正。宣言されたツールが 1 つも存在しない場合は公開を拒否し、一部のみ存在しない場合は警告するようになった
- 管理設定でスキルのみをプラグインに固定している場合に `/add-dir <subdirectory>` がサブディレクトリのエージェントの読み込みを拒否し、エージェントのみが固定されている場合はエージェントを約束してしまっていた問題を修正
- tmux 内でよく起こるように、2 番目のキーが 1 秒以上遅れて届くと 2 キーのキーボードショートカットが無言でキャンセルされていた問題を修正。現在は 3 秒待機し、タイムアウトした場合は通知を表示する
- フォークされたスキル(`context: fork`)が、そのキックオフプロンプトと(`--forward-subagent-text` 指定時は)テキストのターンを stream-json の進行イベントとしてストリーミングしていなかった問題を修正
- シンボリックリンクループなど OS がチェックできないプラグインのデフォルトのコンポーネントフォルダが、黙ってスキップされていた問題を修正。現在はエラーコードとともに `/plugin` に報告される
- Claude apps gateway の OTLP テレメトリリレーが、コレクターが不正または大きすぎるとして数件のペイロードを拒否した後、30 秒間すべての転送を一時停止していた問題を修正
- マーケットプレイスのプラグインのメタデータが `plugin.json` にのみ存在する場合に、`/plugin` の Discover/Browse と `claude plugin list --json --available` が説明や表示名を表示していなかった問題を修正
- 管理設定で設定された Claude apps gateway にサインインしたセッションで再実行すると、`/login` が「no gateway URL is configured」と表示していた問題を修正
- 設定ファイルへの書き込みができなかった場合に `/model` がモデルを「saved as your default」と主張していた問題を修正。現在は保存に失敗したことと理由を表示する
- リモートコントロールからの `/clear` が、完了前に SessionStart フックと開いているターミナルダイアログを待っていた問題を修正
- タブを切り替えるたびに `/config` ダイアログの高さが変わっていた問題を修正
- コンテナが再起動した後の workflow 実行の再開を修正。実行ジャーナルが見つからない場合の再開は、すべてのエージェントを再実行する代わりに明確なエラーで失敗するようになった
- `claude-api` スキルのエラーコードのリファレンスを修正: モデルへのアクセス失敗は 403 ではなく 404 を、利用できない beta ヘッダーは 400 を返す
- 非対話型セッション(stream-json 入力を伴う `-p`、Agent SDK、クラウドセッション)が、新しいユーザーメッセージのたびにシェルの作業ディレクトリをリセットしていた問題を修正。`cd` はターンをまたいで持続するようになった
- レガシーな HTTP+SSE トランスポートのみを話す `http` として設定された MCP サーバーが接続できなかった問題を修正。Claude Code は MCP の仕様通り SSE にフォールバックするようになった
- claude.ai では接続済みのコネクタが、クラウドセッションでは認証が必要と表示されることがあった問題を修正(サポートされていないリクエストに HTTP 401 で応答するサーバーが対象)
- コネクタの承認やサインインリンクの待機中、リモートセッションがサンドボックスコンテナを起動したままにしていた問題を修正
- 再開されたセッションが「background task didn't finish」の通知で、短いステータス行の代わりにモデル向けの長い復旧手順を表示していた問題を修正
- Windows: AppContainer や制限されたトークンのサンドボックス内で実行すると、Read、Write、Edit がすべてのファイルを拒否していた(「symlink resolution changed after permission was checked」)問題を修正
- 大規模リポジトリでの `--worktree` の起動を改善。新しい worktree が並列にチェックアウトされるようになった(git 2.32 以降)
- `/workflows` のエージェント詳細を改善。ツール呼び出しが実行中・失敗・完了としてマークされ、サブエージェントにタスクリストがある場合はそれが表示され、Enter で一覧のツール呼び出しを入力と結果とともに展開できる
- プロンプト入力中のスラッシュコマンドを改善。候補が単一の提案ではなくリストで表示されるようになり(Tab でフルスクリーン外に開く)、プラグインのスキルがベア名でも見つかるようになった
- サインインが必要なリモート MCP サーバーを改善。実際に認証するまで Claude Code が OAuth クライアントを登録しなくなった
- 多くのファイルを読み込む長いセッションの再開時間を改善
- サイズ上限を超えた画像がデコードできない場合のエラー表示を改善。上限を伝えるだけでなく、原因と対処法を示すようになった
- Artifact ツールが他者の書いた artifact を読む際の挙動を改善。要約はページを信頼できないコンテンツとして扱い、埋め込まれた指示をそのまま伝えるのではなくフラグを立てるようになった
- `.claude` フォルダの権限オプションの説明を、実際に許可される内容(セッション中にプロジェクトの `.claude` フォルダ、または `~/.claude` 内のファイルを編集できること)に更新
- 管理設定に `forceLoginGatewayUrl` があるマシンを、`forceLoginMethod: "gateway"` と同様に起動時から Claude apps gateway セッションにするよう変更。残っている claude.ai ログインや API キーは使用されない
- 画像処理をランタイム組み込みの画像サポートを使うように変更。CLI はネイティブの画像モジュールを一時ディレクトリに展開しなくなった
- プラグインの表示メタデータを、Installed タブと `claude plugin details` で `plugin.json` よりマーケットプレイスのエントリを優先するように変更。不足分は `plugin.json` で補う
- Claude apps gateway のセッションが、gateway のリレー経由ではなく、管理設定でコレクター名が指定されている場合は `OTEL_EXPORTER_OTLP_ENDPOINT` へ直接 OpenTelemetry をエクスポートするように変更。名前付きコレクターがないセッションは引き続きリレーを使用する
- [VSCode] 一定期間操作のないセッションを自動的にアーカイブする機能を追加(新しい「Archive inactive sessions」設定、デフォルト 14 日)
- [VSCode] 会話を 10 分以上開いたままにしていると、Reload Window や再起動の後にサイドバーのチャットが空になって戻ってきていた問題を修正
- [VSCode] 「Remote Control is active」メッセージのタイムラインのドットがテキストの下にずれていた問題を修正
