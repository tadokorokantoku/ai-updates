- 管理対象マシンで、複合シェルコマンドの入れ子部分に対する deny / ask ルールが、ユーザーがインストールした mod の承認より優先されない問題を修正
- 短いコードブロックに閉じられていない `<script>` タグが多数ある、または `${` 置換が深くネストしている場合にターミナルがフリーズする問題を修正
- IDE で @ メンションされた、変更された、または選択されたファイルがシンボリックリンク経由の場合に `Read` の deny ルールが適用されない問題を修正
- [VSCode] サインアウトが頻発する可能性があった 2.1.288 の `claude auth status` の変更を元に戻した
- プラグインのコードペインで、ハイライト表示を最終的な幅で一度だけレイアウトすることで、大きなファイルをより速く開けるように改善
- ローカルフォルダのマーケットプレイスからインストールしたプラグインについて、`plugin list`、`plugin eval`、`plugin update` が古いコピーを表示する問題と、シンボリックリンクの `--plugin-dir` のホットリロードを修正
- アップグレード後の最初のセッションでインストール済みの mod が読み込まれない問題を修正
- フルスクリーンで Background tasks ダイアログを開いている間、プロンプト上のプラグインの行が古い内容のまま表示される問題を修正
- リンクが localhost アドレス、パスに `@`、大文字のホスト、または `file:` パスを使っている場合にプラグインペインが何も描画しない問題を修正
- ユーザーがインストールしたプラグインが、組織管理の MCP サーバーのサインインツールの説明を書き換えられる問題を修正
- プラグインが端末の知らないボーダースタイルの Box を描画した際に、起動時にフリーズまたは強制終了する問題を修正
- プラグインの画面上のハンドラーが非同期に例外を投げた際に、supervised / background セッションが終了する問題を修正
- 高さのないプラグインリージョンが拡大し続けた際に、インターフェースエラーでセッションが終了する問題を修正
- サンドボックスが自動許可する場合に、展開される値を持つ環境変数プレフィックス（例: `TZ="$HOME" rm -rf build`）の後ろのコマンドを Bash の deny / ask ルールが見逃す問題を修正
- サンドボックスの自動許可下で、単純な変数代入がコマンドの前にあると Bash の deny / ask ルールがスキップされる問題を修正
- フォルダにマーケットプレイスのマニフェストもある場合に `claude plugin validate` がプラグインをスキップする問題を修正
- teammate 向けの `agent.spawn`、プラグインフックイベント全体で共通の agent id、`$.agent.list()` での idle / waiting 状態を追加
- mod の `ui.render` フックが書き込んだ値により行の描画時に例外が発生すると「unrecoverable interface error」でセッションが終了する問題を修正。エンジンが代わりに自前の行を描画するようになった
- タブ、不正なエスケープ、C1 制御文字を含むテキスト、またはタブと CRLF 改行を含む短いテキストが下の行に重ねて描画される問題を修正
- mod のペインやバンド内の右寄せコンテンツが閉じるマークや `[-]` の下に描画される問題を修正。これらは端末の端から 1 列内側に保たれるようになった
- 描画に失敗した mod の `Client` が、その周囲の mod の描画すべてを巻き込む問題を修正。単独で失敗し、`ui.fault` を発行するようになった
- `claude plugin validate` が Anthropic マーケットプレイス自身のプラグインを失敗扱いにする問題と、`--json` で正常な `plugin.json` を列挙する問題を修正
- 描画に失敗した mod のバンドが、下のカードを一時的にどかせる問題を修正
- メッセージを伴わない失敗をしたプラグインコンポーネントが、理由として `Error` または何も表示しない問題を修正
- mod の作者に表示される、バンドまたはペインの描画失敗時の行を改善: mod 名を示し、何も描画されなかったことを伝える
- 公開されたアーティファクトページが、閉じられていない `<script>` タグの多い短いコードブロックで閲覧者のブラウザタブをフリーズまたはクラッシュさせる問題を修正
- 一度ターミナルが描画中に例外を投げると、mod の Client リージョンがセッション中ずっと失敗状態のままになる問題を修正
