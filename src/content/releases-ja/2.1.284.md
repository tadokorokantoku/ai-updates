- Claude Sonnet 5.5（`claude-sonnet-5-5`）を追加。Anthropic API のデフォルト Sonnet モデルになった — 1M コンテキスト、$2/$10 per Mtok、キャッシュ読み取りは $0.20/Mtok
- auto mode で作業ディレクトリ外の読み取り前に表示されるプロンプトに「Yes, but ask again next time」の選択肢を追加。その 1 回の読み取りだけを許可し、以降の読み取りでは引き続き確認できる
- Claude apps gateway が本バージョン以降で動作している場合、`/usage` とステータスラインの gateway 利用上限にドル金額を表示（例: "$271.40 / $500.00 spent this month"）。ステータスラインの `rate_limits.spend_limit` にも `used_usd`、`limit_usd`、`period` を追加
- `effortSlider:decreaseEffort`、`increaseEffort`、`toggleUltracode` のキーバインドアクションを追加。`/effort` スライダーの矢印キーと Tab キーを `keybindings.json` で再割り当て可能に
- claude.ai サブスクライバー向けに `/rate-limit-options` を `/help` とコマンドメニューに追加。利用上限の通知で案内されるコマンドを見つけられるように
- 対話ターミナルで `/mcp reconnect all` を追加。接続に失敗した、または認証が必要な MCP サーバーをすべて一度に再試行できる
- 管理ポリシーの `availableModels` が空の場合、または `model` も `enforceAvailableModels` も設定せずに Claude Code の起動モデルが除外されている場合に、Claude apps gateway が起動時に警告を出すように
- Claude apps gateway の `telemetry.forward_to` 送信先に `auth: { google: {} }` を追加。gateway の Google Cloud 認証情報を使って Google Cloud の OTLP エンドポイントへ直接テレメトリをエクスポート可能に
- クライアントシークレットの代わりに証明書認証情報を発行する ID プロバイダ向けに、Claude apps gateway と ID プロバイダ間の証明書クライアント認証（`private_key_jwt`）を追加
- 破損したレスポンスストリームにより "JSON Parse error" や "undefined is not an object" といった生のエラーが表示されたり、回答に "undefined" の文字が書き込まれたりする問題を修正。再試行または中断されたレスポンスとして報告される
- thinking ブロックの直後に過負荷またはサーバーエラーが届くと、再試行されずエラーでターンが終了していた問題を修正
- compact 後も "Prompt is too long" エラーが残る問題を修正: compact 後のリクエストがまだ長すぎる場合、直近の会話の保持量を減らしてもう一度 compact する
- セッションのモデルが利用不可でフォールバックモデルも残っていない場合に、モデル利用不可の通知と Learn more リンクではなく、素の "is currently unavailable" メッセージ（クラウドセッションでは "Something went wrong"）が表示される問題を修正
- ユーザーメッセージに不正な `source` を持つ画像が含まれると Agent SDK セッションがクラッシュする問題、および不正なドキュメントブロックの後に以降のすべてのターンが失敗する問題を修正。不正な画像は説明のノートに置き換えられる
- 再開したセッションで、MCP サーバーがまだ接続中の間に MCP ツール呼び出しが "No such tool available" で失敗する問題を修正。呼び出しはサーバーを最大 10 秒待つようになった
- プラン使用状況エンドポイントがレート制限またはログインを拒否した後に繰り返し呼び出される問題を修正。`/usage`、`/extra-usage`、IDE の使用状況ビューは再問い合わせせずにバックオフする
- マネージド設定が MCP サーバーをプラグインのみに制限している場合でも `claude mcp add` が成功と報告していた問題を修正。ロードされないサーバーを保存する代わりに、拒否して対処方法を表示する
- `/plugin` の設定画面を修正: boolean オプションは自由入力ではなく true/false の選択になり、数値オプションは不正な入力を拒否し、←/→ はタブ切り替えではなくオプション欄の変更になる
- `ANTHROPIC_FOUNDRY_RESOURCE` が検証なしで Foundry エンドポイントのホストに埋め込まれていた問題を修正。単純なリソース名でない値は拒否される
- Claude apps gateway 経由の Claude Desktop に 1M コンテキストの選択肢が表示されない問題を修正: gateway が 1M 対応の各モデルを Desktop 向けに自動でマークする
- シェルモードで ↓ を押すと非表示のバックグラウンドタスクピルが選択され、Backspace と Ctrl+U でプロンプトを編集できなくなる問題を修正
- 多数のプラグインを有効にした Windows で Bash ツールが失敗する問題を修正: 存在しないプラグインの `bin/` ディレクトリは PATH に追加されず、継承されたエントリも重複追加されない
- 古い git（2.39 未満）で `sparsePaths` プラグインマーケットプレイスが空でクローンされ、動作中のローカルコピーを置き換えてしまい、更新のたびに "marketplace.json file is no longer present" で失敗する問題を修正
- トランスクリプトモードで `[` を押して会話をスクロールバックに書き出すと、フルスクリーン描画がセッションより上のターミナル出力を消去する問題を修正（macOS と Linux）
- 上にスクロールしている間に返信のストリーミングが完了すると、フルスクリーンのスクロール位置が前のメッセージや最下部に飛ぶ問題を修正
- `/config` や `/plugin` などのダイアログのタブバーが、狭いターミナルでタイトルやタブラベルを単語の途中で折り返す問題を修正。収まらないタブはまとめて次の行に移動する
- `/model` ピッカーで最後のモデルまでスクロールした後、リストの下に "+1 model" と表示される問題を修正。カウントは表示行より下にあるモデルのみを対象にする
- `/keybindings` が、何もしないフッターアクションの Backspace と Delete のバインドを生成される `keybindings.json` に書き込む問題を修正
- 再割り当てしたエージェントパネルの閉じるキー（`footer:close`）が、表示中のエージェントの行でそのキー自体ではなく "x" を入力してしまう問題を修正
- vim モードの `.` が、非常に速く入力されたテキスト（ssh や tmux 経由など）や bracketed paste なしで貼り付けたテキストを繰り返さない問題、および何も入力せずに変更を繰り返した後（`cw` のあと Esc など）にプロンプトが INSERT モードのままになる問題を修正
- vim モードで、最終行での `dd` やプロンプト末尾での `yy` の後にカーソルが画像プレースホルダーの開き括弧に残り、`r` や `x` で画像が壊れたり削除されたりする問題を修正
- ターミナルがフォーカスを取り戻した瞬間に押されたキーが、短い安全用の遅延が再開する前に Remote Control 有効化プロンプトに応答してしまう問題を修正
- ホームディレクトリで Claude Code を起動した場合に、レンダラーの切り替えやアップデート後にワークスペース信頼ダイアログが 2 回表示される問題を修正
- プロジェクト外から `.claude/rules` にシンボリックリンクされたルールが、外部インポートの承認プロンプトを表示せずにスキップされる問題を修正。プロジェクト外からシンボリックリンクされた `.claude` ディレクトリも同じ承認を求めるようになった
- マネージドの `allowManagedPermissionRulesOnly` 下で、マーケットプレイス、claude.ai、npm のプラグインが `allowed-tools` 経由で自身のツールを事前承認できてしまう問題を修正。事前承認が維持されるのは、Anthropic 公式ソースまたはマネージド設定が保証するソースのプラグインのみ
- 依存関係のバージョン範囲を満たせない場合に、最初の `claude plugin install` が失敗してもプラグインが有効化・記録されたままになる問題を修正
- フックが stdout にも書き込んだ場合に失敗したフックの stderr がデバッグログから欠落する問題、および出力のない失敗したフックが何もログされない問題を修正。失敗したフックはステータスコードもログされるようになった
- Elicitation および ElicitationResult フックが返す `{"decision":"block"}` が無視される問題を修正。終了コード 2 と同様に MCP の elicitation を拒否する
- `SendMessage` ツールなしで起動されたセッション（Claude Desktop など）が、それでも他のセッションへのメッセージ送信に使うよう指示される問題を修正
- Remote Control 経由で Claude アプリから送られた写真が、キューに入ったメッセージがターミナルのプロンプトに引き戻されて編集される際に失われる問題、およびキャプションのない写真でカーソルが 1 文字移動する問題を修正
- 自動的な利用上限待機中にメッセージを入力すると、そのターンが再び上限に達した際に待機が "Continue automatically at usage limit" 設定の制御から外れる問題を修正
- 最上位の Max プランのユーザーに利用上限の警告が `/upgrade` を勧める問題を修正。`/usage-credits` が利用可能な場合、警告と `/upgrade` 自体がそちらを案内する
