- `managedMcpServers` 管理設定を追加: 組織が全ユーザーに HTTP/SSE の MCP サーバーを提供できるようになった(エントリの形式は `.mcp.json` と同じ)。実行コマンドを指定するエントリはスキップされる
- 無人のヘッドレスホスト向けに `--permission-prompts none` を追加: プロンプトが発生するはずの操作はすべて自動的に拒否される一方、有効な権限モード(auto モードを含む)が判断を続ける
- `glab mr create/merge/close/reopen/note/update` を認識するようになり、GitLab のマージリクエストが折りたたまれたツールサマリーに `MR !N` として表示され、フッターの MR バッジも更新されるようになった
- `claude plugin validate` に機械可読な検証レポート用の `--json` を追加
- 同時実行中の複数セッションが互いの `~/.claude.json` の変更を黙って上書きしてしまう問題を修正。多数のセッションを同時に実行してもワークスペースの信頼状態がリセットされず、MCP やプロジェクトの状態が失われなくなった
- thinking が一度拒否された会話が、以降のすべてのターンで拒否され続けていた問題を修正
- Bash の `Read()` 拒否ルールが、オプション値として渡されたファイル(`--ignore-revs-file=.env`、`-f.env`、`@file`)、`git diff`/`git grep` のファイルオペランド、`cd DIR && cat FILE` のような複合コマンドをカバーしていなかった問題を修正。拒否対象ファイルを含むディレクトリに対する `grep -r`/`cp -r` は確認を求めるようになった
- テレメトリを無効にしたセッションで OAuth トークンが更新された際に、プロンプトキャッシュが無効化されていた問題を修正
- 数百件のツール呼び出しを含む長いターンの後、フルスクリーンモードで会話が空白表示になっていた問題を修正
- コマンドやスキルの frontmatter で `model:` が指定されているものの auto モードがサポートしていないモデルだった場合に、そのモデルでターンが実行されてしまっていた問題を修正。現在はセッションのモデルが維持される
- Claude Code が認識しないモデルバージョンの Vertex 形式モデル ID(`@YYYYMMDD` サフィックス)に対して `CLAUDE_CODE_MAX_CONTEXT_TOKENS` が無視されていた問題を修正
- 実行中のシェルコマンドのライブ出力プレビューで、前の行が折り返された際に最新行が隠れてしまっていた問題を修正
- claude.ai ユーザーに対して起動のたびに実行されていたバックグラウンドの GitHub 接続チェックを修正。結果が起動間で記憶されるようになった
- 保存されたセッションにペイロードのない添付ファイルエントリが含まれる場合に `--resume` が失敗し(`--continue` では空の会話が開かれ)ていた問題を修正
- インタラクティブセッションでカスタムコマンドとスキルの frontmatter `model:` が無視されていた問題を修正
- 古いバージョンから継続した会話で Artifact の公開が「unexpected parameter `note`」エラーで一度失敗していた問題を修正
- MDM または管理設定ファイルで設定されたポリシーヘルパーがすでに実行されていた場合に、管理対象の `forceRemoteSettingsRefresh` が起動時に無視されていた問題を修正
- `git rev-parse` が「not a git repository」以外のメッセージで失敗するマシンで、worktree isolation が hook で作成された worktree を拒否していた問題を修正
- クラウドセッションからの OpenTelemetry のメトリクスとイベントに `user.email`、`organization.id`、`user.account_uuid` 属性が欠落していた問題を修正
- 起動時にツールを列挙している最中に切断した MCP サーバーが、エラーを報告せずツールなしで接続済みと表示されていた問題を修正
- ファイル編集の権限ダイアログで、変更された行が途中で切れて表示され、その旨の表示がないことがあった問題を修正
- 一時的な git プローブの失敗後、リポジトリ検出が既知のリポジトリ識別情報を失っていた問題を修正
- managed-settings ファイル、drop-in、MDM の plist、HKLM の値のいずれかが解析できない場合に管理設定が静かに無効になっていた問題を修正。Claude Code は起動を拒否し、原因元を明示するようになった
- リモートコントロールセッションで Stop がバックグラウンドのエージェントやワークフローを実際には停止できていなかった問題を修正。強制終了されたタスクはプロセスが終了するまで表示され、再度停止できるようになった
- 以前の停止処理が終了中のワークフロー実行を再開すると、エージェントが重複して実行されることがあった問題を修正
- 末尾にスラッシュや不要な `?`/`#` が付いた github.com のマーケットプレイスリポジトリ URL から、使用できない `.git` クローン URL が生成されていた問題を修正
- ブロックする Stop フックにより、ブロック後のターンでそのターンのモデルの推論内容が失われ、一部モデルではプロンプトキャッシュも外れていた問題を修正
- ブラウザでホストされた MCP サーバーのページが失われた後、リモート(claude.ai)セッションでターン開始に60秒かかっていた問題を修正
- worktree で分離されたセッションが、メインのチェックアウトに到達できない一般的な Bash ループ、xargs パイプライン、ランチャーでラップされたコマンドを拒否していた問題を修正
- テキスト測定を再利用することで、長い応答に対する端末のリサイズと初回描画のパフォーマンスを改善
- `/workflows` のエージェント詳細を改善: JSON の outcome がシンタックスカラー付きで実際の改行を保ったまま整形表示され、長い outcome は展開トグルの背後に折りたたまれるようになった
- ヘッドレス/SDK セッションの開始を改善: MCP サーバーの接続が完了すると、最初のターンが最大50ミリ秒早く始まるようになった
- GitLab リポジトリ内で実行された場合に、`/install-github-app` が GitHub 専用であることを説明し GitLab CI/CD のドキュメントを案内するように改善
- ネストされたバックグラウンドサブエージェントの結果が親サブエージェントのトランスクリプトに保存されるように改善。再開されたサブエージェントは結果を保持し、共有トランスクリプトにも配信内容が表示される
- `allowedMcpServers` の挙動を変更: ユーザーが追加したサーバーのみを対象とするようになった。これまで allowlist によってフィルタされていたリテラルな `managed-mcp.json` サーバーは、アップグレード後に読み込まれるようになる。オフのままにするには `deniedMcpServers` を使用する
- [VSCode] セッション一覧サイドバーに Active クイックフィルターとステータスフィルターメニュー(Needs input、Working、Completed)を追加
- 一時停止中のセッションでコネクタツールの権限プロンプトが承認された後、リモートセッションとスケジュールされたセッションが何も行わなくなっていた問題を修正
