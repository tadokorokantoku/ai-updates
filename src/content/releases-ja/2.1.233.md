- `--worktree` フラグと `claude agents` ビュー（MR は `!N` として表示）に GitLab merge request URL のサポートを追加
- Anthropic upstream 向けに opt-in の `forward_user_identity` apps gateway 設定を追加。サインイン済みユーザーの identity をヘッダーとして送信するようになり、gateway 配下のプロキシがユーザーごとに使用量を計上できるようになった
- Linux 上の Bash ツールコマンド向けに opt-in の memory cgroup サポート（`CLAUDE_CODE_TOOL_MEMORY_LIMIT`）を追加。暴走したビルドがセッションを停止させられなくなった
- WebFetch のセッション URL キャッシュ TTL を設定する `CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS` 環境変数を追加（デフォルトは変更なし: 15分）
- Claude が権限プロンプトを待っている間に環境がシャットダウンした際、クラウドセッションが lost 扱いになることがあった問題を修正
- 固定タイムアウトで長時間保持されたストリームを終了させるサーバー（サーバーレスホストなど）に対して、MCP v2 接続が subscriptions/listen ストリームを延々と再オープンし続けていた問題を修正
- Claude Desktop や VS Code 配下で実行している際、権限プロンプトに対して Notification フックが発火していなかった問題を修正
- サンドボックスが有効な場合に、Linux 上のアイドルセッションが CPU コアを1つ100%のまま維持してしまうことがあった問題を修正
- ユーザーまたはプロジェクトのスキルがバンドル済みスキルをシャドーイングしている際、`/checkup` や `/review` のようなバンドル済みスキルエイリアスが `-p` モードやプラグイン/MCP ロード時に "Unknown command" と報告していた問題を修正
- スキル/コマンドの引数置換を修正し、引数の値がテンプレートマーカーとして再展開されないようにした
- NT の `\??\` デバイスプレフィックスで記述された Windows パスが UNC パス検証を回避してしまう問題を修正し、NTLM 認証情報漏洩の経路を塞いだ
- `claude self-hosted-runner` のセッション開始時間を改善: セッションブランチが作業ツリーを書き換えずに作成されるようになり、サーバーとの2回の往復が agent の起動をブロックしなくなった
- apps gateway のエラー転送を改善: AWS upstream 上の Vertex、Foundry、Claude Platform からの 400/413 エラーが upstream 自身のメッセージを伝えるようになった。apps gateway での auto-compact に関するバグも修正
- `claude plugin validate` を改善し、ベアな `.claude/skills` ディレクトリをチェックして、frontmatter のパースに失敗する SKILL.md を報告するようになった
- スクリーンリーダーモードを改善: `/effort` セレクターが番号入力プロンプト付きの番号リストとして描画されるようになり、ヒントやダイアログのテキストが切り詰められなくなった
- print モードの診断を改善: Claude Code が認識しないモデル ID に対してリクエストが送られた際、stderr に `[claude-code:unrecognized_model]` の行が書き込まれるようになった。`modelOverrides` でマッピングすると抑制できる
- origin リモートが gitlab.com または bitbucket.org にあるリポジトリで GitHub app セットアップのヒントが表示されなくなるように変更。enterprise marketplace のヒントは GitHub 以外の内部 git ホストもカバーするようになった
- Todo/タスク追跡ツール（TaskCreate/Get/Update/List、TodoWrite）が Opus 4.8、Sonnet 5、Fable 5、Mythos 5 以降のモデルでは利用できなくなった。`CLAUDE_CODE_ENABLE_TODO_TOOLS=1` を設定すると元に戻せる
- Windows: 通常の `cd <dir> && <command> > file` という Bash コマンドで auto mode が繰り返し手動承認のために停止していた問題を修正（2.1.232 で発生した regression）
- Windows の Cygwin 形式シンボリックリンクおよび入力リダイレクト（`< file`）に対する 2.1.232 の Bash 権限変更をリバート。より狭い範囲の変更が後のリリースで再導入される予定
