- Claude Code の使用量警告に gateway の spend-limit サポートを追加。上限到達時のメッセージに、上限額・リセット時刻・オペレーターのメッセージが明記されるように（gateway 側も 2.1.225 が必要）
- `claude agents` に、信頼されていないディレクトリ向けの workspace trust プロンプトを追加。`claude` と同様の挙動に
- 長期間有効な `CLAUDE_CODE_OAUTH_TOKEN` が、一時的な 401 エラーによって保存済みログインの短命なトークンに置き換わり、再起動するまで headless セッションが壊れてしまう不具合を修正
- macOS で MCP OAuth サーバーが、keychain の読み取りタイムアウト後にまるで未認証であるかのように 401 エラーを断続的に連発する不具合を修正
- auto mode が、自身の権限チェックに対する safety-filter の拒否を連続ブロック数の上限にカウントしてしまう不具合を修正。アクション自体は引き続き拒否されるが、モデルにはリトライではなく先に進むよう伝えられるように
- headless セッションおよび起動時に、クロスセッションメッセージが通知や有効期限のないまま保留され続けてしまう不具合を修正
- 非常に大きな会話が圧縮された後、Remote Control のセッション再開で会話履歴が壊れる不具合を修正
- エージェント一覧で別プロジェクトのセッションにカーソルを合わせると、次のエージェントの起動ディレクトリが変わってしまう不具合を修正
- `--base-dir` を作成・書き込みできない場合に `claude self-hosted-runner` が登録に成功した後すべてのセッションで失敗していた不具合を修正。起動時に明確なエラーで終了するように
- Claude Code on the web のセッションが、再接続のたびに増え続けるイベントの積み残しを再送信しながら、スタックしていると誤って報告される不具合を修正
- Remote Control を改善: Claude アプリから添付された写真が、別のツール呼び出しでディスクから読み込む代わりに直接 Claude に表示されるように
- [VSCode] Focus view が最新の to-do リスト・保留中の質問のコンテキスト・確定済みの回答を折りたたんで隠してしまう不具合を修正。thinking のみの折りたたみは "Thought for Ns" と表示され、ターン完了時に再び折りたたまれるように
- SendMessage が、他のマシン上の Remote Control セッションに対して、相手から先にメッセージが来た場合のみ返信するのではなく、名前指定（`ListAgents` では `name [ref]` として表示）で会話を開始できるように
- SendMessage: 一度確認済みの Remote Control の宛先が、その宛先自身の一覧を確認できなかった場合でも、このマシン上の同名セッションに差し替えられなくなるように
