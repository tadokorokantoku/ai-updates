- ヘッドレスセッションに `/reload-plugins` を追加。Claude Code Desktop と SDK のコマンド一覧にも表示されるようになった
- デスクトップアプリ、リモートコントロール、その他のヘッドレス(`-p`/Agent SDK)セッション向けにテキスト形式の `/advisor`(`/advisor`、`/advisor <model>`、`/advisor off`)を追加
- リフレッシュ時に `openid` を再度要求された場合のみ id_token を返す IdP 向けに、Claude apps gateway に `oidc.scope_on_refresh` を追加
- `desktop` ポリシーブロックにおける新しい Claude Desktop キー(`userPluginMarketplacesEnabled`、`userPluginUploadsEnabled` を含む)への Claude apps gateway のサポートを追加
- パスに括弧を含む `Edit`/`Write`/`Read` の権限ルールが無効と判定されるか、Bash サンドボックスで無視され、「読み取り専用」のはずのフォルダが書き込み可能になっていた問題を修正
- コンパイルできないパターン(閉じられていない `[` など)を持つファイル権限ルールが1つあると、すべてのファイル編集が `Invalid regular expression` で失敗していた問題を修正。このような拒否ルールは現在、綴られた文字通りのパスのみを対象とする
- Bash の権限チェックが、REPORTTIME、REPORTMEMORY、DIRSTACKSIZE への代入にコマンド置換を隠した zsh コマンドを自動承認していた問題を修正。現在は確認を求める
- 企業のルート CA が OS の証明書ストアにのみ存在する場合に、Bedrock のモデル検出、トークンカウント、AWS SSO/STS の認証情報呼び出しが「unable to get local issuer certificate」で失敗していた問題を修正
- macOS の `permissions.blockReadsOutsideWorkingDirectories` が、サンドボックス化された git からユーザーの git 設定を隠し、worktree で分離されたサブエージェント自身のチェックアウトも隠していた問題を修正
- 以前の `/login` で残った API キーも持つ claude.ai Enterprise/Team ユーザーに対して管理設定が読み込まれなかった問題を修正
- `/status` が、サインイン済みの claude.ai アカウントと設定済みの API キーの両方が有効であるかのように表示していた問題を修正。使用されていない認証情報には印が付くようになった
- バンドルされたスキルのエイリアス(`/doctor` に対する `checkup` など)をキーとする管理対象の `skillOverrides` エントリが適用されない問題と、`<dir>:name` として列挙されたネストされたスキルを `Skill(name)` 拒否ルールがカバーしていなかった問題を修正
- `model: fable` エージェントが `ANTHROPIC_DEFAULT_FABLE_MODEL` の固定値に付与された `[1m]` タグを無視し、20万トークンのコンテキストウィンドウで黙って実行されていた問題を修正
- Fable 5.1 を利用できる組織で `/model` ピッカーに Fable 5.1 が表示されず、`/model claude-fable-5-1` と入力した場合のみ受け付けられていた問題を修正
- Claude Fable 5.1 のプロンプトキャッシュがツール結果の後に付加されたコンテキストをカバーしておらず、ツール呼び出しのタームごとにキャッシュされていない入力として再送されていた問題を修正
- プラグインフックの読み込み失敗後、セッション残り全体でモデル切り替えがブロックされたままになっていた問題を修正。切り替えのたびに再チェックされ、拒否理由が明示されるようになった
- 組織管理のプラグインのマーケットプレイスが読み込めない場合に、セッションでモデル切り替えがブロックされていた問題を修正
- SDK が提供する MCP サーバー(Desktop のコネクタなど)が最初のターンで欠落し、次のターンで初めて表示されることがあった問題を修正
- コネクタが追加または削除された際、クラウドホストの claude.ai セッションで Claude in Chrome のツールがタスクの途中で「Not connected」で失敗していた問題を修正
- 国旗、結合絵文字、アクセント付き文字が折り返し行をまたいで分割される問題と、国旗や結合絵文字が端末の最後の2列に位置する際に古いテキストが画面に残る問題を修正(現在は `…` として表示される)
- リモートコントロールが無効なモデル名のモデル選択を受け入れていた問題を修正。現在はエラーで拒否され、次のメッセージで失敗することがなくなった
- チェックポイントのバックアップファイルが存在せず、実際には何も復元されなかった場合でも `/rewind` と `--rewind-files` が成功したと報告していた問題を修正
- `/rewind` が巻き戻されたターンの古いファイル読み取り追跡情報を残しており、外部での編集後に「File unchanged since last read」というスタブや全文の再挿入が発生していた問題を修正
- セッションの worktree ディレクトリが git メタデータを失った後、(デスクトップアプリが使用する)`-p --resume`/`--continue` が再試行のたびに失敗していた問題を修正。現在は一度だけ失敗し、その後 worktree なしで再開する
- SendMessage で別のエージェントを再開したサブエージェントが、そのエージェントの完了によって呼び起こされなかった問題を修正(通知がメインの会話に送られていた)
- エージェントチーム: プロセス内のチームメイトのトランスクリプトが、長い API リトライ待機中(`CLAUDE_CODE_RETRY_WATCHDOG` 使用時など)にリトライ通知が実際のメッセージを追い出すことでメッセージを失ったり空白になったりしていた問題を修正
- バックグラウンドに移動したセッションが ListAgents に2回表示され(同じ名前の幻の「interactive」の双子として)、ビューアで SendMessage の配信を受け取っていた問題を修正
- 多数のセッションがプロジェクトディレクトリを共有する際に、断続的な「task output swap refused」エラーが発生していた問題を修正
- フルスクリーンでの Ctrl+Z が、一時停止したインターフェースの上に描画された代替スクリーンにシェルを残していた問題を修正
- 長いコンテキスト圧縮がまだ進行中の間に、Workflow ツールのサブエージェントが停止状態として再起動されていた問題を修正
- ホストアプリ(Claude Desktop など)がディレクトリとして保存する URL マーケットプレイスからのプラグインが、「marketplace entry path does not stay inside the marketplace directory」でインストールに失敗していた問題を修正
- claude.ai、デスクトップアプリ、モバイル(リモートコントロール)から操作しているセッションで artifact を公開した際に、余分なブラウザタブが開いていた問題を修正
- 一部の Cowork セッションで Artifact ツールの最初の呼び出しが「Invalid tool parameters」検証エラーで失敗していた問題を修正
- スキルやスラッシュコマンドの実行時に IDE の行選択が失われていた問題を修正(「N lines selected」というコンテキストが Claude に届くようになった)
- ネストされたサブグループ内の GitLab プロジェクト(例: `gitlab.com/group/subgroup/project`)のリポジトリ検出を修正
- GitLab リポジトリで作業している際に、レンダリングされた出力内の `owner/repo#123` の issue 参照が github.com にリンクしていた問題を修正。現在は gitlab.com の issue にリンクする
- Glob/Grep: 権限チェックの前に検索パスがディスク上でプローブされていた問題を修正。存在しないパスは、Read と同様に権限判定後に報告されるようになった
- 2.1.259 で導入された `Read()` 拒否ルールを Bash の引数に適用する変更を取り消し。`Read(./**/build/**)` ルール下ですべてのモードで `npm run build` を拒否し、auto モードでも `cd … && grep` が確認を求めるようになっていたため
- 構造化出力を改善: Workflow の `agent({schema})` が、決して満たされ得ない JSON Schema を事前に拒否するようになり、リトライ上限のエラーには最後のバリデーション失敗の内容が含まれるようになった
- 未プッシュのコミットがある worktree を持つバックグラウンドセッションの削除を改善: メッセージにブランチ名とコミット数が明示され、再度削除すると worktree が破棄される
- Claude apps gateway のリフレッシュ失敗ログに、失敗したステップ名を明示するよう改善
- 非対話型(`-p`/SDK)セッションのアイドル時 CPU 使用率を改善
- Amazon Bedrock 上の Claude apps gateway を改善: 中断されたリクエストの入力トークンが、1トークンのリクエストの代わりに AWS の無料 CountTokens API(`bedrock:CountTokens` 権限が必要)でカウントされるようになった
- `Edit(C:\dir\(name)\**)` のような、`\(` がパス区切り文字ではなくエスケープされた括弧として解釈されるルールに対する設定エラーを改善し、曖昧さのない表記を提案するようにした
- 100万トークンコンテキストモデルの自動圧縮を改善: Opus と Fable のセッションは100万トークンの上限に達する少し前に圧縮されるようになり、非常に大きなコンテキストでのリカバリー圧縮が10分でタイムアウトしなくなった
- `/ultrareview` と `claude ultrareview` を改善し、長時間実行されるクラウドレビューを最大45分(以前は30分)待つようになった
- Claude Fable 5.1 での `/effort` を改善し、セッション途中でエフォートを変更してもプロンプトキャッシュが無効化されなくなった
- バンドルされている `claude-api` スキルを更新し、Go、Java、C# のサンプルが現行世代のモデル ID を使用するようにした。また、より安価な worker やサブエージェントのモデルも現行世代であるべきことを明確にした
- フルスクリーンモードでの `ctrl+l`/`cmd+k` を、端末の `clear` のようにトランスクリプト表示をクリアするように変更。以前のメッセージを見るには上にスクロールする
- 閉じ括弧の後にテキストが続く権限ルール(例: `Bash(ls) x`)が何にもマッチしていなかった問題について、黙って無視するのではなく無効な設定として報告するように変更
- サーバー管理設定を変更し、管理対象の CLAUDE.md(`claudeMd`)がセキュリティ承認ダイアログを表示しなくなった。フック、シェルコマンド、サンドボックス、安全でない `env` 設定は引き続き承認が必要

- Claude apps gateway が、Claude Desktop 1.15200.0 以降が読み取るリスト形式で `orgPluginSettings` を送信するように変更。それより古いデスクトップは無視する
- `managedMcpServers` または `orgPluginSettings` エントリのネストされたオブジェクト内のフィールドを `desktop` ポリシーが誤って綴っている場合に、そのフィールド名を明示して起動を拒否するように Claude apps gateway を変更
- 厳格なサンドボックスモード(`sandbox.allowUnsandboxedCommands: false`)が有効な場合でも、`!` の bash モードプロンプトで入力されたコマンドは、自分のターミナルに入力するのと同様にサンドボックスの外で実行されるように変更
- セルフホストランナーの `--kill-session-after-min` を変更し、ユーザーの入力待ちのみのセッション(一時停止中で次のメッセージで再開可能)を、強制終了して失敗として報告するのではなく解放するようにした
- サブエージェントが開始したバックグラウンドコマンドの1時間の時間制限を削除。メインセッションと同様、終了するか停止されるまで実行され続ける
- [VSCode] フッターのモデルピルに選択中のエフォートレベルを追加し、モデル切り替え後にエフォートレベルが古いままになる問題を修正、フッターピルを以前のコンパクトなサイズに戻した
- [VSCode] セッション一覧のステータスフィルターメニューに Open と Closed を追加
- [VSCode] リモートコントロールが自動的にオンになった際に、新しいセッションでウェルカム画面が消えていた問題を修正
- [VSCode] セッション履歴ピッカーが、既に別のタブで開いているセッションを再度読み込んでいた問題を修正。現在はそのタブに切り替わる
- [VSCode] セッションタブの表示が再読み込み中の間、Rename コマンドが何もせず黙って失敗していた問題を修正。現在は常に適用される
- [VSCode] Claude Code がドロップされた応答を再試行した後に、未完成のメッセージ、空のツールカード、余分な「Thought for」の行が画面に残っていた問題を修正
