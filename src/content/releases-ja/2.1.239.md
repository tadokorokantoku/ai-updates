- コスト見積もり（`/cost`、ステータスライン、`--max-budget-usd`）が、データレジデンシーワークスペース向けの「US-only-inference」1.1倍プレミアムを含むようになった

- Python プロジェクトを `anthropic` 0.x から 1.x へ移行する `/claude-api upgrade` を追加。スキルの Python リファレンスも 1.x 向けに更新（タイムアウトは `httpx.Timeout` ではなく `anthropic.Timeout` を使用）
- クラウドセッション: claude.ai から同期されたプラグインが `name@synced` として表示されるようになり、`claude plugin enable/disable <name>@synced` で操作可能に。また、自分でインストールした同名プラグインを上書きしなくなった
- Alpine/musl ビルド: ネイティブの画像ペースト、クリップボード、音声キャプチャのアドオンが読み込まれるようになった（ランタイムに拒否されていた glibc ビルドではなく musl ビルドのバイナリを使用）
- 月間の支出上限にすでに達している場合の使用量上限メッセージが、セッションまたは週間上限のリセット時期も表示するようになった
- レスポンスの Content-Type ヘッダーを取り除くプロキシ経由での Bedrock ストリーミングを修正。これにより毎ターン非ストリーミングで再実行され、課金される API 呼び出しが密かに倍増していた問題を解消
- SSO プロファイルと `awsAuthRefresh` を使った Bedrock で HTTPS プロキシ経由の起動時にハングしていた問題を修正 — 認証情報の事前チェックが `HTTPS_PROXY` を尊重するようになった
- 存在しないディレクトリから Claude Code を起動した際に生の crash dump が表示されていた問題を修正。明確なメッセージを表示するようになった
- Claude Code プラグインが接続された JetBrains IDE のターミナルで、Edit と Write の呼び出しが約5秒間停止していた問題を修正
- プロンプトがキュー済みの状態で Esc を押すと、次のターンが早期に終了してしまい、Claude がまだ作業中なのにセッションがアイドルになり、その後の再送信で操作が繰り返されてしまうことがあった競合状態を修正
- WebFetch が、本来15分で破棄されるはずのページ内容をセッション中ずっとメモリに保持していた問題を修正
- クラウドセッション（web、デスクトップ、モバイルアプリの Claude Code）が、アイドルワーカーの再起動後に plan mode から復帰しなかった問題を修正
- フルスクリーンモードでターミナルの高さを超える MCP elicitation フォームがクリップされていた問題を修正: フォームがウィンドウに収まるようになり、隠れたフィールドはスクロールで到達可能、Accept/Decline は常に表示されるようになった
- クラウドセッションやSDKの `setMcpServers()` でのセッション途中の再接続時に一時的な 5xx が発生すると、リモート MCP サーバーが失敗状態のままになっていた問題を修正
- リネーム後に会話量が約64KBを超えると、`/resume` からカスタムセッションタイトルが消えていた問題を修正
- `claude -c`／resume が、`_`、`-`、`.` のような文字だけが異なる別ディレクトリのセッションを誤って選択していた問題を修正
- ファイルが変更されただけ、または単に再度開かれただけなのに、`/resume` とエージェントビューがセッションを「最近変更された」として表示・並べ替えしていた問題を修正
- 全プロジェクトモードの `/resume` が、削除済みディレクトリ（削除された worktree など）へ `cd` するよう案内していた問題を修正。そのようなセッションは現在のディレクトリで再開されるようになった
- `dark-ansi` テーマが、フルスクリーンモードで展開されたツール結果を背景と同色のテキストで描画していた問題を修正
- 応答不能な状況でもフルスクリーンレンダラーの案内が起動のたびに表示されていた問題を修正。3回表示されると以降は表示されなくなった
- gitignore 対象のディレクトリ内をターゲットとする場合、`**/` で始まる `.worktreeinclude` パターンが何にもマッチしなかった問題を修正
- UTF-8 BOM で始まる `.md` ファイルのエージェント、スキル、コマンドが無視されていた問題を修正
- 一部のモデルで `/insights` がレスポンス中に `<message>` タグをそのままエコーしていた問題を修正
- マーケットプレイスの `metadata.pluginRoot` が効果を持たなかった問題を修正: ドキュメント通り、裸のプラグインソース名がその配下で解決されるようになった
- ブラウザベースのターミナルで、マウスレポートが分割して届いた際にマウス移動が `"35;150;7M"` のようなテキストとしてプロンプトに挿入されていた問題を修正
- effort／ultracode ステータスバッジ色に対するカスタムテーマの上書きが無視されていた問題を修正
- OpenTelemetry のトレース分断を修正: `PreToolUse` フックによって遅延実行されたツール実行が、新しいトレースを開始するのではなく元のターンのトレースに戻って再開されるようになった
- エージェントビューの vim モードを修正: Escape がプロンプトをクリアする代わりに NORMAL モードへ切り替え、テキストを保持するようになった
- Shift+矢印キーで拡張したテキスト選択が `selection:copy` キーバインドで黙って失われていた問題を修正
- `voice.enabled` 設定経由で音声入力を有効化した後も `/voice` の起動時ヒントが表示され続けていた問題を修正
- シェルモード（`!`）の Tab 補完が `./script` のようなパスから `./` を落としてしまい、シェルが実行できないコマンドになっていた問題を修正
- フルスクリーンモードで、ターミナルウィンドウをクリックしてフォーカスを戻しただけなのに権限プロンプトへの応答やボタン押下として扱われていた問題を修正
- フルスクリーンモードでスラッシュコマンドパネル（`/config`、`/model` など）が最新メッセージを覆い隠していた問題を修正。会話がパネルの上に固定表示されるようになった
- Claude が応答中に `/workflows` の詳細ダイアログを開くと、ターミナルからはみ出してヘッダーが画面外に消えていた問題を修正
- Linux サンドボックスが、存在しない `.git/config.worktree` を読み取り不可としてしまい、`extensions.worktreeConfig` が設定されたリポジトリでサンドボックス化された git コマンドがすべて壊れていた問題を修正
- セッションの作業ディレクトリが削除された後に、フックが "posix_spawn ENOENT" で失敗していた問題を修正。フックはプロジェクトルートまたはホームディレクトリから実行されるようになった
- パターンが rules ディレクトリ自体やシンボリックリンクを指す場合、`claudeMdExcludes` がシンボリックリンクされた `.claude/rules` ファイルを除外できていなかった問題を修正
- 2つの Claude Code プロセスが1つのバックグラウンドジョブの状態を共有していた際に、Remote Control へのセッションタイトル同期が暴走していた問題を修正（2.1.232 のリグレッション）。タイトル更新は重複排除・レート制限されるようになった
- タイトルが `/` で始まるセッションが `SendMessage` で宛先指定できず、`ListAgents` で「(untitled)」と表示されていた問題を修正
- カーソルが `[Pasted text #N]` プレースホルダー内にある状態で Ctrl+W、Ctrl+U、Ctrl+K、Option+Backspace、Option+D、vim の `df`/`dt` を使うと、プレースホルダーが壊れてしまっていた問題を修正
- ログインコード欄などのマスク（パスワード形式）入力で、入力内容が他の場所へ Ctrl+Y で貼り付けられたり、二重 Esc でクリアした際にプロンプト履歴へ保存されたりしていた問題を修正
- 検索ボックスで Ctrl+Backspace が単語ではなく1文字だけ削除していた問題を修正
- 組織のポリシーチェックで拒否されたリクエストが、拒否が表示される前に再送信されていた問題を修正
- コンパクション後に表示されるリマインダーを改善し、スキルの元の引数が新しいリクエストとして再実行されないようにした
- ツール使用行の長いファイルパスが、1行に収まるよう中央で省略表示されるようになった
- 長時間の `SessionStart` や `Setup` フックの実行中も、リモートセッションが keep-alive を送り続けるようになり、フック実行中にコンテナがアイドル判定で回収されなくなった
- `/goal`: 長時間実行されるバックグラウンド作業の定期チェックインが、30分ごとの繰り返しではなく段階的に間隔を広げる（30分後、次に1時間後、それ以降は2時間ごと）ようになった
- `/goal`: `claude --resume` のピッカーからセッションを再開すると、そのアクティブな goal が復元されるようになった
- `ListAgents` が、他のピアがそのセッションにメッセージを送る際に使う自分自身の名前を通知するようになった。また、`SendMessage` で自分自身の名前を宛先にすると「no agent named …」ではなくその旨を伝えるようになった
- `ListAgents` と `/list-agents` が、稼働中のチームメイトも一覧表示するようになった（以前はサブエージェントと他のセッションのみが表示され、到達可能なチームメイトが見えていなかった）
- `keybindingFlavor: "readline"` が Bash に対しても単語キーにマッチするようになった: Alt+F と Ctrl/Option+→ は単語の末尾で止まり、Alt+D はそこまで削除（Ctrl+Y で貼り戻し可能）、句読点も単語の区切りとして扱われる
- 永続リトライモード（`CLAUDE_CODE_RETRY_WATCHDOG`）が、組織の支出上限やクレジット切れのエラーに対して、リセットを無期限に待つのではなく即座に失敗するようになった
- Claude in Chrome: `/clear` がセッションの Chrome タブグループを閉じるようになり、空になったグループは `/resume` 時や Claude Code 終了時にも閉じられるようになった
- リモートセッション: モバイルからアップロードされた画像に保存先のファイルパスが含まれるようになり、Claude がそれを自分が作成するファイルへコピーできるようになった
- Claude Code on the web: Bash などのツールから anthropic.com の非 API ホスト（www、docs など）へのリクエストが、セッションのネットワークプロキシを経由するようになり、環境の許可ドメイン設定が適用されるようになった
- Remote Control: アカウントで Remote Control が有効になっていない場合のメッセージと `claude doctor` の文言をより明確化
- Windows: クロスセッションメッセージングが利用可能になり、macOS/Linux と同様に、自分のマシン間の Claude Code セッションが `SendMessage` でメッセージを送り合い、`ListAgents` で互いを見つけられるようになった
- [VSCode] 使用量上限バナー内の「View usage」が、バナー中央に浮いて表示される代わりに警告文と同じ行に配置されるようになった
