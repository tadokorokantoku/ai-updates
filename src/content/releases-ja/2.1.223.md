- `strictKnownMarketplaces` と `blockedMarketplaces` の managed settings に owner ワイルドカードエントリ（`"owner/*"`）を追加。GitHub org 配下の全マーケットプレイスリポジトリを一括で許可・ブロック可能に
- workflow agent、fork された skill、スラッシュコマンド、再開したバックグラウンドエージェントが要求する subagent モデルが制限されており、代わりに親モデルが実行される場合に警告を表示するように
- クラウドセッションに `/teleport` のヒントを追加。`claude --teleport <session id>` でローカルから続行する方法を表示
- 細工されたコマンドが permission チェックから自身の一部を隠せてしまう Bash の permission バイパスを修正
- タブや不可視 Unicode でパディングされたコマンドが、承認ダイアログでコマンドの一部を隠せなくなるよう permission プロンプトを修正
- workflow script が動的 `import()` を使って workflow サンドボックス外でコードを実行できてしまう不具合を修正
- agent definition の `bypassPermissions` モードが org の bypass-permissions 無効化ポリシーを無視していた permission の抜け穴を修正
- セッション中の `/cd` の後にセッションを再開すると空になる不具合を修正
- gateway のモデル検出が `vertex_ai/claude-*` や `bedrock/anthropic.claude-*` のようなプロバイダープレフィックス付き ID で登録された Claude モデルを隠していた不具合を修正
- Anthropic のモデル ID ではない `modelOverrides` のキーがセッションの正規モデル ID として扱われていた不具合を修正。未知のキーはドキュメント通り無視されるように
- managed settings を修正: サーバー配信の設定が、マシンローカルの `managed-settings.json` や MDM プロファイルの env ブロックを無効化しないように。管理者の env はキー単位でマージされるように
- `sandbox.filesystem.denyWrite` が作業ディレクトリを含む場合に Linux でサンドボックス化されたコマンドが起動に失敗していた不具合を修正
- fork されたバックグラウンドエージェントが、再開時に fork の親プロンプトの再構築に失敗すると、セッションの残り全体で "already resuming" のまま固まっていた不具合を修正
- 履歴に不正な形式の診断情報の添付が含まれている場合に、再開したセッションが毎ターン失敗する、またはインタラクティブアプリが応答しないエラー画面のまま残ってしまう不具合を修正
- 通常とは異なる `git push` の出力をパースする際に稀に発生していたハングを修正
- `CLAUDE_CODE_DISABLE_1M_CONTEXT` を変更し、固定リストだけでなくネイティブ 1M ウィンドウを持つすべての Claude モデルを auto-compaction で 200K に抑えるように。auto-compaction がセッションを 200K に抑えられていない場合、起動時に警告を表示するように
- auto-compact を変更し、未認識のモデル ID のセッションを、想定されるコンテキストウィンドウを超えて成長させるのではなく、その範囲内に維持するように。以前の挙動に戻すには `CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT=1` を設定
- `/review` を `/code-review` のエイリアスに変更。現在の diff または PR（`/code-review <level> <pr#>`）をレビューする。深いクラウドレビューには `/code-review ultra` を使用
- effort level を指定しない `/code-review` が、直前に入力した level を再利用するように変更。level を変更するには `/code-review high` のように入力
