- Claude Fable 5.1 (`claude-fable-5-1`) を追加。Fable のデフォルトモデルとなり、1M コンテキスト、$10/$50 per Mtok(キャッシュ読み取りは $0.25/Mtok)
- 「Time format」(`timeFormat`) と `timeZone` 設定を追加: ターン終了時の時計とトランスクリプト表示のタイムスタンプを 12 時間表示、24 時間表示、24 時間 UTC 表示、または strftime パターンで指定可能に
- auto モードに Containment Escape ルールを追加し、クラウドのメタデータ認証情報の取得、egress の回避、テナント間アクセスが、環境側で想定済みとマークされていない限り自動承認されないように
- `CLAUDE_CODE_SUBAGENT_MODEL_FORCE` を追加。すべてのサブエージェントに `CLAUDE_CODE_SUBAGENT_MODEL`(またはメインモデル)を適用し、スポーン単位やエージェント定義側のモデル上書きを無視する
- `/effort` に `s` を追加し、`/model` と同様に現在のセッションのみ effort を変更可能に
- 停止されたセッションが残した古いサンドボックスマスクファイルに関する `/doctor` の警告を追加
- auto モードで作業ディレクトリ外への最初のファイル読み取り前に一度だけ確認プロンプトを表示するようにし、そのような読み取りをブロックするオプション (`permissions.blockReadsOutsideWorkingDirectories`) を追加
- 検出された `/model` ピッカーのエントリに、ゲートウェイ側から提供される `description` のサポートを追加 (`CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY`)。description がないエントリは引き続き「From gateway」と表示される
- 起動後に作成された `.claude/` フォルダ内の設定が再起動するまで反映されない問題を修正
- `←` で開いたエージェントビューからディスパッチされたセッションが、対象ディレクトリの `defaultMode` やエージェントの `permissionMode` を無視して常に元のセッションの権限モードで開始していた問題を修正
- `claude agents` で `keybindings.json` の Ctrl+G の再割り当てが無視されていた問題を修正。Ctrl+S / Ctrl+T は新しい `Agents` コンテキスト経由で再割り当て可能に
- macOS の npm インストールでセルフアップデート中にバックグラウンドセッションが起動に失敗する問題、および Windows で再利用されたプロセス ID を指す古いデーモンロックファイルが原因で起動に失敗する問題を修正
- スラッシュコマンドパネルの背後でレスポンスがストリーミングされている間、作業中スピナーが止まってしまう問題を修正
- スケジュールされたウェイクアップの後、バックグラウンドセッションの `state.json` の `detail` が自身のディスパッチプロンプトを繰り返し表示していた問題を修正
- `claude agents` で、再プロンプトしたバックグラウンドセッションが完了後も Completed の奥に埋もれたままになる問題を修正。Completed は最新の完了順で並ぶように
- 直前に削除されたディレクトリから `claude --bg` を実行した際に "backgrounded" と表示され、クラッシュしたセッション行が残っていた問題を修正。理由を表示して終了コード 1 を返すように
- Remote Control がセッション途中で再接続する際に Bash ツール定義を再送信し、プロンプトキャッシュミスを発生させていた問題を修正
- Bedrock、Mantle、Vertex、WIF で、二重にリストされたカスタム `Authorization` ヘッダーが設定済みの認証情報を上書きしていた問題、および Vertex セットアップウィザードが `~/.config/anthropic` の残存 Anthropic プロファイルを拾ってしまう問題を修正
- Claude apps ゲートウェイが、不要な host `Authorization` やプロファイルヘッダーを Foundry、Vertex、Bedrock に送信していた問題、および `ANTHROPIC_FOUNDRY_API_KEY` 設定時に Foundry Entra ID アップストリームが起動しない問題を修正
- API キーモードで、Foundry サブスクリプションキーと一緒に残存した Anthropic API キーや認証トークンが送信されていた問題を修正
- メッセージロールなしで保存されたプロンプトを持つ `/schedule` ルーチンが、実行時にやることがない状態になっていた問題を修正
- `claude agents` が、バックグラウンドセッションが他のセッションからのメッセージ承認を待っていることや、誰から送られたかを表示していなかった問題を修正
- 開いているバックグラウンドセッション内で Ctrl+S でスタッシュしたプロンプトが、セッションがアイドルになるか停止して再度開いた際に失われていた問題を修正
- サーバー管理設定経由でプッシュされたテレメトリ (OTEL) 設定が、デスクトップアプリの Code セッションを含むウォームスタート時に無視されていた問題を修正
- リーダーのメールボックス書き込みが一時的にロックされている間に、チームメイトの権限リクエストが二重に応答されていた問題を修正
- コマンドの自動継続レスポンスがストリーミングされている間、進行中のターンの下に幽霊のような重複したスラッシュコマンド行が表示されていた問題を修正
- `policyHelper` の `timeoutMs` と `refreshIntervalMs` がタイマーの最大値 (2147483647) を超えるとエラーになったり、1 ミリ秒ごとに再実行されたりしていた問題を修正。値は上限にクランプされるように
- 別のサブエージェントのトランスクリプトに切り替えた後にトークンカウンターがフリーズまたは異常に遅くなる問題を修正し、レスポンスのストリーミング中にバックグラウンドのサブエージェントとチームメイトのカウンターがリアルタイムに更新されるように
- 末尾にドットが付いたサンドボックスのネットワークホスト (`example.com.`) について、`deniedDomains` エントリがサンドボックス内でホストをブロックできなかった問題、および該当ホストの「二度と確認しない」が効かず確認を繰り返していた問題を修正
- Remote Control の同意プロンプトを閉じる操作 (Esc、または `claude remote-control` での `n`) が同意として扱われ、次のリクエストが確認なしで接続されていた問題を修正
- 起動後に読み込まれた管理対象 MCP の許可/拒否リストや `strictPluginOnlyCustomization` でブロックされるべき設定ファイル内の MCP サーバーに、`/mcp` の再接続・有効化から接続できてしまっていた問題を修正
- `strictPluginOnlyCustomization` が MCP をプラグイン専用サーバーにロックしている場合に、`claude mcp remove` がリモートサーバーの保存済み OAuth 認証情報を削除せずに残していた問題を修正
- Claude アプリから開始した Remote Control (`claude remote-control`) セッションが選択したモデルを無視し、マシンのデフォルトで実行されていた問題を修正
- `allowManagedPermissionRulesOnly` 有効時に、最初の設定リロード後に `--disallowedTools` とセッションの拒否ルールが失われていた問題を修正
- `--resume` がバックグラウンド化された会話を二重にリストし、`--continue` がそのバックグラウンド化前の停止したコピーを再度開いていた問題を修正。`--continue` は完了済みのバックグラウンドセッションも開けるように
- フルスクリーンモードで `!` シェルコマンドの出力をクリックして展開できなかった問題を修正
- 自動更新のたびに古い Claude Code バイナリを実行し続けるバックグラウンドセッションが積み重なっていた問題を修正し、退役させるように
- `claude agents --json` が終了時に端末を一瞬 raw モードに切り替え、他のプログラムの端末設定を上書きしてしまっていた問題を修正
- Proactive 出力スタイルのセッションが、開始したバックグラウンドコマンドや Monitor がまだ実行中の間、アイドル状態にならずに埋め草メッセージやログの繰り返し読み取りでビジーループしていた問題を修正
- コンピューターのスリープ、接続切断、サーバーエラーによってレスポンスがストリーミング途中で打ち切られた際にサブエージェントが停止していた問題を修正。未完了のレスポンスで終了する代わりに自動的に継続するように
- `claude agents` セッション内の `/btw` パネルで `←` が効かなかった問題を修正。回答途中でもエージェント一覧に戻れるようになり、セッションを再度開くとパネルも復帰する
- アドバイザーモデルを設定したセッションで、バックグラウンドリクエスト(compaction、`/recap`、プロンプト候補)がプロンプトキャッシュを利用できず、毎回会話全体をキャッシュなしで再送信していた問題を修正
- モデルが仕掛けた Monitor がまだ実行中の場合に、`claude -p` が最終結果の約 5 秒後に終了してしまっていた問題を修正。ウォッチが発火するかタイムアウトするまで待つように
- コンパウンドコマンドやサブシェル内で実行されたコマンドが auto モードで `permissions.ask` ルールをスキップし、確認プロンプトなしで実行されてしまっていた問題を修正
- プラグインが、コマンド・エージェント・スキル・フック等のコンポーネントパスがシンボリックリンクである場合に、自身のディレクトリ外のファイルを読み取れてしまっていた問題を修正。そのようなパスはエラーで拒否されるように
- `/add-dir` が現在の作業ディレクトリ内のディレクトリを拒否していた問題を修正。`--add-dir` の起動時と同様に、そのディレクトリのスキル・コマンド・エージェントを読み込むように
- トランスクリプトビューから停止したサブエージェントを再開した際に、メインエージェントに通知されていなかった問題を修正
- `/feedback` などのダイアログに ANSI カラー付きテキスト(CI ログなど)を貼り付けるとクラッシュしていた問題を修正
- プロジェクトの `.mcp.json` が FIFO やデバイスファイルのシンボリックリンクである場合に `claude mcp add/remove` がハングしたりメモリを枯渇させたりしていた問題を修正。実用的なメッセージで即座に失敗するように
- `claude -p --input-format stream-json` に JSONL でないデータがパイプされた際に無制限にメモリが増加していた問題を修正。明確なエラーで即座に失敗するように
- サブエージェントや他のツールが実行中にターンをバックグラウンド化 (`←` または Ctrl+B) すると、バックグラウンドセッションがそのツールを再実行せずに拒否されたものとして扱ってしまうことがあった問題を修正
- Bash の `Read()`/`Edit()` 拒否ルールが `< file` リダイレクトや `tac`、`egrep` のような読み取りコマンドに適用されていなかった問題を修正。任意の引数やリダイレクト先に対する拒否ルールが、そのコマンドを確実に拒否するように
- 5 MB を超えて肥大化したトランスクリプト(多数の画像を読み取った場合など)を持つサブエージェントの再開やメッセージ送信が「No transcript found」で失敗していた問題を修正
- worktree で隔離されたセッションが、git に触れない Bash ループ、`$VAR` の読み取り、`"$(…)"`、ヒアドキュメントを「worktree 内に留まることを検証するには複雑すぎる」として拒否していた問題を修正
- 会話を空の状態まで巻き戻した後、`/model` と `/effort` にプロンプトキャッシュの警告が表示されていた問題を修正
- 画像がリクエストごとのサイズ上限を超えるスクリーンショット主体の長いセッションで、毎ターンプロンプトキャッシュミスが発生していた問題を修正
- Edit 権限プロンプトの diff 表示で絵文字や複数コードポイント文字の幅が正しくレンダリングされていなかった問題を修正
- WebSocket MCP サーバーの接続失敗が根本的なエラーではなく「[object ErrorEvent]」としてログに記録されていた問題を修正
- 別の Claude Code プロセスが npm アップデートをダウンロード中に、バックグラウンドセッションが「Couldn't start the background service」で開始に失敗していた問題を修正。ダウンロード完了を待つように
- `timeout` や `setsid` の下などでシェルからデタッチしたバックグラウンドコマンドが、タスク停止や Claude Code の終了後も生き残っていた問題を修正
- タスクパネルや接続中のクライアントからバックグラウンドコマンドを停止した際に、Claude に通知されていなかった問題を修正
- バックグラウンドのサブエージェントを停止した際に、その Monitor が実行されたままになっていた問題を修正
- リンクされた worktree 内のサンドボックス化された git コマンドが、サブディレクトリへの `cd` 後にリポジトリの共通 `.git` ディレクトリへの書き込みアクセスを失っていた問題を修正
- Opus 4.7 以降での長い隠れ思考フェーズ中に Bedrock と Bedrock Mantle のリクエストが無音になり、アイドルタイムアウトで接続が切断されていた問題を修正。ストリームが進行状況イベントを運ぶように
- Claude apps ゲートウェイのセッションが期限切れまたは失効した後に Claude Code を起動すると、ネットワークエラーとして報告する代わりに、セッションが終了したことを伝え `/login` を案内するように修正
- セッションのネットワークプロキシが起動時に起動失敗した場合、クラウドセッションがセッションの残り時間中 git/GitHub の認証情報を失っていた問題を修正。バックグラウンドで再試行して復旧するように
- バックグラウンドデーモンの起動が中断された際にシステムの一時ディレクトリに残る `cc-daemon-*` フォルダの問題を修正。`cleanupPeriodDays` の保持期間クリーンアップがこれらを削除するように
- zsh が bash と異なる方法でパースする特定の `[[ ]]` 条件式を Bash 権限チェックが自動承認していた問題を修正。これらのコマンドは確認を求めるように
- 詳細トレーシングや raw API ボディログをオフにする、またはトレースエクスポートをオンにする設定変更で、管理対象設定の承認プロンプトがそのテレメトリ用の文言ではなく汎用の警告を表示していた問題を修正
- tmux/iTerm2 のペイン内のエージェントチームのチームメイトが、シャットダウン要求を確認した後も開いたままになることがあった問題を修正
- キーレスの Console サインイン(「Sign in with your Console account」)が組織のサーバー管理設定を適用していなかった問題、およびそのサインインで `/status` に Organization が表示されなかった問題を修正
- レンダリングパフォーマンスを改善: 長い会話でのターンごとの再レンダリング処理を削減し、返信が長くなってもストリーミングが遅くならないように、バックグラウンドエージェントの更新も画面全体を再レンダリングしないように
- キー入力ごとのレンダリング処理を削減し、プロンプト入力の応答性を改善
- ポリシーヘルパーの診断を改善: リフレッシュの失敗が `/status` に表示されるように、管理対象設定ダイアログを拒否した際に Claude Code が終了した理由が表示されるように、ヘルパーのタイムアウトがタイムアウトとして報告されるように
- `/code-review --comment` を改善し、対象未サポートと報告する代わりに `glab mr note` 経由で GitLab マージリクエストに所見を投稿するように
- 通知を改善: 別のダイアログの下にキューされた MCP elicitation や権限確認が、表示中の確認と同じ遅延でアイドルデスクトップ通知を送信するように
- 詳細/トランスクリプト出力を改善: まとめて到着した非同期フックの完了通知が、フックごとに 1 行ではなく 1 行にまとめて表示されるように
- `claude self-hosted-runner --configure-git` を改善し、git のプッシュネゴシエーションも有効化するように。古いクローンから新しいブランチを最初にプッシュする際、ツリー全体ではなく新しいコミットのみをアップロードするように
- ゲートウェイのキープアライブによってレスポンスが保持されている間の SDK ホストへの生存報告を改善し、引き上げた `CLAUDE_STREAM_IDLE_TIMEOUT_MS` の下での長い待機がハングしたセッションと誤認されないように
- MCP 接続と OAuth のデバッグ/エラーログを改善し、サーバーの URL やリクエストヘッダーに含まれる認証情報がマスクされるように
- `/fork` を改善し、元の会話のプロンプトキャッシュを新しいバックグラウンドセッションで維持するように: worktree のブリーフィングはシステムプロンプトの変更ではなくメッセージとして届くように

- `--effort` を変更し、新しいモデルのデフォルト effort の保持をそのセッションのみで解除するように(恒久的ではなく)。claude.ai の Remote Control セッションで選んだ effort は、その保持期間中は適用されるように

- `/btw` の履歴ブラウジングを `←`/`→` から `Shift+←`/`Shift+→`(または `[`/`]`)に変更し、最近のサイドクエスチョンを行き来してライブの回答に戻れるように

- Cowork と claude.ai のクラウドセッション: 自分のものではないアーティファクトを読み取る際、auto モードでも常に先に確認するように変更

- [VSCode] セッションリストパネルに、アカウントのメールアドレス・使用量メーター・使用量ダイアログを開く View details リンクを備えた、折りたたみ可能な ACCOUNT & USAGE と SESSION MANAGER のセクションヘッダーを追加
- [VSCode] 入力欄フッターに、現在のモデルを表示しモデルピッカーを開くモデルピルを追加。Effort 行と「More models」ページ付き
