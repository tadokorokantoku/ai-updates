- Bash で git リポジトリのより深い階層に `cd` した後、ディレクトリ単位や `paths:` の skills が見つからない問題を修正
- ターミナルでセッションを再開した際の最初の返信が、次回の再開時に欠落することがある問題を修正

- `/model` と `/effort` のキャッシュ警告が「再読み込みは次のメッセージまで待つ」と表示する問題を修正。Claude の作業中に行った変更は、より早く反映される場合がある
- 最後のメッセージが文中で「あなた待ちの項目」に触れていただけなのに、セッションがあなた待ちと表示される問題を修正

- 空の `!` 入力から Ctrl+D で終了すると、agent view がシェルモードで再び開く問題を修正
- vim モードで、残り行数より大きい `gj` / `gk` のカウントを指定した `d`、`c`、`y` がテキストを削除・コピーしてしまう問題を修正。Vim と同様、カーソルを移動するだけになった

- クラウドセッションでの WebFetch エラーを改善。解決できないホストは、許可されたネットワークドメイン外の可能性があると説明され、Claude が許可すべきホスト名を示せるように

- フラグが立てられたメッセージ後の自動モデル切り替えを、カスタムデプロイ名など Claude Code が認識しないモデル名にも適用するよう変更。無効にするには `CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1` を設定
