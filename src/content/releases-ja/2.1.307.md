- `/claude-api api-version` を追加し、Claude API コードを API バージョン `2026-10-21` に移行できるように
- パーミッションルール、auto mode、セーフティチェック、フック、サンドボックスがツール呼び出しを停止・確認要求・差し戻しするたびに発行される OpenTelemetry イベント `claude_code.safety_event` を追加
- `CLAUDE_CODE_DISABLE_1M_CONTEXT` が設定されていて、モデルが `opus[1m]` のように `[1m]` サフィックス付きエイリアスの場合に、model-not-found エラーでリクエストが失敗する問題を修正
- カスタム `ANTHROPIC_BASE_URL` ゲートウェイ配下および Foundry で、効果のない `prompt-caching-scope` beta ヘッダーが送信される問題を修正
- macOS でログインキーチェーンがロックされている間、`claude -p` で MCP サーバーが "needs authentication" と表示される問題を修正。理由が表示されるようになり、ロック解除後の次回実行では再サインインなしで接続される
- macOS または Linux のコンピューターが MCP サーバー接続中にスリープした際、サーバーがタイムアウトとして報告され、ヘッドレス実行で失敗状態のままになる問題を修正
- 接続が呼び出し中に閉じられたとき、HTTP MCP ツール呼び出しが二重に送信される問題を修正。リトライされるのは読み取り専用または冪等なツールのみに
- バックグラウンドタスク実行中に、SDK MCP サーバーの最新ツールなしでターンが開始されることがある問題を修正
- 多数の PDF ページ、画像、その他の大きなツール結果を読むターンで発生する一部の "Autocompact is thrashing" エラーを修正
- クラウドセッションで `/autocompact` の設定がセッション再起動後にデフォルトのウィンドウに戻る問題を修正
- クラウドまたは self-hosted runner セッションの再起動時に、`/clear` で消去した会話が復活することがある問題を修正
- Claude apps gateway セッションで `CLAUDE_STREAM_FIRST_BYTE_TIMEOUT_MS` が無視される問題を修正
- `OTEL_EXPORTER_OTLP_HEADERS` 設定時に、Claude apps gateway 配下の Claude Desktop セッションからのテレメトリが拒否される問題を修正
- `/permissions` > Recently denied で拒否されたシェルコマンドが表示されない問題と、そこからの承認を再試行コマンドのチェック時に auto mode のローカル分類器が無視する問題を修正。承認する行には説明ではなくコマンドが表示される
- `/help` と `/` コマンドメニューで、`/claude-api` などのバンドルスキルに短い説明ではなくモデル向けの長い説明が表示される問題を修正
- ストリーミング応答でサブエージェントのトランスクリプトにプレースホルダーのトークン使用量と空の stop reason が記録される問題を修正
- API のモデル確認に 5 秒以上かかると Agent SDK の `setModel()`（およびそれを使うアプリ）によるモデル切り替えが拒否される問題を修正。最大 15 秒待つように
- 接続アプリ経由で停止されたバックグラウンドコマンド（デスクトップアプリがアイドルセッションをアーカイブした場合など）が、ユーザーによる停止として Claude に報告される問題を修正。通知には出力ファイル名が含まれるように
- Cowork クラウドセッションで、サイトが 4xx ステータスや robots.txt による拒否を返した際に WebFetch がツールエラーを報告する問題を修正。ローカルセッションと同様に通常の結果として扱われる
- 直接設定された GitHub MCP サーバーの書き込みツールが、デスクトップアプリの Code タブで何も作成せずに閉じるフォームを表示する問題を修正
- サーバーが再利用中の接続を閉じていた場合に、Artifact ツールの読み取りが connection reset で失敗する問題を修正
- Self-hosted runner: `--use-anthropic-git-proxy` を使うセッションが、以前のセッションがクローンに残した `.claude/settings.local.json` をコミットする問題を修正
- Self-hosted runner: checkout フック中にセッションのアーカイブ・再キュー、または runner の停止を行うと、フックのプロセスが残り runner のスロットが保持されたままになる問題を修正
- パースできないツール呼び出しからの復旧を改善: エラーでターンを終了する前に、最大 2 回までリトライするように
- 同時に起動された fork サブエージェントを改善: 各 fork に自分がどの起動分かが伝えられ、互いの作業を開始しようとすることが大幅に減る
- ブラウザサインインを改善: アカウントプロファイルの読み込みを待たず、サインイン完了後すぐに成功ページが表示される
- クラウドおよび self-hosted runner セッションの Web 検索エラーを改善: 理由付きの 403 で拒否された検索は、汎用の "Authentication error" ではなくその理由を表示する
- デスクトップアプリの MCP サーバーの 1 つが接続できない場合の、クラウドセッションでの最初の返信までの時間を改善
- トランスクリプトに大きな貼り付け画像や PDF 読み取りを含むセッションの Remote Control 接続時間を改善
- WebSearch の予算を使い切った際に Claude へ渡される通知を変更し、ブラウザやコンピューター操作で検索エンジンに問い合わせないよう指示を追加
- 設定の `env` ブロック内の `axScreenReader` 設定と `CLAUDE_AX_SCREEN_READER` を、ユーザー設定、管理設定、`--settings` 設定からのみ適用されるよう変更（2.1.305 以降）
- Self-hosted runner: checkout フックをデフォルトで 30 分後に停止し、セッションのセットアップを失敗させるよう変更。それ以上必要な場合は `--checkout-hook-timeout-min` を引き上げるか `0` に設定
- Self-hosted runner: Anthropic-managed git 用に作成される証明書ファイルが、CLI と同様に信頼する証明書をフィルタするよう変更。除外された数は `[runner:warn]` 行に表示される
- [VSCode] 音声ディクテーションが自動停止した場合（15 秒間音声が認識されない、または 2 分の上限）に、理由とそれまでのテキストが保持されることをマイクボタン上に通知するよう追加
- [VSCode] Show more で展開した長いプロンプトがチャットパネル全体を覆う問題を修正。固定されたプロンプトはパネルの 40% までに制限されスクロールするように
- [VSCode] LaTeX 数式を含むリスト項目やテーブルセルの一部が、リッチテキストエディタに新しいリストやテーブルとして貼り付けられる問題を修正
- [VSCode] `NODE_EXTRA_CA_CERTS` が `~/.claude/settings.json` のみに設定されている場合に、TLS 検査プロキシ配下でディクテーションが失敗する問題を修正。`CLAUDE_CODE_CERT_STORE` にも従うように
- [VSCode] 「still open somewhere else」通知を、拡張機能の再起動で残った Claude プロセス（通常は約 10 分以内に自然終了）にも対応するよう変更
- [VSCode] 音声ディクテーションが、CLI と同様に信頼する証明書をフィルタするよう変更
- [VSCode] 拡張機能自身のリクエストが、CLI と同様に信頼する証明書をフィルタし、環境変数またはユーザー設定で指定された `NODE_EXTRA_CA_CERTS` ファイルを信頼するよう変更
- [Cloud sessions] 検索の実行中にリポジトリピッカーが "No repositories match" と表示される問題を修正。結果が届くまで "Searching…" を表示する
- [Cloud sessions] self-hosted 環境の "Waiting for a runner" ステータスが途切れる問題を修正。オンデマンド runner では最後のメッセージからカウントアップし、失敗した試行も表示する
- [Code Review] `@claude review stop`（`off`、`pause` も可）を追加。新しいレビューを開始せずに、プルリクエスト上の `@claude review always` サブスクリプションを終了できる
