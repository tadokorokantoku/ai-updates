- 「Prompt is too long」エラー後の compact で、base64 や SVG などの密度の高いテキストを含む会話を残しすぎ、次のリクエストが再び失敗しうる問題を修正

- 長時間の編集後に外部エディタを閉じた瞬間、質問の自動継続タイムアウトが発火する問題を修正
- Windows: Git Bash がなく、hook のコマンドが引用符付き文字列（引用符で囲んだパスなど）のみの場合に、PreToolUse および PermissionRequest hooks がツール呼び出しを通してしまう問題を修正
- auto モードで、作業ディレクトリ外への最初の読み取り前のプロンプトを改善。それらの読み取りをブロックするとシェルコマンドが権限確認を求めるようになる場合、その旨を表示
- トランスクリプトファイルが非常に大きい場合の、非対話セッション（`-p`、Agent SDK）の compact 中のメモリ使用量を改善
- tmux（`allow-passthrough` と `focus-events` が有効）、kitty、Ghostty、フルスクリーン描画の iTerm2 3.5+ で、mod の `Image` が `alt` テキストのみではなく画像を描画するように改善
- Linux: bubblewrap によるサンドボックス起動を Ubuntu の AppArmor によるユーザー名前空間の制限が妨げている場合に、`/sandbox` と起動時の警告がそれを明示し、解除方法を案内するように改善
- 非対話セッションで、サーバーの elicitation が未回答のまま MCP ツール呼び出しがタイムアウトした場合のエラーを変更。回答がなかったことと、呼び出しを繰り返さないことを Claude に伝えるように
