- agents ビューに、セッション名で検索する Ctrl+F と、グループ間を移動する Alt+↑/↓ を追加。どちらも、およびリネームも keybindings.json で再割り当て可能

- レスポンス途中の API タイムアウトでターンが失敗する問題を修正: 非対話セッションとサブエージェントは部分的なレスポンスから続行し、thinking のみのレスポンスは再試行する
- 直前の返信のトークン使用量が 0 と報告された場合に、長い会話が自動コンパクトされず "Prompt is too long" で失敗する問題を修正
- `--resume` が、コンパクト直後に復元されたファイルなどのコンテキストを落とすことがある問題を修正
- 再開したセッションで、ターン最後のレスポンスが保存されず、次の `--resume` でプロンプトが未回答のまま表示されることがある問題を修正
- 読み込み中に同じセッションがファイルを書き換えた際、再開時にトランスクリプトが途中で切れた状態で読み込まれることがある問題を修正

- Mantle や structured outputs を拒否するゲートウェイ経由で、セッションタイトル・メモリ想起・プロンプトフックが失敗する問題を修正。structured outputs を無効にする `CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS` を追加
- ブロックされたツールが Bash でないのに、auto mode の拒否が Bash の permission rule を指し示す問題を修正
- Bedrock と Mantle の auto mode が、古いモデルへのリクエスト（WebFetch の要約や `sonnet` サブエージェントなど）の後、セッションの残りでローカル分類器に切り替わる問題を修正
- 新しく選んだモデルで再起動したクラウドセッションが、サーバーに拒否された後もそのモデルとして応答する問題を修正
- 未承認 URL への WebFetch の permission プロンプトが 5 分間未回答のとき、Cowork クラウドセッションが入力待ちのままになる問題を修正
- 別のデバイスで開始した Cowork クラウドセッションにスマートフォンが参加した際、プロンプト候補が表示されない問題を修正
- Claude Code の再起動前に描画されたビューで、mod のボタンが別のボタンのアクションを実行することがある問題を修正
- 1 つの `Code` 要素にパースできない diff があると、プラグインのペインが何も表示しない問題を修正。プレーンコードとして描画されるようになった
- プラグインの LSP サーバーが、`initializationOptions` と `settings` で置換後の値やマニフェストのデフォルトではなく、リテラルの `${user_config.*}` と `${CLAUDE_PLUGIN_ROOT}` プレースホルダーを受け取る問題を修正
- worktree で動くサブエージェントで、プラグインの `tool.call` フックが Bash を失敗させたりファイル検索が誤ったフォルダーを読んだりする問題を修正
- 古い git（2.39 未満、例: Ubuntu 22.04 の 2.34）で `git-subdir` プラグインのインストールが失敗する、または不完全なプラグインがキャッシュされる問題を修正
- `--plugin-dir` で読み込んだプラグインが `/plugin` で "Configure options" を表示しない問題を修正
- タイマーや読み取りの実行中にプラグインがリロードまたは無効化されると、バックグラウンドセッションが終了する問題を修正
- 引用符なしデリミタのサンドボックス内ヒアドキュメント（`python3 <<EOF`）で、本文がプレーンテキストと単純な `$VAR` 参照のみの場合も、sandbox auto-allow 下で毎回承認を求められる問題を修正
- シェルが算術式として評価する値の `BASHPID` 代入を、黙って許可せず Bash ツールの permission チェックで確認するよう修正

- 別セッションが保留していたメッセージを Claude が「配信済み」と報告する問題を修正: 配信されなかったことと該当セッション名を通知するようになり、SDK セッションでは Claude がターン中にそれを知れる

- 認証情報をセキュアストレージに保存できなかったときに `/login` が "Login successful" と報告する問題を修正。失敗を表示し、新しいログインが反映されなかった場合は再試行を提案する (anthropics/claude-code#73861)
