- 先に実行される plugin が mod の hook をスキップした際に、イベント名と plugin 名を示す transcript 行を追加
- mod の `tool.check` の応答に `decider: "person"` を追加: 許可ダイアログまたはホストのコールバックだけが承認でき、誰にも確認できない環境では mod の理由付きで拒否される
- mod の `tool.check` イベントに `e.isReadOnly` を追加。ツール呼び出しが読み取り専用の場合に設定される
- `/auto-mode-setup` を追加: プロジェクトと直近のセッションを読み取り、あなたの環境について auto mode に教えるための案内付きセットアップ。Bedrock、Vertex、Foundry、Claude apps gateway、テレメトリ無効のセッションでも利用可能に
- `/claude-api managed-agents-secure` を追加: Managed Agents の agent 設定を Anthropic が公開しているセキュリティガイドと比較する（何も変更しない）
- transcript ビュー (Ctrl+O) のコンパクション要約に、それ以前に呼び出されたツール名を追加
- Pro および Max プランで、非アクティブな会話を再開すると 5 時間の使用上限のかなりの割合を消費する場合に警告を追加: そのまま再開するか、新しい会話を始めて前の会話に言及すれば Claude が参照できる
- `ANTHROPIC_API_KEY` を起動時に承認した後、または `/config` で「Use custom API key」を切り替えた後、組織ポリシーが 1 時間ごとのチェックまで更新されない問題を修正
- `sandbox.filesystem.denyRead` の glob に、文字クラスではない角括弧（`[user-id]` のような route フォルダなど）が含まれる場合に、Linux でサンドボックス化されたコマンドが起動に失敗する問題を修正
- マウントされたドライブやトップレベルのフォルダ（`/Volumes`、`/media`、WSL の `/mnt/c`）に対する `rm -r` が、`rm -rf /Applications` と同様の安全確認プロンプトの対象にならない問題を修正
- ファイルのトリミング中にディスクが満杯になると、`CLAUDE_CODE_TRANSCRIPT_LOCAL_GC` が保存済み transcript のメッセージを失わせる問題を修正
- plugin が subagent を生成したり終了済みの subagent を再実行したりして、`--max-turns`、Stop、入力終了を過ぎてもヘッドレス実行が続く問題を修正
- mod のリロード失敗時に、維持されているバージョンのツールとコマンドが削除される問題と、以前のバージョンがまだ読み込まれているかどうかについてのメッセージが誤っている、または表示されない問題を修正
- `key` を持たない同じラベルのボタンが変更なしで再描画されると、mod のボタンのクリックが失われる問題を修正
- managed settings があるマシンや Team / Enterprise プランで、組み込みの `plugin-authoring` skill による mod 共有がシークレットスキャンで止まる問題を修正
- URL 承認が必要な WebFetch を行う subagent ごとに、誰も承認できないまま Cowork クラウドセッションの定期実行が毎回 5 分待たされる問題を修正
- 作業ディレクトリ外のファイルへの Write 結果や拒否された編集が `../../…` と表示される問題を修正。`~/…` またはフルパスで表示されるようになった
- Cowork クラウドセッションで、claude.ai Directory plugin の skill が「/」メニューから選んでもコマンドとして実行されない問題を修正
- ターミナルで別のアカウントがサインインしている場合に、Remote Control がデスクトップ会話の履歴を恒久的に隠してしまう問題を修正
- 有料プランで DISABLE_TELEMETRY または DO_NOT_TRACK が設定されていると、Claude Desktop から Remote Control を開始できない問題を修正
- SDK およびデスクトップセッションで、モデル切り替え、メッセージ、割り込みがコンテキスト使用量チェックの後ろで待たされる問題を修正
- LLM gateway 経由で `context_management: Extra inputs are not permitted` エラーが発生する問題を修正。Claude Code は該当フィールドなしでリクエストを再送する
- 初回セットアップ中のサインイン後や /logout 後の最初の起動で、server-managed settings 経由で配信された OpenTelemetry 設定がセッション全体で無視される問題を修正
- macOS と Linux の Claude Desktop Code タブのセッションで、サンドボックスなしの Bash コマンドが ~/.zshrc などのシェル起動ファイルで export した環境変数を認識しない問題を修正
- サーバーエラー後に Consumer Terms の通知が 1 日以上スキップされる問題を修正
- ネットワークまたはサーバーエラー後に、`/privacy-settings` が適用されない可能性のある選択肢を表示する問題を修正
- API が長すぎるとして拒否した会話のコンパクション中にターンを停止すると、"Context limit reached" や "Prompt is too long" エラーが発生する問題を修正
- subagent が完了直後にメッセージを受け取ったり再開されたりすると、直近の作業を忘れることがある問題を修正
- `claude --help` の `--tools`、`--resume`、`--debug`、`--json-schema`、`--disable-slash-commands`、`--system-prompt-snapshot`、`claude update` の説明を実際の動作に合わせて修正
- HEAD が detached 状態または別のブランチにある場合に、`claude --worktree` が終了時に確認なしで worktree とそのブランチを削除し、コミットを失う可能性がある問題を修正
- 再開したセッションとクラウドセッションで、起動時に plugin がリロードされるたびに skill 一覧全体を Claude に再送していた問題を修正
- 画像のような名前のアイドル状態のパイプやデバイスを待つ Read を、割り込みで終了できない問題を修正
- `CLAUDE_CODE_EFFORT_LEVEL` が `auto` または `unset` でレベルが送信されない場合に、`/effort status`、`/effort ultracode`、プロンプトの effort 表示が推測した effort レベルを表示する問題を修正
- 同じツール呼び出しの Agent SDK コールバック hook がタイムアウトした際に、PreToolUse hook の拒否理由がタイムアウトエラーに置き換わる問題を修正
- 大きなコマンドの出力ファイルをセッションの tool-results フォルダにコピーできなかった場合に、ディスクが満杯でなくても Bash と PowerShell がそのファイルを削除する問題を修正
- プレビュー付きの選択式質問に入力したメモが、約 100 桁未満のターミナルで "…" で切り詰められ、入力内容が見えなくなる問題を修正 (anthropics/claude-code#82768)

- agent teams: メインセッションからシャットダウン要求を承認しても CLI 全体が終了しないよう修正
- ある skill の `once` hook が、実行後に別の skill の同一 hook も削除してしまう問題を修正

- マウスボタンを離す前に Ctrl+C を押すと、agents ビューでテキスト選択がコピーされずにクリアされる問題を修正
