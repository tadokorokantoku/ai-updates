- Claude Mods を追加: プラグインがより深い動作を変更できるようになった

- Self-hosted runner: GitHub CLI がインストールされていない macOS と Linux のマシンで、Anthropic マネージドの git を使うセッション向けに、組み込みの `gh api`（REST のみ）を追加

- 再接続リクエストに応答がないとき、Remote Control が数分間メッセージを受信できない問題を修正: 30 秒で諦めて再試行するようになった
- `asyncRewake` を設定した hook のスクリプトファイルが存在しないとき、「found issues」通知で Claude が繰り返し起こされる問題を修正: 壊れた hook は一度だけ報告される

- Chrome に接続できないとき、Claude in Chrome のブラウザピッカーが JSON パースエラーを表示する問題を修正
- claude.ai ログインで `/model` の Fable を選ぶと現行バージョンの ID が保存される問題を修正: 保存されるデフォルトは Opus や Sonnet と同様に最新の Fable に追従する
- Opus 5.5 と Sonnet 5.5 の切り替え（`/model`、`opusplan`）で過去の MCP ツール通知が書き換えられ、以前の extended thinking が失われることがある問題を修正
- Amazon Bedrock Guardrails のブロックがレスポンスの途中で届き、返信が thinking で始まっていた場合に、guardrail のメッセージではなく API エラーでターンが終了する問題を修正
- 危険な `rm`（`/` やホームディレクトリへのものなど）が、同じコマンドで `~` やワイルドカードのパスへ出力をリダイレクトしていると常時確認のセーフガードを失う問題を修正
- 返信の実行中にモデルを切り替えた後、`claude -p` と SDK セッションが以降のすべてのメッセージでモデルフォールバックを繰り返す問題を修正
- セッションの再開後やコンパクション後に、フォルダの CLAUDE.md が二重に添付される問題を修正
- エージェントの終了後、セッションの開始元ワークツリーが削除され、バックグラウンドセッションを `claude agents` から再度開けない問題を修正
- `/advisor` のペアリングチェックを修正: Sonnet 5.5 が Opus 4.7 と 4.8 にアドバイスできるようになり、API が拒否するアドバイザーは黙って無視されず事前にフラグが付く
- Bash の権限プロンプトに「Contains simple_expansion」のような内部パーサー名が表示される問題を修正し、分かりやすい説明に変更
- 低速または高負荷のマシンで、長い会話中にスクロールキーを押し続けると fullscreen セッションが「Claude Code exited after an unrecoverable interface error」で終了する原因を修正
- 組織のツール別権限の上限が、`__proto__` という名前の MCP ツールで黙って無視される問題を修正
- JSON として保存された大きな MCP 結果を、1 行を分割できない Read の offset と limit でページングするよう Claude に指示していた問題を修正
- コンパクション後に、コミット帰属リマインダーがツール結果の中で配信される問題を修正
- screen reader モードで、検索ボックス（/resume や /permissions など）とサインインコード欄のカーソルが入力テキストから離れる問題を修正
- screen reader モードで、追加コンテキストが任意である /rewind の要約オプションで、何も入力せずに Enter を押すと拒否される問題を修正
- screen reader モードで、Tab が何もしない承認プロンプトに「Tab to amend」のヒントが表示される問題を修正
- screen reader モードで、/permissions と /mcp で何もしない矢印キーが一覧に出る問題と、空のメニューや検索ボックスがキーを使っている間に「Select with numbers」と表示される問題を修正
- screen reader モードで、ファイル編集の承認プロンプトなどの diff で変更行が読み上げられない問題を修正
- screen reader モードで、`claude --teleport` の進捗画面と、チェック中の MCP フォーム欄がスピナーのフレームごとにスクリーンリーダーへ再送される問題を修正
- `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS` が、セッションタイトルと prompt hook のリクエストから structured-output 形式を取り除かず、Bedrock ベースのゲートウェイが拒否する問題を修正
- screen reader モードで、前の画面がターミナルウィンドウより高かった場合に、2 つ目の承認プロンプト、変更された /config の行、却下されたプランの行の先頭行が欠ける問題を修正
- `--include-partial-messages` が、途中で打ち切られた返信の `message_stop` を遅れて、または一切送らず、アプリが返信を進行中のまま表示する問題を修正
- `claude agents` が、バックグラウンドセッションが待っている権限プロンプトを表示しないことがある問題を修正
- コミット済みの `.gitattributes`（UTF-16 で保存されたものなど）を読めずにアップロードが止まったとき、`/ultrareview` が `.git/info/attributes` についてのアドバイスをする問題を修正
- HTTP プロキシ配下で `claude remote-control` の登録が、誤解を招く「Check your organization permissions」エラーで失敗する問題を修正 (anthropics/claude-code#97352)
- Linux のサンドボックス化された Bash コマンドが、Claude Code 実行ファイルへの開いたハンドルを継承する問題を修正
- 「Reduce motion」設定がオンでも、実行中ツールのドットと 3 つのスピナーが動き続ける問題と、/rewind の確認画面でメモを入力中に「ago」の時間が更新される問題を修正
- screen reader モードで `claude agents` の時刻が毎秒変わる問題を修正: 変更は最大でも 10 秒に 1 回になった
- 失効した claude.ai ログインで「OAuth token revoked」ではなく汎用の `API Error: 401` が表示される問題を修正。`-p` モードではエラーが「Failed to authenticate」で始まる
- `/ultrareview` のアップロード拒否で、リポジトリの設定ファイルが指定する変数を自分のユーザー設定にコピーするよう案内される問題を修正
- `/<skill>` をプロンプトとして入力して実行した `context: fork` スキルのターンが、Skill ツールの fork と異なり `--output-format stream-json` と SDK でストリーミングされない問題を修正
- /feedback と /bug を修正: 事前入力される GitHub issue に最近のエラーメッセージが含まれなくなり、確認画面ではそれらがレポートの一部として一覧表示される
- リポジトリがプレーン http で提供されている場合に、`claude plugin marketplace add --sparse` と `git-subdir` プラグインのインストールが「transport 'http' not allowed」で失敗する問題を修正

- 起動時の `--plugin-url` ダウンロードと重なったプラグインのリロードが、セッションにキャッシュされたプラグインアーカイブを破損させる問題を修正
- Claude Desktop を開く操作がタイムアウトした場合や出力が多すぎた場合に、`/desktop` が部分的な出力を引用する問題を修正: エラーに原因が示されるようになった

- 同期されたプラグインの SessionStart hook が新しい cloud セッションで実行されない問題を修正
- トランスクリプトの「N hooks ran」の要約と verbose デバッグログの一致 hook 数に Claude Code 内部のコールバックが含まれ、設定した hook が 1 つでも 2 つと表示される問題を修正

- cloud と SDK セッションでセッション中に追加されたリポジトリが、Claude がディレクトリを変更した後にスキルとプラグインを読み込まず、CLAUDE.md の読み込みも遅れる問題を修正
- 一辺が 8,000 ピクセルを超える PNG、JPEG、WebP 画像がリモートセッションから送信できない問題を修正: Claude は縮小したコピーを送るようになった

- `/config` を改善: 循環する設定に ‹ › を表示して ←/→ で双方向に切り替えられ、狭いターミナルでは各値をラベルの下に積み、PgUp/PgDn で一覧をページ送りできる
- プラグインマーケットプレイスのエラーを改善: マーケットプレイスが無視または拒否された理由と対処法を平易な言葉で説明する
- プラグイン一覧を改善: プラグインの依存関係がインストールされていない場合にその旨を表示し、プラグインの更新では完了しなかったインストールを再試行する
