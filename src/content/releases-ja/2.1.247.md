- `SendFeedback` ツールを追加: セッション中に問題が発生した場合、Claude がフィードバックレポートの下書きを作成し、`/feedback` からレビューして送信できるように（`feedbackDrafts` 設定でオフ可能）
- `spinnerTipsOverride` に `{id, text, cooldownSessions, priority}` エントリ、`tipsFile`、`label` を追加。組織が組み込みのヒントと並べて独自のヒントをローテーションできるように
- Bash 権限プロンプトに auto mode を案内するヒントを追加。ワンキーで「Yes, and switch to auto mode」を選択可能に
- `/claude-api cost-optimize` を追加: 既存プロジェクトの Claude API 利用コストをプロファイルし、コスト削減策（キャッシング、トークン管理、バッチ、effort、モデル選択）を1つずつ効果測定しながら適用できるように
- `/claude-api` スキルに Admin API のカバレッジを追加（組織メンバー、招待、ワークスペース、API キー、レート制限レポート、ワークロード ID フェデレーション、CMEK）
- 履歴検索、`/config`、`/mcp`、`/skills`、バックグラウンドタスク、`/model` において、矢印キー + Enter を素早く押すとナビゲートした行ではなく1つ上の行に対して操作が実行されていた問題を修正
- サブエージェントが初回呼び出しのモデルで404が発生すると停止していた問題を修正。セッションのフォールバックモデルチェーンを使用するようになり、親に返されるエラーにはエラータイプ、ステータス、リクエストID、モデルが含まれるように
- フックやバックグラウンドエージェントが数メガバイトのエラー出力を出力した場合に会話がオーバーフローし、セッションが「Prompt is too long」でフリーズすることがあった問題を修正
- kitty プロトコル対応ターミナルで非ラテン文字（キリル文字など）のキーボードレイアウト時に Ctrl キーボードショートカットが発火しなかった問題を修正
- エスケープシーケンスの直後でマウスレポートが複数回の読み取りに分割されて届いた際に、`<35;150;7M` のようなテキストがプロンプトに挿入されていた問題を修正
- dotfile で管理された `~/.claude/settings.json` のシンボリックリンク（nix/home-manager、stow）がサンドボックスの書き込み可能領域外を指すように変更されている場合に、Bash サンドボックスのコマンド後クリーンアップがそれを削除していた問題を修正
- `/terminal-setup` が Zed の `keymap.json` 全体を上書きし、キーバインドをマージしていなかった問題を修正
- セッションレジストリを更新できなかった場合に `/rename` が無言で成功を表示していた問題を修正。他のセッションには旧名が表示され続ける可能性がある旨を表示するように
- `--agent` で開始したセッションでの `/compact` および「Summarize from here」が、会話固有のシステムプロンプトではなくデフォルトのシステムプロンプトで要約していた問題を修正
- ターミナルホストプロセスが停止した後、`claude agents` でバックグラウンドセッションが永久に「opening…」と表示され続けていた問題を修正。数秒以内に理由付きで失敗と表示され、Enter で再起動できるように
- フックやバックグラウンドタスクの出力ファイルが書き込めない場合にメモリが無制限に増加していた問題を修正。ファイルには出力が失われた旨が記録されるように
- SSH経由の `/install-github-app` を修正: コピーショートカットが常に成功したと表示するのではなく、サインインURLがどのようにコピーされたかを表示するように。ブラウザを開けない場合はURLが即座に表示される
- フォアグラウンドから引き継がれたシェルコマンドが、バックグラウンドセッションで完了した際に内部エラーを記録したり、誤解を招く `[exited with code -1]` 行を表示したりしていた問題を修正
- バージョン指定のないマーケットプレイスプラグインのライブキャッシュディレクトリが、2つ目のスコープへのインストール時に削除・再作成され、それを使用中の実行中セッションを妨害する可能性があった問題を修正
- `/remote-control` で開始した Remote Control セッションが、接続先クライアントに作業ツリーの差分を報告していなかった問題を修正
- Claude Code の起動前にセルフホストランナーセッションが `running` と報告し、Claude デスクトップアプリから「Claude is waiting for your input」という時期尚早な通知がトリガーされることがあった問題を修正
- 管理設定で Claude apps ゲートウェイのサインインが構成されており、かつ Anthropic のエンドポイントに到達できない場合に、初回セットアップが「Unable to connect to Anthropic services」で終了していた問題を修正
- メッセージ送信直後にモードを切り替えると、クラウドセッション（Claude Code on the web、デスクトップアプリ、モバイルアプリ）が以前の権限モードを表示することがあった問題を修正
- バックグラウンドエージェント、シェル、モニターが実行中のままターン間でセッションのコンテナが再起動すると、クラウドセッションが無反応になっていた問題を修正。再開されたセッションは失われた作業内容を報告するように
- プラグインマーケットプレイスのハードニングを改善: 制御文字や不可視文字を含む名前を拒否し、`/plugin` および `claude plugin` の出力内でマーケットプレイス提供のテキストがエスケープセーフになるように
- Bedrock、Vertex、Foundry セッション（およびテレメトリが無効なセッション）を改善: 設定された MCP サーバーへの接続に失敗した場合、Claude がツールが存在しないと結論づけるのではなく、その旨を伝えられるように
- Sonnet 5 のデフォルトの自動圧縮ウィンドウをフルの1Mコンテキストに変更。1Mウィンドウのセッションは約934Kトークンではなく約967Kトークンで自動圧縮されるように
- クロスセッションのピアメッセージがデフォルトで `Message from @<sender>: <first line>` の1行プレビューに折りたたまれるように変更。Ctrl+O で全文を展開可能
- レンダリングされた Markdown 内のターミナルハイパーリンクを変更: ネットワークパスやオートマウンターのパスを指す、制御文字を含む、または不可視文字で始まるリンク先はプレーンテキストとして表示されるように
- 直前のチェックから1分未満の場合、プロンプトフッターのPRバッジがターミナルの再フォーカス時にGitHubの再チェックをスキップするように変更
- 管理設定でゲートウェイサインインまたはカスタム OAuth デプロイが強制されている場合、ログイン後だけでなく起動時からアナリティクスをオフのままにするように変更
- Claude apps ゲートウェイのサインインリクエストが Claude Code であることを識別するように変更（`surface=claude_code` デバイス認可パラメータと `claude-code/<version>` User-Agent）
- 管理者の管理設定を読み込めない場合、ホスト提供またはユーザーごとの Windows レジストリ設定が存在していても、組織のサインイン強制が起動時に終了するように変更
