- Claude Code がセッション内で書いた mod を有効にするか尋ねたときの回答の記録を追加
- Claude apps gateway の `mantle` upstream に `assume_role` を追加。別の AWS アカウントのロールや、開発者ごとの AWS コスト按分に使用できる
- mod の `$.model.fork` に `effort` オプションを追加。セッションの effort に関係なく、短いサイドジョブを `low` で実行できる。結果には送信した effort が含まれる
- 保存された claude.ai サインインの有効期限日を `claude auth status`（`loginExpiresAt`）と `claude -p` の JSON 結果（`credential_expires_at`）に追加
- 保存された claude.ai サインインの期限が切れる 10 日前から、`claude -p` のテキスト出力に stderr の 1 行警告を追加
- 不正な tool call のリトライが尽きた後に `--continue` が以前の会話を失うことがある問題を修正（2.1.314 のリグレッション）
- 多数の Bash コマンドが実行中の macOS セッションで、メモリが増加して停止する問題を修正
- メッセージ送信直後、または遅いプロンプトが表示される前に入力したキーで、権限プロンプトに回答されてしまう問題を修正
- 共有ネットワークのホームディレクトリで設定ファイルを更新できない場合に、`/logout`、`claude auth logout`、`claude mcp remove` が成功と報告したり、trust・consent・MCP 設定の変更が通知なく破棄されたりする問題を修正
- 同じホームで別のターミナルやホストが同じアカウント・組織に再サインインした際、ジョブが `Not logged in` で終了する問題を修正
- `claude mcp add` と `remove` がロックなしで設定を書き込んでいた問題を修正。ロックを待つか exit 1 で終了するようになった（ただし他のジョブの保存によって保存済みサーバーが置き換わる可能性は残る）
- 低速なトークン更新が保存される前に `claude plugin` コマンドが終了し、次回の実行でサインアウトされる可能性がある問題を修正
- `claude plugin marketplace add` が拒否するカスタム名の marketplace ファイルを `claude plugin validate` が通してしまう問題を修正
- バージョンプローブで終了する stdio MCP サーバーが起動のたびに再プローブされる問題を修正。独自の理由で 3 秒未満で終了したサーバーは、7 日間 legacy ハンドシェイクに固定される
- 同じマシンの別のログインが保存した `allowedProviders` リストによって、起動時にセッションが拒否される問題を修正
- アイドル時の compaction が、要約ではない返信で会話を置き換えてしまう問題を修正
- バックグラウンド subagent の実行中に「Now using usage credits」の通知が約 30 秒ごとに再表示される問題を修正
- 失敗するカスタムスラッシュコマンドや Claude のみが呼び出せるコマンドが、`claude -p` と SDK セッションで何も出力しない問題を修正
- mod が `turn.step` をフックしているとき、API エラーで返信が途切れても `claude -p` と Agent SDK セッションが成功を報告する問題を修正
- headless セッションで、モデル変更直後に送信したメッセージが Stop 後も実行され続ける問題を修正。Stop は待機中のメッセージと同様にキャンセルまたは停止する
- アイドル状態の非対話セッションが終了した際、削除済みのセッショントランスクリプトが最後のプロンプト付きで再作成される問題を修正
- 更新やバージョンクリーンアップで、まだ実行中のプロセスのバイナリが削除された後、`claude remote-control` ホスト、バックグラウンド daemon、self-hosted runner が新しいセッションを開始できない（`spawn ENOENT`）問題を修正
- 別のユーザーが所有する実行中の Claude Code プロセス（例: `sudo claude` で残ったもの）がバージョンクリーンアップで終了済みと扱われ、そのバイナリが削除される可能性がある問題を修正
- 接続に失敗した後も `/remote-control` がセッションを利用可能と表示する問題を修正
- リクエストが 404 で失敗したときに `/design revoke` が成功と報告する問題を修正
- self-hosted runner やクラウドセッションの再起動後に承認されたシェルコマンドが、指定されたフォルダではなくセッションの開始フォルダで実行される問題を修正。そのフォルダに入れない場合は実行されない
- クラウドセッションの再起動後、承認済みのコネクタツールが利用できないことが Claude に伝えられない問題を修正
- サービスが数分間アップロードを拒否した際に、クラウドセッションがターンの途中で停止される問題を修正
- `Setup` hook が `CLAUDE_ENV_FILE` に書き込んだ変数が、一部のクラウドセッションで Bash ツールに渡らない問題を修正
- tool call でレスポンスが途切れた後や、拒否された画像・ドキュメントが削除された後、クラウドセッションのターンが実行中にもかかわらず iPhone アプリで完了と表示される問題を修正
- 再起動したセッションが、API エラーで失敗したメッセージを、後ろで待機している新しいメッセージより先に再送する問題を修正
- 大きな画像の読み取り直後や tool call のリトライ直後に再起動すると、中断されたターンが失われる問題を修正
- `NODE_EXTRA_CA_CERTS` のファイルが空、PEM ではない、または先頭の証明書が破損している場合にすべての接続が失敗する問題を修正。読み取り可能な証明書が使用され、stderr に警告が表示される
- 使用量制限後に workflow を再開すると、完了済みの agent が再実行される問題を修正
- クラウドセッションの `/mcp` がモデルの使えないツールまで数えていた問題を修正。サーバーの行に利用可能なツール数が表示される

- 画像が 20 枚を超えるリクエストで画像が大きすぎる場合のエラーが、常に上限を 2000px と表示していた問題を修正。API の上限が表示される

- ネットワークホームディレクトリにデータ用の空きがなく新規ファイルのみ受け付ける場合に、保存済みログインが空ファイルで置き換えられる問題を修正

- バックアップのない空の `~/.claude.json` が破損と報告される問題を修正。ファイルがない場合と同様に起動する

- 保存済み claude.ai ログインが期限切れになった際のサインイン失敗について修正。その旨が表示され、`claude -p` では `claude auth login` と `claude setup-token` が案内される
