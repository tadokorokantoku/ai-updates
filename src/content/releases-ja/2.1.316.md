  - "Opus 4.8 の fast mode を非推奨化（Opus 5.5 へ移行）"
---

- `ultrathink` キーワードを無効にする `CLAUDE_CODE_DISABLE_ULTRATHINK` を追加
- Claude apps gateway にプールされたグループ予算を追加。各メンバー自身の上限に加えて、グループのメンバーが共有する月次予算を 1 つ設定できる。spend limits admin API の `pooled_budget` で設定する
- 互いに証明し合ってループしているシステムのクロス証明書を保持する `CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP` を追加。プライベート CA がそれを必要とするサーバー向け
- 他に指定がない場合に subagent が動作する effort レベルを、セッションのものを継承する代わりに設定できる `CLAUDE_CODE_SUBAGENT_EFFORT` を追加
- Claude apps gateway に `managed.policy_mode: layered` を追加。最初に一致したポリシーだけでなく、開発者に一致するすべてのポリシーが適用され、それぞれが下に列挙されたポリシーの上にマージされる
- Claude apps gateway の Bedrock upstream に `guardrail.input_tagging` を追加。Amazon Bedrock guardrail の prompt attacks フィルターが必要とする input タグでプロンプトを囲む。`all_messages_and_system` はシステムプロンプトにもタグを付ける
- 2026 年 10 月 30 日付で Opus 4.8 の fast mode を非推奨化。2026 年 11 月 30 日に削除される。削除後、Opus 4.8 での fast mode リクエストはエラーを返し、標準の Opus 4.8 にはフォールバックしない。高速化を維持するには Opus 5.5 に移行すること
- Claude Code が自ら終了した場合（認証情報が拒否された場合やクラウドセッションがアーカイブされた場合など）に、macOS と Linux でシェルコマンドが実行されたまま残る問題を修正
- Bash ツールのシェルで、値に改行を含む bash alias（Git Bash を除く）や、名前がダッシュで始まる関数が壊れたり失われたりする問題を修正
- `SHELLOPTS` が export されている場合に、Bash ツールから起動した bash スクリプトが最初のコマンドの後で止まる問題を修正
- コマンドが型キャスト、`param`、`using`、または属性で始まる場合に、PowerShell hook が終了コード 2 でブロックしない問題を修正
- 圧縮されたレスポンスが途中で切れたり破損したりした際に、一部のネットワークリクエストがハングする問題を修正
- Vertex AI と Amazon Bedrock で、アカウントやリージョンでまだ最新モデルが利用できない場合に、`sonnet`、`opus`、`haiku` が古いモデルへ切り替わらずセッション途中でエラーを表示する問題を修正
- Claude apps gateway が、リクエストで指定されたすべてのモデルを `availableModels`、`deniedModels`、`models` に照らして確認していなかった問題を修正。ブロックされたモデルを指定したリクエストは、該当フィールド名を示す 400 を返すように
- managed settings が Claude apps gateway を要求する環境で `claude auth login` の実行が拒否される問題を修正。ターミナルでは gateway のサインインが表示されるように
- Read の allow ルールが対象に含まれている場合に、`--restricted` セッションが作業ディレクトリ外のファイルをアップロードする問題を修正
- 不可視文字を含むプロンプトの送信に Enter が 2 回必要だった問題を修正。通常のプロンプトは最初の Enter でクリーンアップされて送信され、コマンドは引き続き確認を待つ
- 親 sub-agent のモデルを継承した sub-agent が、バックグラウンドジョブやメッセージで起こされた際にメインモデルへ移ってしまう問題を修正
- `"$defaults"` を含まない managed の `autoMode.allow` リストが、ホストアプリの `--settings`、`/permissions` で追加した最初のルール、または `/auto-mode-setup` によって組み込みの例外を取り戻してしまう問題を修正
- サーバーが安全性の判定を返さなかったために auto mode がターンを停止した場合に、クラウドセッションとクラウドのスケジュールタスクが失敗としてマークされない問題を修正
- バックグラウンド agent がまだ実行中のときに、auto mode がターンを停止した理由が `claude -p` のテキスト出力に示されないことがある問題を修正
- 実験的 beta を無効にしたプロキシや LLM gateway の背後で、ホストアプリケーション（Claude Desktop など）が起動したセッションにおいて `CLAUDE_CODE_AUTO_MODE_SERVER=1` が無視される問題を修正
- 認証情報風の名前の環境変数が `1` のようなスイッチ値に設定されている場合に、plugin MCP の `headersHelper` スクリプトが破損した `CLAUDE_PLUGIN_ROOT` とサーバー URL を受け取る問題を修正
- SDK の `register_repo_root` control request が、作業ディレクトリ外のディレクトリの CLAUDE.md を読み込まない問題を修正（`CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1` 使用時）
- Artifact ツールが `self` レベルの artifact データベースアクセスルールを `?` と表示し、それらのルールが失われる再公開を拒否する際にも引用しない問題を修正
- `/model <id>` で、このバージョンが認識しないモデルを指定し auto-compact が 200K コンテキストウィンドウを前提とする場合に警告が出ない問題を修正
- "hold space to speak" のヒントが 1 セッションで 3 回分の表示を使い切ってしまう問題と、push-to-talk が未割り当てのときに空のキーを表示する問題を修正
- タイムアウト時に検索プロセスが kill されても終了しない場合に、Grep と Glob が返らなくなる問題を修正（Windows で確認）
- 会話の一部がまだ保存されている最中に `/clear` や `/resume` を実行した場合に、会話の再開時にプランが復元されないまれなケースを修正
- 幅の狭いターミナルで、初回セットアップがセキュリティに関する注意書きとターミナル設定の説明の単語を欠落させる問題を修正
- Enterprise アンケートカードが、1 または 0 を入力して少し待つと回答として受け付けてしまう問題を修正。入力した回答には Enter が必要に
- セルフホスト runner: セッションのプロセスが置き換えられた後、Claude の作業中に送信したメッセージが Stop の後に応答される問題を修正
- セルフホスト runner: セッションが新しいマシンに移った際に、MCP サーバーのオン/オフ切り替えが失われることがある問題を修正
- Windows: rc ファイルが errexit と pipefail を設定し、winpty alias のみ、または alias が未定義の場合に、Git Bash で Bash ツールが alias と関数を失う問題を修正
- Claude Desktop の Code タブまたは web から開始した `/code-review` を改善。クラウドおよび `claude remote-control` セッションで、プレーンテキストのリストではなく findings カードが表示されるように
- 大規模リポジトリでの `/diff` を改善。通常、更新のたびに実行されるリポジトリ全体の git コマンドが 1 つ減り、git が遅い場合は更新の間隔が空けられる
- `/ultrareview`、クラウドセッション、クラウド agent が GitHub remote を見つけられない場合のメッセージを改善。https://github.com/new でリポジトリを作成するよう案内し、`/ultrareview` は `gh` が拒否するコマンドを提案しなくなった
- SSL 証明書エラーで、中間証明書を省略しているサーバーなど考えられる原因と、それぞれの対処法を示すように改善
- auto mode を変更：`"$defaults"` を含まない `autoMode.allow` リストが、スケジュールタスクのプロンプトに関する組み込みルールを削除しなくなった
- Team および Enterprise ログインの server-managed settings を変更：Anthropic の API から取得した設定は承認プロンプトなしで適用され、検証に通らない保存済みコピーは拒否される
- [VSCode] チャットパネルから Claude apps gateway にサインインできるように。ターミナルは不要
- [VSCode] `ultrathink` を、ターミナルと同様に `xhigh` effort でターンを実行し、チャットボックスで虹色に表示するよう変更
- [VSCode] モデル設定に `opus[1m]` のように `[1m]` タグが付いている場合に、Effort スライダー、Ultracode スイッチ、モデル名が表示されない問題を修正
- [VSCode] 設定ファイルにエラーがある間、保存済みの `/btw` サイドクエスチョン履歴が早すぎるタイミングで削除される問題を修正
- [VSCode] 「Yes, and manually approve edits」でプランを承認した会話が、リロードや再起動後に Auto mode で復帰する問題を修正
- [Cloud sessions] クラウドセッションにフォームカードを追加。MCP サーバーが求めるフォームを、気付かないうちにリクエストがキャンセルされるのではなく、入力または辞退できる
- [Cloud sessions] 切り替えて戻ったクラウドまたは Remote Control セッションがメッセージを最新状態に更新している間、"Catching up…" の行を表示するように
- [Cloud sessions] network secrets を変更：Enterprise メンバーが自分のクラウド環境で、表示だけでなく追加と削除もできるように
- [Cloud sessions] クラウドセッションの Changes ペインを改善。リストが省略している内容についての注記が、diff の上の行ではなくブランチ名の横のバッジになった
- [Cloud sessions] Claude がディレクトリを変更した後、クラウドセッションの Files ペインでのファイル検索がフォルダを ../.. パスで表示する問題を修正。結果はプロジェクトルートからのパスで表示される
- [Claude Tag] Slack チャンネルで作成した canvas が別のチャンネルや DM にも共有された後、そのチャンネルから Claude がその canvas の編集や追記を拒否する問題を修正
- [Claude Tag] 両方の組織が Claude をインストールしており、Slack が返信をもう一方の組織のアプリに配信した場合に、Slack Connect スレッドでタグなしの返信に応答がない問題を修正
- [Claude Tag] Slack でのクラウドスケジュールタスクのライブステータスチェックリストが中途半端な状態のままになる問題を修正。実行中に投稿したトップレベルのメッセージを、その実行で編集できるように
- [Claude Tag] Slack チャンネルの Respond automatically スイッチを、チャンネルの Configure ページと Claude Tag 管理設定の "How Claude participates" の選択肢に変更
- [Code Review] Code Review の analytics ページに severity 別 findings カードを追加。期間内の findings の合計、severity ごとに積み上げた日次チャート、各 severity の件数を表示する
