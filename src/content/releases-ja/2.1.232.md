- Subagent forking がデフォルトで有効に: `subagent_type: "fork"` のサブエージェントは会話全体と prompt cache を継承するようになり、対話セッションでの teammate 以外の agent 起動はデフォルトでバックグラウンド実行されるようになった
- プロンプト内で `@` を入力すると名前で他の Claude セッションをメンションできる。Claude はそのセッションに `SendMessage` で直接到達する
- `SendMessage` は、1つのライブセッションと完全一致するベア名前に対して、ref での確認を求めることなく直接配信するようになった
- 同一マシン上の対話セッションが一意な名前を維持するようになった: 別のライブセッションが既に使っている名前でセッションを開始・リネームすると `name-word-word` のバリアントが割り当てられ、その旨が通知される
- `/config` に「Dialog expiry」と「Messages from your other sessions」（クロスセッションの受信を accept/hold/refuse）の行を追加
- GitLab のトークンファミリー（`glrt-`、`gloas-`、`glptt-`、`glagent-`、`glimt-`、`glsoat-`、`glcbt-`、`glft-`、`glffct-`）のシークレットredaction を追加し、ルーティング可能な `glpat-`/`gldt-` トークンは完全に redaction されるように。`glab` CLI の設定ストアも `gh` と同じサンドボックスおよび認証情報パスの保護を受けるようになった
- プラグインマーケットプレイスに GitLab サポートを追加: ベアな `gitlab.com` リポジトリURL（ネストしたサブグループを含む）が `github.com` の URL と同様に clone できるようになり、clone 認証失敗時のヒントが実際の git ホスト名を表示するようになった
- 設定: `additionalMarketplaces` と `allowedMarketplaces` が、`extraKnownMarketplaces` と `strictKnownMarketplaces` のよりわかりやすいエイリアスとして受け付けられるようになった
- エンタープライズポリシー: ベアなリポジトリURLに対する url 型の `blockedMarketplaces` エントリが、CLI がそれを git clone として分類した場合もそのURLをブロックし続けるようになった
- Gateway: `desktop:` オーバーレイが、これまでの手書きの11個のキーだけでなく、リリース済みの Desktop 設定すべてを受け付けるようになり、Desktop 自身のスキーマに対して起動時に検証される。未知または不正なキーは起動を失敗させる
- Gateway: `managed.policies[].match.groups`/`admin.admin_groups` の空エントリや、不正な `email_domain` の値（空、または `@`・空白・カンマを含む）が、誰にもマッチしない・誰にでも管理者権限を付与するといった黙った動作ではなく、起動時に失敗するようになった
- Fable 5 access を持つ組織向けに、`/advisor` で Fable 5 が再びアドバイザーとして提供されるようになった。利用クレジットの同意は `/model fable` から設定
- 変数を書き込むパラメータが `$PSDefaultParameterValues` を黙って上書きし、後続コマンドのファイルアクセスをリダイレクトできてしまう PowerShell の権限バイパスを修正
- パス検証が通常ファイルとして扱っていた Cygwin 形式のシンボリックリンクを Git Bash が辿ってしまう Windows の権限バイパスを修正。そのようなリンク経由の書き込みには権限の承認が必要になった
- ネストした git リポジトリが親ディレクトリから trust を継承してしまう問題を修正。各リポジトリごとに個別の trust 確認が必要になった
- サーバーが応答しない、またはプロトコルバージョンのプローブに不正な形式の応答を返した際に、MCP 接続が30秒のconnectタイムアウトいっぱいハングしていた問題を修正
- クラウドセッション内の bridge がホストする Remote Control セッションが、そのセッションのトランスクリプトや認証情報を継承してしまっていた問題を修正
- Claude Desktop や IDE から開始した Remote Control セッションが、ローカルセッションを再開するたびに新しい claude.ai セッションとして表示されていた問題を修正。既存のセッションに再アタッチするようになった
- アイドル中の Remote Control セッションが、新しく接続したクライアントから到達不能に見えていた問題を修正
- session worker の再起動時に、Remote Control の bridge セッションが会話履歴を復元していなかった問題を修正
- Remote Control: claude.ai またはアプリからセッションが削除された会話を再開する際、ログインに関するエラーメッセージで失敗する代わりに、代替セッションを開始するようになった（v2.1.227 で発生した regression）
- managed settings の読み込みに失敗した際、「Press Enter to continue」の後に Cloud gateway の `/login` が無言で終了したり、応答しないターミナルが残ったりしていた問題を修正。理由が表示されるようになった
- voice service が接続を拒否した際に、ネイティブビルドの voice mode が「listening…」のまま止まってしまう問題を修正。拒否が即座に表示されるようになった
- mTLS のクライアント証明書のローテーションに再起動が必要だった問題を修正。接続エラー時にローテーションされた証明書と鍵を Claude Code が自動的に再読み込みするようになった
- 不正な形式の AWS または Vertex のリージョン値がリクエストURLの構築に使われていた問題を修正。デフォルトリージョンにフォールバックするようになった
- Bedrock、Vertex、gateway デプロイで、stream idle timeout エラーがリクエストを失敗させていた問題を修正。復旧できるようになった
- 切り詰められたテキストを含むコンテンツサイズのオーバーレイが1列分広く描画されてしまう問題と、先頭が切り詰められたテキストが省略記号だけに潰れてしまう問題を修正
- 長いシェルコマンドや agent の説明プレビューが絵文字の途中で切れて文字化けする問題を修正
- `known_marketplaces.json` への同時書き込みによって、プラグインマーケットプレイスが黙って登録解除されてしまうことがあった起動時のレースコンディションを修正
- リロード後も残り続ける作業が実行中の間、`/update` と `/tui` が再起動を拒否していた問題を修正
- SDK およびリモートセッションで、usage-limit のガイダンスが利用できないスラッシュコマンドを提案していた問題を修正
- 対話的な `--advisor fable` 起動時の同意メッセージが、終了したばかりの対話セッションで `/model fable` を実行するよう案内していた問題を修正
- フルスクリーンストリーミングを改善: 更新のたびに会話全体を再正規化しなくなったことで、長いセッションでも応答性が保たれるようになった
- managed settings の承認ダイアログを改善: エンドポイントURLを表示し、telemetry のみの変更に対してよりわかりやすい文言を使用し、通常の OpenTelemetry オプションをスキップし、サーバー管理のサンドボックスバイナリのオーバーライド（`sandbox.bwrapPath`、`sandbox.socatPath`、`sandbox.ripgrep`）には承認を必須とするようになった
- `/feedback` と `/bug` が、Claude が応答中に呼び出された場合でもターンの終了を待たずに即座に開くようになった
- `/plugin install plugin@marketplace` がまずマーケットプレイスを更新するようになり、新しく公開されたプラグインを手動のマーケットプレイス更新なしにインストールできるようになった
- `/code-review` の high、xhigh、max effort が、他のレベルと同様にバックグラウンドエージェントで実行されるようになった
- 貼り付けた画像やクリップボードの画像が、イベントループをブロックせずに読み込まれるようになった
- Remote Control が、ネットワークの瞬断後も約30分間再接続を試み続けるようになり、1時間の間に複数回瞬断しても切断されなくなった
- Remote Control: 会話の再開が、同じマシン上でまだ Remote Control を持っている別の Claude Code から黙ってそれを奪わなくなった。奪う場合はそちらで `/remote-control` を実行すること
- エージェントパネルを更新: 完了したサブエージェントは `/tasks` のフッターヒントとともに即座に非表示になり、「↓ N more」のオーバーフローインジケーターが視認性のため左に移動した
- Remote Control: ターミナルに、セッションが別のデバイスに引き継がれた、別のアプリから終了された、削除された、のいずれかが表示されるようになり、それを取り消してしまう再接続の提案が行われなくなった
- Bash の入力リダイレクト（`< file`）が、すべてのプラットフォームで引数形式の指定と同様に権限チェックされるようになった
- 完了したバックグラウンドエージェントを再開する際のメッセージを短縮
- Cowork セッションが、ユーザースコープのメモリファイルからの外部 @-import をインライン展開しなくなった
- 共有 `/tmp` 上に自動生成されるクロスセッションメッセージング用ソケットディレクトリを強化: 事前に仕込まれたシンボリックリンクや他ユーザーのディレクトリが、使用される代わりに拒否されるようになった
- Linux のファイルシステムサンドボックスを、保護対象パスのバイパスに対して強化
- `sandbox.ripgrep` が user、managed、`--settings` の設定からのみ有効になるよう変更。プロジェクト設定でサンドボックスの ripgrep バイナリを上書きできなくなった
- カスタムサブエージェントの作成を勧めるスタートアップのヒントと、`/powerup` ツアー内の対応するアクションを削除
