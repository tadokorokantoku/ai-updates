- `sandbox.allowNestedUserNamespaces` を追加: Linux のサンドボックス内コマンドが user namespace を作成できる（Chromium、rootless podman）。サンドボックスのファイル保護を回避できるようになる
- `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS` を追加: 無人リトライモード（`CLAUDE_CODE_RETRY_WATCHDOG`）が、リセット前に解除された使用上限を検知できる
- エンドポイントまたはゲートウェイが tool search を拒否する場合や、ゲートウェイで ToolSearch が禁止されている／`--tools` から除外されている場合に、Vertex、Bedrock などでリクエストがすべて失敗する問題を修正（2.1.304 のリグレッション）: tool search なしで再試行するようになった
- モデル名が `modelOverrides` の値と大文字小文字または `[1m]` タグだけ異なる場合に、`/effort` と `/autocompact` の設定が適用されない問題を修正
- bare リポジトリの新しい worktree がデフォルトブランチではなくローカルの HEAD から始まることがある問題と、変更のない subagent の worktree が削除されないことがある問題を修正
- ディスクフル時に Bash コマンドが生の `ENOSPC` ファイルパスで失敗する問題を修正: ディスクが満杯であることと、何も実行されていないことを伝えるエラーになった
- クラウドセッションまたは SDK の `setMcpServers` で渡された MCP サーバーが、後からあなたの設定にある同名のサーバーに置き換えられる問題を修正
- subagent がフォールバックモデルに切り替わった後、Claude が subagent の作業に対して誤ったモデル名を答える問題を修正
- コンパクション時に要約に収めるため最も古いメッセージを除外した場合に、クラウドセッションとチームメイトが Claude にそれを伝えていなかった問題を修正
- スケジュールされた Cowork クラウドセッションで、WebFetch が誰も承認できない URL 承認を必要とする subagent ごとに 5 分待たされるケースをさらに修正
- Workflow の resume が、完了済みの `pipeline()` と `parallel()` のエージェントを実行のジャーナルから復元せず再実行する問題を修正
- `/resume` で会話を切り替えた後、Remote Control が `/resume` に空の「(session)」エントリを残す問題を修正
- 狭いターミナルで `/usage` の行が切れる問題を修正
- 起動時の警告がロゴの上に生テキストとして表示される問題を修正: デバッグログに出力されるようになり、何も制限しない権限ルールはバナー下に警告行として表示される
- スクリーンリーダーモードを修正: 検索ボックスが VoiceOver で「telephone recorder」と読まれる記号ではなく「Search:」と読まれるようになり、Ctrl+R の検索一致や「ultrathink」など強調表示されたプロンプトテキストの単語内に空白が入らなくなった
- Self-hosted runner: stdout のみを runner または orchestrator と共有する start script が、`TERM` 設定時に `Resource temporarily unavailable` で失敗する問題を修正（2.1.300 のリグレッション）
- Self-hosted runner: git credential helper または askpass プログラムが `GIT_CONFIG` 経由で設定を読む場合に、2.1.296 以降リポジトリアクセスが失敗する問題を修正
- Self-hosted runner: バックグラウンドで起動した runner が出力を開いたままにすると、orchestrator が spawn-runner hook をタイムアウトと報告する問題を修正
- `/usage` を改善: 各警告が出所を示す 1 行の修正案になり、`f` で修正を適用できる。同じ修正案は VS Code と `/doctor` にも表示される
- MCP 同意ダイアログを改善: プロンプト向けの Enter が Accept として受け取られにくくなった
- mod の `Image` が、全画面レンダリングの iTerm2 3.5 以降で画像を描画するよう改善（以前は `alt` テキストのみ表示）
- Remote Control: spawn モードのメッセージを改善: `w` を押すと新しいモードがフォルダに保存されると表示され、保存済みモードを使った後続の `claude remote-control` 起動ではその取得元が表示される
- `allowedMcpServers` が、`env` のみで `${VAR}` を使う `managed-mcp.json` の stdio サーバーをフィルタしないよう変更: 許可リストに無かったサーバーもアップグレード時に読み込まれる。無効にしておくには `deniedMcpServers` を使用
- Claude Desktop がパスでマウントした plugin は、組織の managed settings で `allowManagedPermissionRulesOnly` が設定されている場合、`allowed-tools` を保持しないよう変更
- `/artifacts` の削除確認を変更: 1 または Enter で保持、2 で削除、Esc でキャンセル。`y` と `n` では応答できなくなった
- mod のドッキングペインを、より広いターミナルから引き継いだ幅も含め、ターミナル幅の 45% 以内に収めるよう変更
- [VSCode] SessionStart または Setup hook の実行中に「Running start-up hooks」スピナー状態を表示（スクリーンリーダーのアナウンス付き）
- [VSCode] `spinnerVerbs` 設定で組み込みの動詞が短いものに置き換えられたとき、スピナーが「Compacting...」を切り詰める問題を修正
- [VSCode] セッションが時間内に開始せず hook も実行中でない場合のメッセージを変更: サインインやネットワークではなく出力ログを先に示し、原因を一覧表示する
- [Cloud sessions] Cloud environments 管理ページが、既存の環境を「installs packages」エラーで誤って保存拒否する問題を修正
- [Cloud sessions] self-hosted 環境の削除を改善: ダイアログとエラーメッセージが、削除を妨げているものと影響範囲を示すようになった
- [Claude Tag] Claude が参加していない公開 Slack チャンネルを Claude Tag 管理の Add 場所検索に追加し、管理者がそこからセットアップできるようにした
- [Claude Tag] 別の GitHub アカウントに移動したリポジトリを Claude Tag のアクセスバンドルに再度追加できるよう修正
- [Claude Tag] Slack DM スレッドで設定した routine が、同じスレッドの別の routine が会話を再開した後に投稿しなくなる問題を修正。どちらも投稿を続ける
- [Claude Tag] Slack スレッドで設定した routine が、会話終了後に投稿せず成功と報告する問題を修正: 該当の実行はスキップされ、作成者に通知される
- [Claude Tag] 大規模な組織で、チャンネル一覧の読み込み中でも plugin、skill、bundle の編集ができるよう Claude Tag 管理ページを改善
- [Code Review] レビュー中に複数のプッシュが pull request に入った際、Code Review が最新のコミットをレビューしないことがある問題を修正
- [Code Review] Code Review の再レビューが、以前のブロッキング指摘が未解決のまま LGTM で始まらないよう変更
