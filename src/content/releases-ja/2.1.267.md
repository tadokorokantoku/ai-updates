- `maxEffortLevel` 設定を追加(トップレベル、または `modelSettings` 配下でモデルごとに指定可能): Bedrock、Vertex、Foundry を含むすべてのプロバイダーでエフォートレベルの上限を設定できる。ユーザーはそれより低いレベルを選ぶことは引き続き可能
- `--system-prompt-snapshot off` を追加: 会話に記録済みのシステムプロンプトを再利用せず、リクエストのたびにシステムプロンプトを新規にレンダリングする(プロンプト文言を試行錯誤する用途向け)
- サンドボックスを要求する管理設定を持つ組織で、クラウド上の Cowork のスケジュールタスクが起動時に失敗していた問題を修正
- モバイルクライアントで `/context` などのローカルコマンドの出力が空白でレンダリングされていた問題を修正
- エージェントビュー内で tmux や ssh セッションに再接続した後、shift+enter と option+backspace が機能しなくなっていた問題を修正
- フルスクリーンモードで上にスクロールしたときに、会話の先頭に薄く表示される last-prompt ヘッダーが表示されない問題を修正
- 出力スキーマが大きい Workflow の `agent()` 呼び出しが、安全性分類器によるチェックではなく auto モードで拒否されていた問題を修正
- バックスラッシュを含むマーケットプレイスエントリのパスが、macOS と Linux で取得済みマーケットプレイスのコンテインメントチェックを回避できてしまう問題を修正
- Claude Desktop などのホストアプリ配下で AWS または Google Cloud の認証情報が期限切れの場合、再認証エラーが表示される前に汎用的な「request failed」で10回リトライしていた問題を修正
- `-p --resume` 経由で `/compact` や他のスラッシュコマンドを実行した後にセッションを再開する際、「Continue from where you left off.」という余分なターンが挿入されなくなるよう修正
- 大きなセッション(トランスクリプトが 5MB 超)を再開する際、並列ツール呼び出しとその hook 出力が再読み込みされた会話から失われていた問題を修正
- 管理設定の `allowedHttpHookUrls`、`httpHookAllowedEnvVars`、`allowedChannelPlugins` が読み取れない場合に、すべて許可ではなく何も許可しないよう修正
- Claude apps gateway サインインを要求する管理設定のマシンで、`/login` の Esc キーがダイアログを閉じずに何もしなかった問題を修正
- アップロード中に接続が切れてアーティファクトの公開が中断された場合、アップロードが完了していないと判定できるときは不明な結果として報告する代わりに1回リトライするよう修正
- デフォルトのエフォートが固定されているモデル(Opus 4.7、Opus 4.8、Fable 5)で、カスタムコマンド・スキル・サブエージェントの `effort:` frontmatter が無視されていた問題を修正
- ページファイルが有効な UTF-8 でない、または置換文字(U+FFFD)を含む場合にアーティファクト公開が分かりにくいエラーで失敗していた問題を修正。エラーに修正すべき行と列が表示されるようになった
- `claude agents` の `@` ディレクトリメニューが、セッション開始後に作成されたリポジトリを一覧に表示しない問題を修正
- Claude Desktop や VS Code のセッションに参加する Remote Control クライアントで、パーミッションモードが再度変更されるまで古い表示のままだった問題を修正
- サーバー資格情報の期限切れ(起動から約30日後)時に `claude remote-control` が終了し、接続済みのすべてのセッションが切断されていた問題を修正。ホストが再登録して継続するようになった
- 異なるモデルやモードのリクエストが異なる制限ウィンドウを報告する場合に、使用量上限の警告がセッション中に点滅していた問題を修正
- MCP サーバーがツールを再送信したとき、または組み込みツールがモデルが既に読み込んだツールを再レンダリングしたときに、それ以前の reasoning が失われていた問題を修正
- 切断された MCP サーバーやアップグレードにより会話の途中でツールが消えた際に、ツールリストが書き換えられそれまでの thinking が破棄されていた問題を修正
- 会話からフォークされたバックグラウンドワーカーが、セッション途中で会話のツールブロックに EnterWorktree を追加し、プロンプトキャッシュの再利用を壊していた問題を修正
- ToolSearch のないセッションでセッション途中に MCP・プラグインツールがツールリストに追加され、プロンプトキャッシュの再利用が壊れていた問題を修正。対応モデルでは今後 deferred な定義として受け取るようになった
- /model でのモデル切り替え時にすべてのツール定義が再送信されていた(プロンプトキャッシュミス)問題を修正。コミットや PR の attribution テキストは、モデル変更時に更新される会話ノートとして届くようになった
- MCP コネクタが以前とは異なるタイミングで再接続した際に、再開されたセッションでインラインのツールセットが書き換えられていた問題を修正
- 最初のターンでツールを実行していた場合、再開されたセッションで記録済みのツール説明を再生する代わりに再レンダリングしていた問題を修正
- claude.ai コネクタのツールがセッションと再開の間で変化した際に、プロンプトキャッシュミスと extended thinking の消失が発生していた問題を修正
- 再開されたセッションで、コネクタが再接続する前に以前の MCP ツールのアナウンスが書き換えられ(extended thinking も失われて)いた問題を修正
- print モード(`-p`)の会話をインタラクティブに再開した際にプロンプトキャッシュが壊れていた問題を修正。システムプロンプトの prefix が変化しなくなった
- `/diff` パネルを改善: 落ち着く前に「0 files changed」とスピナーが一瞬表示される問題がなくなり、空の状態がパネル中央に表示されるようになった
- Bash ツールの説明ガイダンスを改善: コマンドをそのままエコーするのではなく、平易な言葉で何をするコマンドかを説明するようになった
- サンドボックスのガイダンスを改善: `pbcopy` などのクリップボードコマンドがサンドボックス内で失敗した場合に `/copy` を提案するようになった
- Bash ツール呼び出しが多いセッションでの `--resume` の初回レンダリング時間を改善
- プロンプト入力の応答性を改善: スピナーやストリーミングの再描画にキー入力が1フレーム遅れることがなくなった
- プロンプトキャッシュの安定性を改善: サブエージェントおよび `--system-prompt` や `--append-system-prompt` で開始されたセッションが、システムプロンプトとツール定義を再レンダリングするのではなく一度だけ記録するようになった
- Artifact ツールの公開エラーを改善: 公開が拒否された場合、理由と対処法がメッセージに表示されるようになった
- セルフホストランナー: `--use-anthropic-git-proxy` を登録時にサーバーへ報告するように変更し、レガシーな git プロキシ経由でクローンし続けるセッションごとに警告を表示するよう変更
- ゲートウェイ: `forward_user_identity` のアップストリームが、メールが転送された開発者に対して 429 をそのまま返すよう変更(以前は次のアップストリームにフェイルオーバーしていた)。これによりプロキシのユーザーごとの制限が維持される
- [VSCode] 保存済みトランスクリプトに循環した parent リンクが含まれる会話でフォーク・過去メッセージの編集・巻き戻しを行った際に、拡張機能ホストが CPU 使用率 100% でハングしていた問題を修正
- [VSCode] WSL2/WSLg でスクリーンショットを貼り付けると、チャット入力に生の画像バイト列が挿入されていた問題を修正。クリップボードが画像を提供する場合は添付され、それ以外の場合は貼り付けが無視されるようになった
- [VSCode] チャットの diff ブロックが常にダークエディタテーマでレンダリングされていた問題を修正。ハイコントラストを含む、有効な VS Code カラーテーマに従うようになった
- [VSCode] メッセージ入力欄で入力中に右から左書きの文字と英語のテキストが混在すると順序が誤って表示される問題を修正
- [VSCode] Windows (CRLF) の改行コードのファイルで diff ビューの編集を承認すると「String not found in file」で失敗する問題を修正
- [VSCode] スペースを含むパスのファイルが @-mention で欠落する問題を修正
- [VSCode] ワークスペースフォルダがリモートホストにのみ存在する Remote-SSH 接続のウィンドウで、セッション一覧ビューの読み込みが失敗する問題を修正
- [VSCode] 大きい、またはシンボリックリンクの多いワークスペースでファイルを表示した際に暴走する ripgrep プロセスを修正
- [Claude Code on the web] GitHub Enterprise Server セッションで、トークンが期限切れになると GitHub アカウントが未接続と表示されていた問題を修正。PR・issue 操作でトークンが自動的に更新されるようになった
- [Claude Code on the web] Claude GitHub App のない組織で `gh` コマンドや GitHub API 呼び出しが失敗していた問題を修正。接続済みの GitHub アカウントを使用するようになり、未接続の場合はその旨を表示するようになった
- [Claude Tag] Claude Tag の管理設定にあるプリセット接続フォームに「Use a custom connector」リンクを追加。最初からやり直すことなくカスタム接続に切り替えられる
- [Claude Tag] 組織の使用量クレジットが尽きた場合に Claude が「The API rejected the request as invalid」と返信していた問題を修正。クレジット切れであることと、追加方法を説明する返信になった
- [Claude Tag] Claude がチャンネルのトップレベルに投稿したメッセージの編集・削除をスレッドから要求された際、投稿元のセッションに届かず訂正メッセージで応答していた問題を修正
- [Claude Tag] Admin settings > Review requests の Tool access requests で **Connect** が「Authorization failed」で失敗する、または要求されたアクセスバンドルが削除済みと表示される問題を修正
