- `ANTHROPIC_DEFAULT_MODEL` 環境変数を追加: 新しいセッションが開始時に使うモデルを設定できる。`/model` での選択は引き続きそれを上書きし、再起動後も保持される（`ANTHROPIC_MODEL` とは異なる挙動）
- クロスセッションの `SendMessage` に `notify_when_idle` を追加: 同じマシン上の別の Claude Code セッションに、次にアイドルになった時に一度だけ通知するよう依頼できる（オプトイン・単発・ポーリングなし、macOS と Linux 対応）
- サンドボックス: macOS で、ワイルドカードの読み取り拒否ルール（例: `**/.env`）が許可された読み取り領域の内側でも優先されるようになり、一致したディレクトリの中身も対象になり、拒否されたファイルをリネームして回避することもできなくなった
- セッションが切り替えていたディレクトリが削除された後、クリップボードへのコピー、バックグラウンドのハウスキーピング、バックグラウンドセッション、ローカル MCP ログが壊れていた問題を修正（2.1.229 から発生）
- フルスクリーンレンダラーが一度起動に失敗すると恒久的に失敗し続けていた問題を修正: 以降のすべての起動で終了する代わりに、クラシックレンダラーにフォールバックするようになった
- `/model` ピッカーがターミナルより高く描画されていた問題を修正: ウィンドウに収まる数のモデルのみ表示し、残りはスクロールで到達できるようになった
- 閉じタグの不整合によりメッセージ本文が summary フィールド内に残った場合に `SendMessage` の呼び出しが拒否されていた問題を修正
- サブプロセスの起動に失敗した際（例: Windows interop が無効な WSL 上の `powershell.exe`）に発生していた未処理の Promise rejection を修正（2.1.234 でのリグレッション）
- フルスクリーンモードで、ターミナルのリサイズ後、次の更新まで新しく送信したメッセージが表示されないことがあった問題を修正
- フルスクリーンモードで、複数行プロンプトをクリアした後にプロンプト上部に空白の帯が残ることがあった問題と、ターミナルを別サイズにしてから元に戻した際にペインが再描画されない問題を修正
- managed-settings の承認プロンプトが起動時に表示されないことがありながら、最初のキー入力を承認として捉えてしまっていた問題を修正
- tmux（iTerm の tmux 統合）でターミナルのタブタイトルが揺れていた問題を修正: タイトルはテキストが変化した時のみ書き込まれるようになり、960ms ごとにアニメーションすることがなくなった
- クラウド環境一覧が空または不正な形式で返ってきた際の分かりにくいエラーを修正
- Remote Control 使用時、Fable 5 の初回利用クレジットプロンプトが 60 秒間応答がないとフォールバックモデルを自動選択していた問題を修正
- `~/.claude.json` にキャッシュされた guest-pass 報酬が不正な形式だった場合、スピナーのヒントが一切表示されずバックグラウンドエラーが繰り返し発生していた問題を修正
- SDK/VS Code セッションでのスキルのホットリロードが、セッションの作業ディレクトリが削除された後、スキル変更のたびにエラーを発生させていた問題を修正（2.1.229 以降）
- アイドル・retire・起動タイムアウトで解放されたセルフホストランナーのセッションが、post-session フックの完了前に別のランナー上で再開してしまうことがあった問題を修正
- Clawd マスコットの目と足が、一部のフォントサイズの iTerm2 で不均一に描画されていた問題を修正
- 稀に発生していたセッションリキャップの暴走を修正: リキャップテキスト（自動および `/recap`）は 400 文字を上限とし、単語の境界で切り詰められるようになった
- 起動パフォーマンスを改善: セッションカウンターがバックグラウンドで書き込まれるようになった
- auto mode を改善: auto mode が有効な間は `Monitor` の allow ルールが一時的に無視され、Monitor コマンドも Bash コマンドと同様にレビューされるようになった
- Bedrock、Vertex AI、Foundry 使用時、およびテレメトリが無効な場合の auto mode を改善: 分類器が Claude API と同じデフォルト（重大度スコア付き分類を含む）を使用するようになった
- auto mode を改善: git status のチェックが、リポジトリの `status.showUntrackedFiles=no` 設定によってクリーンなツリーだと誤認識させられなくなった
- `/model` ピッカーを変更し、最新モデルの名前のみをハイライトするようにした。これにより、任意の一部ではなく新しいリリースをハイライトが示すようになった
- `/goal`: 長時間実行のバックグラウンド作業の裏で目標が止まっているアイドルセッションが、戻ってくるのを待つ代わりに 30 分後（その後 1 時間後、2 時間後）に自動的にチェックインするようになった
- `/usage` が Team・Enterprise メンバー向けに usage-credits の消費行を表示するようになり、何も消費していない場合は 0% で上限表示されるようになった
- print/SDK モードでの SIGTERM が、終了前に中断されたターンや合成の tool denial を記録しなくなった。実行中のコマンドは引き続き終了され、プロセスも終了コード 143 で終了する
- スラッシュコマンドのタイプミスやこのセッションで利用できないコマンドで Enter を押した際、最も近いあいまい一致を実行する代わりに報告するようになった。プレフィックスとエイリアスは引き続き実行される
- Remote Control が、CLI が終了するかターミナルが閉じられてから数秒以内にセッションをオフラインとしてマークするようになった
- `SendMessage` が、急激なメッセージのバーストがセッションの受信可能量を超える場合、送信済みと報告しつつ実際には破棄する代わりに、事前にそれ以降のメッセージを拒否するようになった
- プロンプト境界のセッションタイトルチップをフッターの右端と揃えた
- 右寄せのフッター項目（goal インジケーター、セッション状態、バックグラウンドエージェントの状態）と切り詰め通知が、プロンプト領域の他の要素と一貫した右マージンを共有するようになった
- [VSCode] トランスクリプトにスクリーンリーダー対応を追加: 返信・権限リクエスト・エラー・状態変化のライブ通知、およびターンごとの見出しナビゲーション
