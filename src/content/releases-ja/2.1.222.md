- worktree で分離されたセッションとその subagent が、メインのチェックアウトに対して破壊的な git コマンドを実行できてしまう不具合を修正。分離はすべてのセッション種別でファイル編集と Bash に適用されるように
- バックグラウンドエージェントタスク（サマリー、compaction、リネーム）で `PreToolUse` の auto-allow hook が tool の制限をバイパスしていた不具合を修正
- Team および Enterprise で、以前の使用クレジット申請が却下されたメンバーに対して `/usage-credits` が「すでに使用クレジットのリクエストを送信済みです」と表示し、新規リクエストの送信をブロックしていた不具合を修正
- HTTPS プロキシ経由で起動時の接続確認がハングした後に失敗していた不具合を修正。API リクエストと同じプロキシ対応のトランスポートを使用し、タイムアウト時に明確なメッセージを表示するように
- 実際には完了していたレスポンスに対して "Connection closed mid-response" エラーが報告されていた不具合を修正
- `/usage` が MCP サーバーの使用量を過大に帰属させていた不具合を修正: サーバーへの呼び出し以降のすべてのターンではなく、実際にそのサーバーの tool 結果を消費したリクエストのみがそのサーバーの割合に反映されるように
- ブランチが push された後に作成された pull request が、GitHub REST API 経由の場合を含めセッションにリンクされていなかった不具合を修正
- org で制限された `model: opus` のような subagent・teammate のファミリーエイリアスが、親モデルにフォールバックせず、そのファミリー内で org が許可する最新モデルへ段階的に下がるように修正
- カスタム `ANTHROPIC_BASE_URL` gateway でサーバーの keep-alive ping が届いているにもかかわらず stream idle timeout が発火していた不具合を修正
- セッショントークンが無効な場合に claude.ai コネクタが誤って認可が必要と表示されていた不具合を修正。代わりに `/login` のヒントを表示するように
- MCP サーバーが削除された後などローカルで使用できなくなった tool について、tool エラーが表示されていなかった不具合を修正
- `SendMessage` が長いサマリーを拒否していた不具合を修正。文字数制限で送信が失敗する代わりに切り詰めるように
- subagent の transcript view でスピナーの effort ラベルが subagent 自身の `effort:` 設定ではなくセッションの effort レベルを表示していた不具合を修正
- file watcher がファイルシステムエラーに遭遇した場合や file watcher の teardown 中に稀に発生していたクラッシュを修正
- `--ax-screen-reader` モードで backspace のたびに入力行全体が読み上げられていた不具合を修正。行末の削除では削除された文字のみが読み上げられるように
- `CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST` が設定されている場合に、ホストのモデル選択キーがディスク上の古い `managed-settings.json` より優先されていなかった不具合を修正
- auto mode の安全性を改善: `SendMessage` 経由で他のエージェントセッションに送信されるメッセージが、送信前に permission classifier で評価されるように
- `disable-model-invocation` が設定された skill を Claude が呼び出そうとした際の拒否メッセージを改善: skill のワークフローを模倣する代わりに、skill の実行をユーザーに依頼するよう案内するように
- `/diff` view、Remote Control のワークスペース diff、および Claude Code on the web セッションのファイル編集 diff を改善し、ワークスペースで設定された diff driver や textconv を無視して生の git blob コンテンツを使用するように
- Remote Control の自動起動を変更し、リポジトリローカルの設定（`.claude/settings.json` または `.claude/settings.local.json`）では有効化できないように（無効化は引き続き可能）。有効化はユーザースコープで `/config` から行う
- ultraplan 機能を削除
