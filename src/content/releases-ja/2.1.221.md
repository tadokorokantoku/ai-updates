- [VSCode] Focus view を追加: チャットメニューのトグルで tool activity を隠し、ターンごとの展開可能なサマリーとライブの実行中 tool インジケーターを表示。`Ctrl+Alt+F` または "Claude Code: Toggle Focus view" コマンドで切り替え
- Linux と WSL 上の sandbox credential ファイル向けに `mode: "mask"` を追加 — sandbox 化されたコマンドはセンチネルコピー（ファイル全体、または `extract` の正規表現で捕捉した範囲のみ）を読み取り、sandbox proxy が egress 時に実際の値へ置換する。macOS ではファイルのマスキングは `deny` にフォールバック
- marketplace または plugin 名が Claude Desktop の managed marketplace sync に拒否される場合、`claude plugin validate` に警告を追加
- 古いモデル向けに書かれたパターンについてプロンプトと tool description を監査する `prompt-audit` サブコマンドを `claude-api` skill に追加
- zsh が `[[ ]]` の正規表現条件式内で隠しコマンドを実行できてしまう Bash tool の permission チェックのバイパスを修正。該当するコマンドは permission を求めるように
- Windows で引用符を含むパスを PowerShell の permission チェックが誤って処理していた不具合を修正。該当するパスは承認を求めるように
- thinking を無効にした状態で開始したセッションで、その後 thinking トグルが効かなくなっていた不具合を修正。MCP サーバーを接続途中で無効化しても黙って元に戻らないように
- print モード（`-p`）で `--mcp-config` から指定した MCP サーバーが最初のターン前に接続されておらず、モデルが tool 呼び出しをリテラルなテキストとして出力してしまう不具合を修正
- Esc でプロンプトを取り消してから再送した際、@ でメンションしたファイルが黙って失われていた不具合を修正
- `constructor` のような組み込みオブジェクトプロパティと同名の SDK MCP tool の API リクエスト準備時にクラッシュしていた不具合を修正
- thinking が無効な状態で effort `xhigh`/`max` の場合に WebSearch が 400 エラーで失敗していた不具合を修正
- sandbox proxy 経由の大きなアップロードが sandbox 化された環境で TLS エラーで失敗していた不具合を修正
- Team および Enterprise の spend-limit メッセージが、個人の spend limit ではなく組織の月次上限を誤って原因としていた不具合を修正
- 迷い込んだ `HOME` 環境変数を設定している Windows マシンの desktop-managed セッションで、AWS SSO named profile を使った Bedrock 認証が失敗していた不具合を修正
- `CLAUDE_CODE_RESUME_INTERRUPTED_TURN=0` が中断されたターンの自動再開を無効化しなかった不具合を修正。falsy な値が尊重されるように
- スリープからの復帰時に、2つの Claude Code プロセスが同じ MCP コネクタや WIF OAuth トークンを同時にリフレッシュしてしまい、再認証を強制することがあった稀なレースコンディションを修正
- Claude Code Desktop または claude.ai からのセッションのリネームが CLI のセッション名を更新していなかった不具合を修正。あらゆるリネーム経路からのセッション名がサニタイズされるように
- 端末専用の built-in（`/help`、`/feedback` など）と同名の plugin・org 配布の skill が、非対話セッションで呼び出せなかった不具合を修正
- plugin がリロードされた後も "Plugins changed" 通知が消えずに残り続けていた不具合を修正
- Vim モードを修正: yank register がダイアログ、履歴検索、transcript view をまたいでも失われず保持されるように
- Vim モードを修正: 空のプロンプトまで undo した際、agent view に戻る前に「もう一度 ← を押す」確認が働くように
- Google Vertex AI での tool search を改善: Claude 4.5 世代以降のモデルで再度有効化
- auto mode を改善: 並列 tool 呼び出しの permission チェックがキャッシュ効率化され、チェック保留中にモードを切り替えても古い結果を適用せず確実にプロンプトを表示するように
- 会話プレフィックスのキャッシュを判定間で再利用することで、auto-mode の permission チェックにおける prompt-cache コストを削減
- Stats パネルを改善し、トークン合計にキャッシュトークンを含めるように。input・output・cache read・cache write の内訳付き
- `/ultrareview` のエラーメッセージを改善: リポジトリがベースと履歴を共有しない場合、ブランチのないチェックアウトは事前に拒否され作成方法の助言が表示される。また、既に完全なクローンに対して `git fetch --unshallow` を提案しないように
- Windows の起動を改善: プロセス作成時刻を PowerShell を起動せずネイティブの kernel32 呼び出しで読み取るように。`powershell.exe` をゲートするエンドポイントセキュリティツールがプロンプトを出さなくなった
- バックグラウンドセッションを変更し、作業を保存するために commit・push し、タスクが求める場合のみ draft PR を作成し、CLAUDE.md の git 指示に従い、常に作業の場所を報告して終了するように
- `/plugin install` を変更し、古い marketplace カタログをリフレッシュしてリトライしてから plugin が見つからないと報告するように
- `/plugin` からインストールした plugin を、安全な場合は常に `/reload-plugins` を必要とせず即座に有効化するように変更
- plugin が `skills` パスとして `"."` を受け付けるように変更。ルートレベルの `SKILL.md` の検証エラーが plugin のルートを使うよう提案するように
- `/status` にセッションの種類を表示するように変更: `interactive`、またはバックグラウンドジョブの `attached`/`unattended`
- 絵文字オートコンプリートが `:thumbsup:`、`:thumbsdown:`、`:love:` のような一般的な代替ショートコードを受け付けるように変更
- `/fork` でフォークしたセッションが、元のセッションのチェックアウトで作業する代わりに独自の worktree を作成するように変更
- Claude in Chrome が、不要になったブラウザタブを閉じるように変更
- fast mode を変更し、セッション途中で使用クレジットが尽きた際、黙って失敗する代わりにストリーム上で報告するように
- Monitor を変更: 出力を生成せずに終了した watch は "stream ended" と報告する代わりに、その旨を報告するように
- Gateway の `model` フィールドの検証を変更: 文字列以外の値は転送せず 400 で拒否するように
- 承認プロンプトから、繰り返し表示されていた "Permission mode changed while the auto-mode classifier call was queued" という通知を削除
