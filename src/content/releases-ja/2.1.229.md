- 直近の Remote Control セッションを再開する `claude remote-control --continue` を文書化
- セルフホストランナーセッションでサーバー提供の Claude Code フックをサポート、マネージド環境と同じ挙動に
- 長い思考待ちの間にゲートウェイのストリーミングレスポンスへ SSE キープアライブ ping を追加し、Vertex や Bedrock アップストリームでのアイドルタイムアウト切断を防止
- プラグインマーケットプレイスの `command` ソースを追加：ローカルコマンド（IDE など）がプラグインディレクトリを出力し、セッションごとに再解決されて再起動なしで適用される。`mode: "link"` はそれをそのまま使用
- `ListAgents` が切断された Remote Control セッションを `offline` としてマークし、クラウドセッションには `cloud` ラベルを付けるように変更
- 長い応答がストリーミング中に一部消えたり、ターミナルに二重表示されたりする問題を修正
- ツール呼び出しの `glob`、`file_path`、`command` の値が文字列でない場合にエラー画面へクラッシュする問題（該当セッションの `--resume` 時も含む）を修正
- 非常に狭いターミナルウィンドウでプログレスバーや Markdown テーブルを描画した際の RangeError クラッシュを修正（`claude --continue`/`--resume` の起動時にもクラッシュしうる問題）
- Windows で、拡張長パス（`\\?\`）または UNC パスでファイルを参照するツール呼び出しやメッセージがあるとクラッシュする問題を修正
- `CLAUDE_CODE_ATTRIBUTION_HEADER` で attribution ヘッダーを無効化しているユーザー（Anthropic API に直接接続）で、auto モードがすべてのツール呼び出しで失敗する問題を修正
- カスタム `ANTHROPIC_BASE_URL` ゲートウェイを使用する claude.ai サブスクライバーで、`/model` が Sonnet/Opus 1M を拒否する問題を修正
- 認可サーバーが厳格な場合の MCP OAuth で、リダイレクト URI に `localhost` の代わりに `127.0.0.1` を使用するよう修正
- ノート PC のターミナルでスラッシュコマンドを入力した後、Remote Control クライアントの作業中スピナーが動かなくなる問題を修正
- `/install-github-app` が生成する Claude Code Review ワークフローが、プルリクエストにレビューを投稿せずに完了してしまう問題を修正
- IDE 拡張機能接続中に、数千件の IDE 診断があるファイルを編集した後に UI が数秒間停止する問題を修正
- ワンショットの `claude plugin` コマンドが不要な liveness ファイルを残し、古いプラグインバージョンのクリーンアップを妨げる問題を修正
- CPU 制限のあるコンテナ内で、動的ワークフローがコンテナの CPU 制限ではなくホストマシンのコア数を使用してしまう問題を修正
- アトミックなファイル置き換え後のファイルウォッチャーのハンドルリークと、ネットワークまたは仮想ファイルシステムでスケジュールタスクウォッチャーが失敗した際の Windows での未捕捉エラーを修正
- SDK および `--input-format stream-json` セッションで、空白のみのメッセージを送信すると 400 API エラーになる問題を修正
- メッセージ単体で API の 32MB リクエスト上限を超える会話で、画像やドキュメントを取り除けない場合にコンパクションのリトライを繰り返してしまう問題を修正。現在は明確なメッセージとともに一度だけ失敗するように変更
- Claude Desktop セッションからの OpenTelemetry エクスポートが、Desktop 管理のゲートウェイがテレメトリのエンドポイントも兼ねている場合に拒否される問題を修正
- `managed-mcp.json` がデプロイされ、サーバーが MCP サーバーを配信する場合に、セルフホストランナーや他のリモートセッションが起動時に終了してしまう問題を修正。該当の MCP サーバーは警告付きでスキップされるように変更
- セルフホストランナーのリポジトリ準備が Git Credential Manager のプロンプトでハングする問題を修正。認証情報がない場合、git は即座に失敗するように変更
- ワークフローのファンアウトで、同一プレフィックスの兄弟エージェントの実行タイミングをずらし、後続のエージェントがキャッシュされたプロンプトのプレフィックスを再読み込みせずに済むように改善（`CLAUDE_CODE_WORKFLOW_PREFIX_STAGGER_MS=0` で無効化可能）
- 「プロンプトが長すぎます」エラーを改善：`/compact` を提案するだけでなく、自動コンパクションで回復できなかった理由を説明するように変更
- サンドボックスを改善：ネットワークドメインリストの IPv6 リテラルがブラケット付き（`[::1]:443`）になり、曖昧な表記は fail-closed で強制され `/doctor` でフラグが立つように
- `/login` を更新：ログイン成功後にも `CLAUDE_CODE_OAUTH_TOKEN` の上書き警告を再度表示するように変更
- `/commit-push-pr` を変更：危険なフラグ（`--force`、`--amend`、`--no-verify` など）を伴う git/gh コマンドが自動承認されなくなった
- セルフホストランナーの Windows 起動時に、明示的な `--base-dir` を必須に変更。Windows にはデフォルトのチェックアウトディレクトリが存在しないため
- [VSCode] 「Report a problem」と `/bug` が、廃止されたアンケートリンクの代わりに組み込みのフィードバックダイアログを開くように変更
- [VSCode] `/btw` のサイドクエスチョンパネルを、サイドドッキング・スタックレイアウトの両方で境界をドラッグしてリサイズできるように変更
- [VSCode] サイドバーにセッショングループを追加 — 右クリックで作成・名前変更・削除、Cmd/Ctrl クリックまたは Shift クリックで複数セッションをまとめて移動可能に
