- まれな内部レイアウトエラーの後、プロセスは動作し続けているのに対話セッションの再描画が完全に停止してしまう問題を修正
- Claude Code を git インストール先の親フォルダから起動した際に、Windows で `git` / Git Bash が見つからない問題を修正
- 前回の応答以降に `/model` でモデルが変更されていた場合、`/tui` がセッションを以前のモデルに戻してしまう問題を修正
- インストールまたはアップグレード後の最初のセッションで、クロスセッションメッセージングが受信箱なしで開始されてしまうことがある問題を修正
- Remote Control 接続中に `/resume` を行うと、再開した会話のタイトルや履歴が接続先のセッションに漏れてしまう問題を修正
- `claude self-hosted-runner` セッションで、セッションが push しないリポジトリの `checkout` フックが失敗すると、新しいランナーごとに毎回失敗していた問題を修正。該当リポジトリは警告付きでスキップされるように変更
- バックグラウンドタスクの完了と後続ターンの開始の間の隙間で、セルフホストランナーのセッションが終了してしまう問題を修正
- セッションのクリーンアップがプロジェクトのメモリフォルダ内のコンテンツを削除してしまう問題を修正
- バックグラウンドのプラグインキャッシュのクリーンアップが、シンボリックリンクされた開発用チェックアウトのみが存在するプラグインのキャッシュを削除してしまう問題を修正
- 設定のマージに関する問題を修正：より優先度の高い設定階層でマーケットプレイスのエントリが再定義されると、別の階層のカスタムヘッダーを継承してしまっていた問題。マーケットプレイスのエントリはエントリ単位でマージされるように変更
- スキル呼び出し後に、deferred-tools のリマインダーがモデルに二重送信されることがある問題を修正
- claude.ai から同期されたスキルを強化：ローカルのコマンドや MCP プロンプトをシャドーイングしなくなり、説明文はサニタイズされてラベル付けされ、ローカル環境ではスキル本文が `!` コマンドの実行や `@` ファイルの展開を行わなくなった
- クロスセッションメッセージを改善：送信者と本文が折りたたまれた 1 行ではなくインラインで表示されるようになり、他のマシン上の Remote Control セッションへのメッセージには送信元の Remote Control セッション名が表示されるように変更
- Vertex AI の認証情報の扱いを改善：Google Cloud の認証情報が期限切れまたは未設定の場合、数分間リトライし続けるのではなく数秒で失敗するように変更
- コンパクション処理の進捗表示を改善：リトライのカウントダウンとスタール時のヒントが、進捗バーだけでなくコンパクション中にも表示されるように変更
- タブバーのちらつきを軽減するため、ターミナルタイトルのビジー状態を示すスピナーのグリフを更新
- Write ツールを変更：新しいモデルは、Edit ツールと同じルールに従い、このセッションで読み込んでいない既存ファイルも上書きできるように変更。古いモデルは引き続き事前の読み込みが必要
- Pro、Max、Team プランの初回利用時の通知から、auto モードのセッションのコストがわずかに高くなるという古い注記を削除
