- Claude Haiku 5.5 (`claude-haiku-5-5`) を追加。Anthropic API の Haiku のデフォルトモデルに — 1M コンテキスト、$0.10/$0.50 per Mtok（100K 超のプロンプトは $0.50/$2.50）
- `subagentStatusLine` のペイロードに `agentType` を追加し、スクリプトがカスタムサブエージェントの種類を区別可能に
- mod 向けの `$.tool.register` に `isDeferred` を追加: `false` にするとツールのスキーマを tool search の背後ではなく最初からプロンプトに載せる
- コンテキスト compaction 直前の自分の最後の操作を、compaction 後に完了済みと扱ってしまい、終わった作業を取り消したりやり直したりすることがある問題を修正
- HTTP MCP 接続が送信した全リクエストを接続が閉じるまで保持し続けるメモリリークを修正
- Claude の作業中に送信したメッセージが、`←` でセッションをバックグラウンドに移した際に失われる問題を修正。キュー中のメッセージを移せない場合、`←` はその場にとどまり、その旨を表示するように
- `/model` の effort で ←/→ が最高または最低レベルを越えて循環し、誤って Low をモデルのデフォルト effort として保存してしまうことがある問題を修正
- `--chrome` で起動したセッションで `/tui` が Claude in Chrome を切断し、`--no-chrome` を無視する問題を修正
- ホスト、権限ルール、`--tools` リストによって `SendMessage` が除外されたセッション（再開したものを含む）で、`SendMessage` でサブエージェントに継続・メッセージ送信するよう Claude に指示してしまう問題を修正
- サブエージェントや `--agent` セッションに、自身のツールリストから外れているだけの組み込みツールが、セッション全体で無効化されていると伝えてしまう問題を修正
- claude.ai 同期スキルの編集後の description が、新しい会話や `/clear` までモデルに届かないことがある問題を修正
- ログインの期限切れ間近または切れている状態で、`claude logs`、`stop`、`kill`、`rm` および `claude daemon status`、`stop`、`uninstall` がサインアウトしてしまうことがある問題を修正
- セッションフォルダの読み取りが一時的に失敗した場合（例: 開いているファイルが多すぎる）に、フッターのエージェント数が消える問題を修正
- `worker` という名前のカスタムエージェントが開始時に「Agent」と表示される問題と、エージェント詳細ダイアログのタイトルがエージェント終了後にエージェントタイプを失う問題を修正
- publish 呼び出しのストリーミング中に、Artifact ツールのトランスクリプト行が一瞬 `Artifact("(unprintable path)")` と表示される問題を修正
- Linux で、サンドボックス化されたコマンドの実行中に、設定ファイルが「解析できない」として `/ultrareview` アップロードが一部のリポジトリ（別のチェックアウト内にあるものなど）を誤って拒否する問題を修正
- split-index ファイルによる `/ultrareview` アップロードの拒否時に、git がインデックスを読めなくなる可能性のある git コマンドを案内してしまう問題を修正
- 非常に長い Remote Control およびクラウドセッションで、返信がストリーミングされず一ブロックずつ表示されることがある問題を修正
- Remote Control が認証情報の復旧のたびにセッションの開始履歴を再アップロードする問題を修正
- `claude remote-control` で起動したセッションで PushNotification が「Remote Control inactive」と報告する問題を修正
- プラグインフックワーカーの再起動中に、mod の `classic.*` イベントのフックがスキップされ、設定のフックだけが応答してしまう問題を修正
- `$.session.append` を呼ぶ mod で `claude plugin test` が失敗する問題を修正。追加された行は新しい `mock.session` で読み戻せる
- Docker Desktop のある Mac（`~/.docker/bin` 配下のリンク）で `claude plugin eval` が Bash を許可する実行をすべて拒否する問題を修正。拒否時に、リンクを保持していた認証情報ストアの該当部分が示されるように
- `desktop` ポリシーが `builtinBrowserEnabled` など Claude Desktop の組み込みブラウザキーを設定している場合に、Claude apps ゲートウェイが起動を拒否する問題を修正
- 同意が `.claude/settings.local.json` または `--settings` ファイルにのみ保存されている場合に、`claude agents` がバックグラウンドセッションで無視される bypass 権限を提示する問題を修正。先に同意を求め、bypass を無視するセッションでは消えない短い通知を表示するように
- プロンプトに未送信のテキストがある、または質問への回答待ちの状態で、`←` が 10 秒後にセッションをバックグラウンド化する問題を修正（未送信テキストがある場合は移動をキャンセル）
- `←` でセッションをバックグラウンドへ移した直後に、権限プロンプトの Esc またはフィードバックなしの No でターンが止まらない問題を修正
- セッションフォルダを読み取れない場合（例: 開いているファイルが多すぎる）に、エージェントビューがセッション一覧を一時的にプレースホルダー行に置き換える問題を修正
- Claude が Read ツールではなく Bash ツールの単一ファイル向け cat、head、tail、sed -n、grep コマンドでファイルを閲覧した際に、パススコープのルールやネストした CLAUDE.md が読み込まれない問題を修正
- 先頭と末尾が同じ語のペーストテキストが、入力されたものとして Claude に送られることがある問題を修正
- ペースト直後に入力またはペーストしたアクセント記号が末尾の文字と結合した場合に、ペーストテキスト内のスキル名が入力されたものとして扱われる問題を修正
- レポート送信中に Ctrl+O または Ctrl+Z を押すと `/feedback` が下書き一覧に戻り、送信をキャンセルできなくなる問題を修正
- ファイルやフォルダを削除できない場合に `claude purge` が黙って停止する（exit 0、またはターミナルでハング）問題を修正。残りを削除し、削除できなかったものを一覧表示して exit 1 で終了するように
- keybindings.json のチェックを修正: 単独の " "（スペースキー）はエラーとして報告されなくなり、"ctrl+ k" のようなキーには警告が出るように
- スペースのみの行での vim モードの `>>` と `<<` がカーソルを行末の先に残し、続く `x` で何も削除されない問題を修正
- vim モード: Visual モードで行全体を削除（`V` の後に `d`）した後、カーソルが最初の非空白文字に移動し、その後の `.` がカーソル行に作用するように修正
- Windows: ステータスライン、フック、シェルコマンドの停止時に、同じプロセス ID を割り当てられた無関係なプロセスを終了させてしまうことがある問題を修正
- 2.1.281 の auto mode 拒否メッセージの変更（拒否は正確なコマンドだけでなく結果にも及ぶと Claude に伝える）を元に戻した
- コンテナ再起動で保留中の `/loop` ウェイクアップやスケジュールタスクが失われた後もクラウドセッションがスリープしたままになる問題に対する 2.1.290 の修正を元に戻した。Claude には通知されず、セッションはスリープしたままになる
- Team および Enterprise 組織の起動を改善: ポリシーと managed 設定をより早く取得し、停滞したリクエストは 3 秒後に再試行
- Claude in Chrome を改善: ブラウザのタブ報告が遅い場合に拒否されるページ操作が減少
- ブラウザに到達できないクラウドセッションでの Claude in Chrome のメッセージを改善: 複数の組織に所属している場合、拡張機能を同じ組織でサインインする必要があることと、その変更方法を表示
- Bash の編集 diff の注記を改善: 一覧のファイルはコマンドの実行中に変更されたもので、他のプロセスによる書き込みを含む場合があることを明記
- artifacts を改善: Claude がライブラリを 2 週間以上前の正確なバージョンに固定
- セッションが使用されていない間の claude.ai スキル同期の変更確認を、約 10 分ごとから約 40 分ごとに変更
- モデルに通知されるエージェント一覧と MCP サーバーの順序を変更: 非 ASCII 文字を含む名前は ASCII の名前の後に並ぶ
- OpenTelemetry の `claude_code.at_mention` ログを、プロンプトを読み取るたびにエージェントと MCP リソースのイベントをそれぞれ最大 100 件までに変更
- Self-hosted runner: オーケストレーターのポーリング間隔を一定の 5 秒から 4〜6 秒のスリープに変更し、同じ環境の複数レプリカが同時にポーリングしないように
- [Claude Tag] Slack がメッセージに未接続のワークスペースのラベルを付けた場合に、ワークスペース間で共有された Enterprise Grid チャンネルで Claude in Slack がワークスペース未設定と答える問題を修正
- [Claude Tag] 管理者がチャンネルのコネクタ、プラグイン、スキル、ルールを変更したときに、Claude in Slack がチャンネルで作業の途中で停止する問題を修正。変更は Claude の作業完了後に適用されるように
- [Claude Tag] 追加メモ付きでスレッドのルーティンを今すぐ実行するよう Claude in Slack に依頼すると、投稿できない別の実行が開始される問題を修正。実行はそのスレッドで継続するように
- [Claude Tag] Claude Tag 管理設定のアクセスバンドルの Add a connector ダイアログで、一度 Google にサインインすると全 Google コネクタが接続済みと表示される問題を修正

- [Claude Tag] Claude in Slack を変更: 管理者のみ投稿可能なアナウンスチャンネルには、自己紹介を投稿せずに参加
- [Claude Tag] Claude Tag 管理設定のチャンネルルールの上限を、ワークスペースごと、および組織全体の Slack ページで 20 から 50 に変更
