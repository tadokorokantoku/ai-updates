- `hook_execution_complete` OpenTelemetry イベントに、フック出力のサイズとファイルに保存された過大な出力の数を追加

- 安全性チェックが応答を返さなかったとき、auto mode が休止せずにアクションを何度も拒否する問題を修正。今後はリトライが徐々に間隔を空け、10 回連続で失敗するとメッセージを表示してターンを停止するように
- モデルが `file_path` と `content` の代わりに `path`、`file_text`、`file_content` や余分な `description` を送信したときに Write 呼び出しの検証が失敗する問題を修正

- 誤って入力された `n` がダイアログを閉じ、誤って入力された `y` がダイアログを確定してしまう問題を修正。Enter と Esc で確定・キャンセルするように(`keybindings.json` で `y`/`n` を `confirm:yes`/`confirm:no` にバインドすれば元の動作に戻せる)

- Windows のターミナルで、Enter 時に不可視文字が除去された後にプロンプト行が乱れたまま表示される問題を修正。今後は画面が再描画され、送信される正確なテキストを確認できるように
