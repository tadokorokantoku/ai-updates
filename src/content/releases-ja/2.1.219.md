highlights:
  - "Claude Opus 5 に対応。1M context でデフォルトの Opus モデルに"
---

- Claude Opus 5（`claude-opus-5`）を追加。デフォルトの Opus モデルとなり、1M コンテキスト、fast mode は $10/$50 per Mtok
- サンドボックス化されたコマンドに対し、許可されていないホストへの通信をプロンプトなしで拒否する `sandbox.network.strictAllowlist` 設定を追加
- `/add-dir` または SDK の `register_repo_root` control request がセッション途中で新しい working directory を登録した後に発火する `DirectoryAdded` hook を追加
- headless の stream-json init イベントに `mcp_server_errors` を追加。config 検証によりスキップされた `--mcp-config` のエントリを一覧表示し、ターミナル実行では起動時に警告を表示
- 任意の settings ファイルから advisory な Dynamic workflow size guideline を設定できる `workflowSizeGuideline` 設定キーを追加。設定されている間は `/config` の該当行が非表示に
- stream-json でのネストされた subagent の転送を追加: depth-2 以上で生成された subagent が `--forward-subagent-text` 設定時に表示されるようになり、生成元の Agent `tool_use` id をキーとする
- ターン途中の API エラーでターンが失敗した際、`claude -p` のテキスト出力がすでに生成済みの回答を破棄していた不具合を修正
- サーバーへの接続に失敗した際、`claude mcp list` と `/mcp` に HTTP ステータスとエラー文言を追加。また MCP config の値に前後の見えない空白がある場合の警告を追加
- self-hosted runner の再起動中に承認した permission が、セッション再開時に破棄されていた不具合を修正。承認済みのアクションが正しく実行されるように
- 古いキャッシュに焼き付いていたラベルにより、対象プランでも Fable モデルの行に "Requires usage credits" と表示されていた不具合を修正
- self-hosted runner の起動中に SIGTERM が届いた際、リースが期限切れになるまで古い active 行が残っていた不具合を修正。正しくクリーンに登録解除されるように
- self-hosted runner の spawn・セッション失敗に構造化された失敗カテゴリを追加し、hook のエラー・runner のクラッシュ・config のエラーを区別できるように
- `/model` ピッカーで統合された Opus の行が "Opus (1M context)" ではなく単なる "Opus" と表示されていた不具合を修正
- GNU screen 内でのコピーオンセレクトが、選択範囲をコピーする代わりに base64 をターミナルに出力していた不具合を修正
- Remote Control クライアントが、モデル切り替え・再接続・組織チェック失敗の後も古い fast-mode ステータスを保持し続けていた不具合を修正
- Windows で `CLAUDE_CODE_GIT_BASH_PATH` が bash/sh バイナリでないパスを指している場合に終了したり bash として使われたりしていた不具合を修正。現在は警告付きで無視される
- Vim mode を修正: 空のプロンプトで ← を押すと、INSERT からだけでなく NORMAL mode からも agent view に戻るように
- スクリーンリーダーモードで、入力された文字だけをエコーする代わりにキー入力ごとに入力行全体を書き換えていた不具合を修正
- "Remote Control is only available via api.anthropic.com" エラーを改善し、原因となった具体的な設定名を表示するように
- `claude --teleport` を改善し、現在のチェックアウトがセッションのリポジトリと一致しない場合にどのリポジトリを指しているかを表示するように
- dynamic workflows のデフォルトを medium size guideline（15 agent 未満を目安）に変更。`/config` の Dynamic workflow size で他のサイズや無制限を選択可能
- managed MCP の allowlist/denylist における `${VAR}` エントリの解決元を、settings ファイルの env ではなく起動時の環境と managed-settings env に変更
- `/model` ピッカーが最新モデルの名前のみをハイライトするように変更し、ハイライトが任意の部分集合ではなく新リリースを示すように
- 実行中の workflow のステータス行に現在のデフォルト workflow size を追加し、`/config` へのポインタを表示
- fast mode から Opus 4.7 を削除。`/fast` は Opus 5 と Opus 4.8 に適用される
- claude-api skill を更新し、デフォルトを Claude Opus 5 に。Opus 4.8 からの移行パスを追加
- subagent が最大 depth 3 までネストした subagent を生成できるようになった（以前は 1）。`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1` でネストを無効化可能
