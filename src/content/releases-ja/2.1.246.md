- サブコマンドの前にワイルドカードを置いた Bash 許可ルール（例: `Bash(git * main)`）はサブコマンドの前に挿入されたオプションにもマッチしてしまうため、起動時に警告を追加
- `/permissions` に Auto mode タブを追加。auto mode のクラシファイアールールを表示・編集可能に
- ターン終了時の所要時間表示にターンの完了時刻を追加（例: `✻ Sautéed for 23s · done 6:05 PM`）
- ターミナルのリサイズ後、フルスクリーンモードで次のキー入力まで最下部にジャンプしても空のトランスクリプトが表示されていた問題を修正
- diff に非常に長い1行（base64 文字列など）が含まれる場合にトランスクリプトが著しく遅くなっていた問題を修正。そのような行は切り詰めてマーカー付きで表示するように
- 以前のメッセージ位置にいるときのフルスクリーンモードでの不安定なスクロールを修正。最下部へのジャンプがトランスクリプト途中で止まってしまう問題を含む
- Claude Code の起動ディレクトリが削除されていた場合、マシンがスリープしていた場合、またはホストのプロセス起動が遅い場合に、バックグラウンドセッションが45秒後に開けなくなっていた問題を修正
- 別の Claude Code プロセスが npm パッケージを再インストール中だった場合に、バックグラウンドセッションが「Couldn't start the background service … EACCES」で開けなくなっていた問題を修正
- メッセージの最初の500文字に Markdown 記法が含まれない場合にメッセージ全体で Markdown レンダリングが無効になっていた問題、および `+`/`N)` リストと setext 見出しに関する問題を修正
- ヘッドレス/リモートセッションで受信メッセージによって中断された MCP ツール呼び出しが、明示的な中断エラーではなくモデルに「completed with no output」として報告されていた問題を修正
- パラメータのスキーマが空（`{}`）の場合に MCP ツールの引数が実際の型ではなく JSON 文字列として送信されていた問題を修正
- 実行途中で中断されたコマンドが、中断されたことを示す表示なしに「Ran 1 shell command」と表示されていた問題を修正
- 動的ワークフロー実行中に ← キーを押す、または `/background` を実行すると、完了済みのサブエージェントが再起動されてしまっていた問題を修正。事前に確認し、再起動されるサブエージェントの数を表示するように
- ワーカーがまだ起動中（Windows で多い）に `claude agents` で開始直後のセッションを開くと、「was stopped while the respawn was in flight」で停止してしまっていた問題を修正
- `claude agents` がバックグラウンドの名前付きセッションを二重に表示していた問題を修正。同じ会話を再度バックグラウンド化すると新しい行に番号が付くように（例: `my-session (2)`）
- 古いバックグラウンドセッションの記録が指していた場合に、バックグラウンド保持のクリーンアップ処理が `.claude/worktrees/` 配下の自作の git worktree を削除していた問題を修正
- 非常に大きなセッションで auto mode のツール呼び出しが「temporarily unavailable」として拒否されていた問題を修正。安全性チェックのタイムアウトをプロンプトサイズに応じてスケールさせるように
- プラグインキャッシュが同一プラグインに対して重複した SHA 名のディレクトリを作成していた問題を修正
- frontmatter の `name` にすでに `<plugin>:` プレフィックスが含まれるプラグインスキルが、スラッシュメニューで二重表示されていた問題を修正（例: `/plugin:plugin:skill`）
- インストール済みプラグインをベア名で指定した場合に `claude plugin update` が失敗していた問題を修正（完全修飾名でのみ動作していた）
- `plugin.json` が UTF-8 BOM 付きで保存されている場合にプラグインのインストールが失敗していた問題を修正
- `skills/*/SKILL.md` 配下でスキルを定義しているプラグインについて、`/reload-plugins` が0件と報告していた問題を修正
- フックのエラーメッセージが解決済みのプラグインパスではなく `${CLAUDE_PLUGIN_ROOT}` のリテラルを表示していた問題を修正
- `/rename` がテーマのプロンプト境界色（カスタムテーマの `promptBorder` を含む）をデフォルトのシアンで上書きしていた問題を修正。`/color` で明示的に選ばない限りテーマの色が保持されるように
- カスタムテーマの diff カラー（`diffAdded`/`diffRemoved` とその暗めのバリアント）が diff や `/theme` プレビューで無視されていた問題を修正
- `keybindings.json` の未知のアクション名を持つバインディングがそのキーを無効化してしまっていた問題を修正。今後はそのバインディングをスキップしてデフォルトの動作を維持し、`--debug` 時に警告をログ出力するように
- UTC より東のタイムゾーンで `/stats` のアクティビティヒートマップが各日の活動を1マスずれて表示していた（日曜日の件数が月曜日の下に表示される）問題を修正
- すでにフォークまたはバックグラウンド化されたセッションから `/fork` すると、新しいセッションが空の会話で開始されていた問題を修正
- `/--` で始まるプロンプト（Lean のドキュメントコメントなど）が Claude に送信されず、不明なスラッシュコマンドとして拒否されていた問題を修正
- 入力したテキストが実際のパスにマッチしなくなった後も `@` ファイルピッカーが開いたままだった問題を修正
- エージェントビューへ移動して戻った後、ステータスラインのコストと所要時間が0にリセットされていた問題を修正
- ターミナルウィンドウをクリックしてフォーカスを戻しただけなのに、フルスクリーンモードでキーボードフォーカスがポインタ下のコントロールに移動していた問題を修正
- 補完対象のトークンまたは作業ディレクトリに null バイトが含まれる場合にパス補完が失敗していた問題を修正
- Windows/macOS: 異常終了したセッションが `~/.claude/sessions` に残していた古いエントリを、ヘッドレスセッションがクリーンアップしていなかった問題を修正
- サードパーティの Anthropic 互換エンドポイント（`ANTHROPIC_BASE_URL`）が `id` なしの `tool_use` ブロックをストリーミングした場合に、最初のツール呼び出しで UI がレンダリングエラーで停止していた問題を修正
- 非常に大きな既存ファイルを上書きした後、実際には書き込みが完了していたにもかかわらず Write ツールが「Out of memory」と報告するか長時間フリーズしていた問題を修正
- `~/.claude/plugins/known_marketplaces.json` が空または破損している場合に `claude plugin install <name>` がエラーを報告せず、無言で終了（またはターミナルでハング）していた問題を修正
- 保存された履歴にサードパーティ API プロキシが書き込んだような、Anthropic API が受け付けないツールブロックが含まれる場合に、再開したセッションが毎ターン400エラーで失敗していた問題を修正
- サーバー管理設定を持つ一部の Team/Enterprise ユーザーで `curl -fsSL https://claude.ai/install.sh | bash` が「Raw mode is not supported」で失敗していた問題を修正
- permission mode が未設定の場合、plan mode で終了したセッションを VS Code 拡張機能や、権限プロンプトツール付きの `claude -p --continue`/`--resume` で再開すると plan mode の外側で再開されていた問題を修正
- サンドボックスの「Network request outside of sandbox」権限プロンプトが表示されている間 `Notification` フックが発火していなかった問題を修正
- ぶら下がった `&&` や `||` 演算子を持つ不正な形式のコマンドについて、Bash の権限チェックが常に承認を要求するように修正
- `--strict-mcp-config` セッションが、決して読み込まれない `.mcp.json` サーバーの承認を求め、バックグラウンドセッションが起動時に待機し続けていた問題を修正
- Anthropic へのテレメトリおよびメトリクスリクエストが、サードパーティゲートウェイ（`ANTHROPIC_BASE_URL`）用に設定された API キーを送信していた問題を修正。認証情報は自身のホストにのみ送信されるように
- `apiKeyHelper` が短命の JWT を返す場合、アイドル後の最初のプロンプトで API エラーが表示されていた問題を修正。期限切れのキャッシュ済みトークンは送信前にリフレッシュされ、401/403 認証エラーは静かにリトライされるように
- フルスクリーンおよび Ctrl+O のトランスクリプトビューでセッションが長くなるにつれてメモリが増加していた問題を修正。レンダリングされた各メッセージ行がトランスクリプト全体のツール検索結果のコピーを保持しないように
- 1つのリポジトリ（複数の worktree など）から同時に開始した `/ultrareview` 実行とクラウドセッションが、別の起動時の未コミット変更を引き継いで開始してしまうことがあった問題を修正
- `/autofix-pr` などのバックグラウンドクラウドセッションで表示されるタスク進捗カウント（例: `3/5`）がタスクを見落とすことがあった問題を修正
- Remote Control セッションが claude.ai と Claude アプリで2回目のプロンプトまでプレースホルダー名のままだった問題を修正。最初のプロンプト後に自動生成タイトルが表示されるように
- `requiresUserInteraction` が指定された MCP ツールの権限プロンプトに「Yes, and don't ask again」が引き続き表示されていた問題を修正。選択すると許可ルールが書き込まれるがツール側では無視されていた
- ワークポーリングの応答が不正な形式（プロキシによる HTML ページの割り込みなど）の場合に、セルフホストランナーが実行中のセッションを終了、またはランナー自体が終了していた問題を修正。ポーリングをリトライするように
- `/cd` を改善: 移動先ディレクトリのプロジェクト設定、フック、`.mcp.json` サーバー（通常の承認プロンプトを経由）、スキル、エージェントが `--resume` を待たずに移動直後から有効になるように
- bash シェルでの Bash ツールのレイテンシを改善: 関数ごとに base64 サブシェルを使わずスナップショット関数をリプレイするように
- サブエージェントの結果を改善: `maxTurns` の上限で停止したサブエージェントは、完了したように見せるのではなく、出力が部分的である旨と `SendMessage` での継続方法のヒント付きで返されるように
- 非対話セッション（`-p`、SDK、クラウドセッション）を改善: サーバーエラー、接続断、またはストールによりストリーミング途中で切れた応答を、エラーで終了せず自動的に継続するように
- ワークロード ID フェデレーションセッション、起動時に実行される `apiKeyHelper` の間に送信されるイベント、およびアイドル中にログイントークンが期限切れになった後の、組織への使用状況テレメトリの帰属を改善
- Bedrock、Vertex AI、Foundry、Claude apps ゲートウェイ経由、およびテレメトリや非必須トラフィックが無効な場合でも Claude が自ら `/code-review` を開始できるように変更
- `/goal`: アイドルセッションが1つのゴールにつき開始できる長時間バックグラウンド作業のチェックインを最大3回までに制限するように変更。次のメッセージでさらに3回分が許可される
- `claude install` と `claude update` を変更し、保留中の管理設定同意プロンプトをコマンド実行中に表示せず、次回の対話セッションまで遅延させるように
- claude.ai から同期されたプラグインの OpenTelemetry プラグインイベントを変更: `plugin_id_hash` が実際のマーケットプレイスを反映し、`enabled_via` は管理者インストールのプラグインでは `admin-install` になるように
- コマンドサンドボックスのファイルシステム設定が `--setting-sources` を尊重していなかった問題を修正
