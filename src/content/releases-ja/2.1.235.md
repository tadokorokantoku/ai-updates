- インストール済みの `aspell`、`hunspell`、`ispell` を使い、プロンプト入力中にスペルミスの単語に下線を表示する任意の `spellcheck` 設定を追加
- セッション途中で言語サーバーが切断・再接続した際にプロンプト全体のキャッシュが無効化されていた問題を修正
- ネストした markdown のリスト項目が深さ 3 以上で位置ずれしていた問題を修正し、ターミナル UI で折り返されたリスト項目にぶら下げインデントを追加
- 一部の複数行プロンプトで、プロンプト入力のハイライト（スラッシュコマンド、キーワード、メンション）が 1 文字以上ずれて表示されていた問題を修正
- 権限プロンプトのコメント欄で Shift+Tab を押すと、欄を閉じる代わりに編集を承認しセッション全体の編集権限を付与してしまっていた問題を修正
- 該当エージェントが利用できないセッションで、Agent ツールが general-purpose をデフォルトとして案内していた問題を修正: `subagent_type` を省略すると、利用可能なエージェントを列挙した明確なエラーが表示されるようになった
- notebook のセルが読み取れない場合に、セル削除・置換の承認ダイアログが既存のセル内容を黙って省略していた問題を修正。ダイアログに理由が表示されるようになった
- Claude が応答中に実行したスラッシュコマンドが、実際の文字ではなく HTML エンティティとして表示されていた問題を修正
- バックグラウンドでの自動更新後、プロンプトフッターに「Update installed」の再起動通知が表示されなかった問題を修正
- まだ open な task があるセッションを再開・再起動した際、展開済みタスクリスト（`ctrl+t`）が常に折りたたまれた状態で開始していた問題を修正
- `/ultrareview` や `/autofix-pr` などのクラウドセッションがバックグラウンドで実行される際のメモリ・CPU使用量を改善: イベントストリームが更新のたびに再スキャン・再レンダリングされなくなった
- 権限ダイアログを改善: 表示テキストと「don't ask again」オプションが、許可の対象と常に一致するようになり、内容を完全に表示できない場合は「don't ask again」が提供されなくなった
- ネイティブの macOS/Linux ビルドに組み込まれた `grep` を改善: 病的なパターンでメモリを枯渇させる代わりに早期に失敗するようになり、`-m N` と `-A`/`-C` の併用で正しいコンテキストが表示されるようになった
- コンテキスト上限エラーを改善し、auto-compact が無効な場合にその旨と `/config` での再有効化方法を表示するようになった
- Vim モード: 詳細トランスクリプトの切り替え（ctrl+o）やパネルを閉じた際に、NORMAL モードとカーソル位置が保持されるようになった
- ダイアログ: 矢印キーと Enter を素早く連続で押した際、以前ハイライトされていた選択肢ではなく、移動先の選択肢が選択されるようになった
- `SendMessage` が、クロスセッション配信には大きすぎるメッセージを黙って破棄する代わりに、事前に拒否するようになった
- Remote Control: `claude rc` が、対話的な起動時と同じ enterprise-gateway 可用性チェックを適用するようになった
- [VSCode] 複数の Claude パネルがあるウィンドウを復元・リロードした際、開いている Claude タブ間でフォーカスが勝手に移動していた問題を修正
