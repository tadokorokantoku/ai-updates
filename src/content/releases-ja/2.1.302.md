- `CLAUDE_CODE_AUTO_MODE_MODEL` を追加: クライアント側 auto mode classifier が使うモデルを選択できる。サーバー側 auto mode のモデルは変更しない
- `/config` に `Idle compaction` 行を追加: idle compaction のオフ/オンを切り替えられる。idle compaction 後に表示される通知に、オフにする方法も表示されるようになった
- `/design-sync` と `/design-login` に、スタンドアロンの Claude Design (claude.ai/design) が 2026 年 12 月 14 日に終了する旨の通知を追加
- 会話の compaction 中にターンを停止すると "Prompt is too long" エラーが出る問題を修正
- Vertex や Bedrock にセッション途中で切り替えた後、"diagnostics: Extra inputs are not permitted" でリクエストが失敗する問題を修正
- Read ツールが、任意のサイズの画像ファイルや、画像名のパイプ/デバイスを丸ごとメモリに読み込んでいた問題を修正。128 MB を超える画像ソースは拒否される
- gateway が `anthropic/claude-opus-4-1` のようにプレフィックス付きで Opus 4 / 4.1 を指す場合に、`/autocompact` と `/effort` が誤ったモデルに保存される問題を修正
- セッション途中で追加されたツールが ToolSearch 経由や compaction 後に再度読み込まれると、プロンプトキャッシュがミスする問題を修正
- `claude plugin` などのサブコマンドが、待機中の settings/config 書き込みの完了前に終了し、変更が失われたり `.tmp` ファイルが残ったりすることがある問題を修正
- git の ref 形式が reftable の場合に、plugin marketplace が更新のたびに再 clone される問題と、新規インストールした git plugin のバージョンが "unknown" と表示される問題を修正
- PowerShell ツールが plugin の `bin/` フォルダ内のコマンドを見つけられない問題と、何も見つからない検索 (rg, grep, findstr, git grep) を `Select-Object` などの整形 cmdlet にパイプするとエラーになる問題を修正
- デスクトップアプリの Claude が、利用できない環境で MCP server の認可/再接続のために claude.ai の設定や `/mcp` を案内してしまう問題を修正
- Claude が空の edits リストを送ると artifact の publish が失敗することがある問題と、より新しいバージョンの artifact に拒否された後に Claude が誤った方法で更新を再試行する問題を修正
- ほとんどの auto mode classifier ブロックで OpenTelemetry の `tool_decision` イベントに `classifier_category` が欠落する問題と、`OTEL_LOGRECORD_ATTRIBUTE_COUNT_LIMIT` が低い場合に新しい `tool_decision` 属性が `tool_use_id`、`tool_source`、`tool_parameters` を押し出す問題を修正
- agents view で、長いリストを下に移動したりセクションを折りたたんだりすると行が空白のままになる問題を修正
- 未サインイン時に `claude remote-control --help` が usage を表示して終了しない問題を修正
- クラウドセッションで失敗した `/design consent` と `/design revoke` が、利用できない `/design-login` を案内する問題を修正。claude.ai/design/settings を案内するようになった
- MCP server がプロトコルバージョン 2026-07-28 をネゴシエートしつつ `resultType`、`ttlMs`、`cacheScope` を省略した場合に、ツールが表示されない、またはすべてのツール呼び出しが失敗する問題を修正
- プロンプト提案が、プランではクレジット課金でのみ利用できるモデルでクレジットを消費する問題を修正。クレジット課金された返信の後はスキップされる
- バッククォートで囲まれた URL が折り返された場合に最初の行しかクリックできない問題を修正。ハイパーリンク対応ターミナルでは URL 全体が 1 つのリンクになる
- `claude plugin details <name>@builtin` が plugin 未検出時に、組み込み plugin を決して表示しない `claude plugin list` を案内する問題を修正。`/plugin` を案内するようになった
- リンクが途中から始まる絵文字が 1 カラム幅広く折り返され、質問プレビューで隠れたりテーブルがリスト表示になったりする問題を修正
- 存在しないディレクトリを指す不要な `.git` ファイルがある場合に、git 2.56 以降で worktree isolation が worktree の作成/再開を拒否する問題を修正
- クラウドセッションが新しいプロセスで再開した際に、コストと使用量がゼロから再開する問題を修正
- Self-hosted runner: git の reftable 形式で保存されたチェックアウトを再利用するセッションで、git fetch が "bad object refs/heads" で失敗する問題を修正
- Windows: exFAT や FAT32 ドライブ上のプロジェクトで、`--plugin-dir` 付きで開始したセッションを含め、すべてのファイル書き込みが拒否または確認される問題を修正
- 多数の plugin を有効にした場合の起動時間を改善: plugin の command / agent ファイルの読み込みに必要なファイルシステム呼び出しが大幅に減った（特に Windows）
- サーバー側 classifier を使う auto mode を改善: 安全性チェックには長すぎる会話は compaction されるようになり、チェック対象のツール呼び出しがすべて拒否されることがなくなった
- 別のフォルダーから再度開いたバックグラウンドセッションに LLM gateway がない場合のメッセージを改善: "Not logged in" ではなく理由を表示する

- fork subagent (`subagent_type: "fork"`) を、ターミナルと同様に `claude -p`、Agent SDK、デスクトップアプリ、VS Code でもデフォルトで有効に変更。`CLAUDE_CODE_FORK_SUBAGENT=0` で無効化でき、`claude mcp serve` は fork を提供しない
- デスクトップアプリと VS Code で、メイン会話の subagent を（Claude に選ばせず）ターミナルと同様に常にバックグラウンドで実行するよう変更。`claude -p`、Agent SDK、デスクトップアプリ、VS Code での subagent 自身の Agent 呼び出しは、デフォルトでフォアグラウンドで実行される
