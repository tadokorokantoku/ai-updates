- 新しいクラウドのスケジュールタスクに、依頼していないコネクタが付与された場合に `/schedule` で警告を表示し、削除方法を案内するように追加

- 組織のリモート管理設定がセッションに読み込まれていない場合と、その後読み込まれた場合に、Claude Desktop の Code タブで通知を表示するように追加

- Claude apps gateway の admin API にコストレポート `GET /v1/organizations/analytics/cost` を追加。指定した期間の過去の支出を、合計、開発者別、日別、IdP グループ別に取得できる
- `admin:` を設定した Claude apps gateway で、各開発者の IdP グループを日次で記録し、`admin.identity_retention_days` の期間保持するように追加。コストレポートはこれでグループ分けする
- `CLAUDE_CODE_DISABLE_NESTED_SESSION_ID` を追加。セルフホストランナーで `1` に設定すると、セッション内で実行される `claude -p` が以前のバージョンと同様にそのセッションの ID とトランスクリプトを使う

- base URL に設定した LLM gateway がサーバー側の安全性チェックに 403 または 422 を返すと、auto mode が毎ターン失敗する問題を修正（apiKeyHelper 使用時の 403 は従来どおり）
- トークンの更新が遅い場合に `claude auth status` が更新の保存前に終了し、次回実行時にサインアウトされる可能性がある問題を修正

- セッションが多いプロジェクトで、リンクされたセッションが最初のページより古い場合に `claude --from-pr` が "No conversations found" と報告する問題を修正
- 2 つの権限プロンプトが同時に出た場合、2 つ目に claude.ai とモバイルアプリでファイルパスやコマンドが表示されない問題を修正
- Remote Control と SDK ホストが、mod のツール呼び出しに対して「今後確認しない」を提示する問題を修正
- クラウドおよび SDK セッションで、タイトル生成中に新しいメッセージまたは Stop が届くとセッションタイトルが失われる問題を修正

- クラウドセッションの auto mode で、Artifact ツールがアップロード、データベースへの書き込み、outputs フォルダー経由のファイル保存を行うと承認待ちで停止する問題を修正
- claude.ai から同期した skill がディスクに書き込めない場合に、失われたり 10 分ごとに再ダウンロードされたりする問題を修正
- `/schedule` がクラウドのスケジュールタスクを作成または更新した後、結果に次回実行時刻とリンクを含めない問題を修正
- スクリーンリーダーモードで、実行中の subagent の経過時間とトークン数が変化のたびに読み上げられる問題を修正
- リージョンまたはネットワークによるブロック（HTTP 403）がサインイン失敗として表示される問題を修正。エラーでブロックであることを説明するようになった
- クラウドセッションで、同期されたプラグインに同じサーバーが含まれていると、動作中の claude.ai コネクタについて Claude が認可が必要または失敗したと伝える問題を修正
