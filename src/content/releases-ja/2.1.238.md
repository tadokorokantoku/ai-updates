- `keybindingFlavor` 設定を追加: `"readline"` に設定すると、プロンプト中の Ctrl+W が Bash と同様に直前の空白まで削除するようになる（デフォルトの `"classic"` は従来どおり）
- プラグインマーケットプレイス: url マーケットプレイスまたはカタログエントリの `headersHelper` が、カタログおよび同一オリジンのアーカイブ取得用に HTTP ヘッダー（短命トークンなど）を発行するコマンドを実行できるようになった
- カタログエントリの `headersHelper` は、そのプラグインをインストール／更新するときのみ、コマンド内容を表示した上で実行される。`claude plugin install/update` は `[y/N]` で確認する（`-y` 指定も可能）
- `claude self-hosted-runner --defer-shutdown-max-min <minutes>` を追加: SIGTERM を受け取ると、接続中のセッションはそのまま提供を続け、指定した分数後に残りを park してから終了する
- egress プロキシが接続ごとに新規発行の `Proxy-Authorization` ヘッダーを要求する場合向けに、`claude self-hosted-runner --proxy-authorization-command` / `--proxy-authorization-file` を追加
- 長時間の対話セッションでメモリ使用量が際限なく増加していた問題を修正: サブエージェントのツール結果は、最近の表示ウィンドウから外れると解放されるようになった
- カスタム、プロジェクト、プラグインの output style がセッション途中でデフォルトの口調に戻ってしまう問題を修正
- アカウントの使用量上限に近いが超えていない場合に `CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION=true` でもプロンプト候補が無効化されていた問題を修正
- リダイレクトを含まないコマンドに対して、worktree 分離による Bash 拒否メッセージが「リダイレクトを削除してください」と表示していた問題を修正
- self-hosted runner が、1 回の遅延・喪失したポーリングリクエストだけでサーバーから削除され、正常なセッションが別の runner に引き渡されてしまうことがあった問題を修正
- 4,096 文字を超える URL で MCP elicitation ダイアログが何も表示されない問題、およびプロジェクトパスがターミナル幅に収まらない場合に権限プロンプトから「今後確認しない」の選択肢が消えていた問題を修正
- Bash コマンドが kill・タイムアウト・中断されたときに `/tmp/claude-*-cwd` ファイルが残ってしまう問題を修正
- キー入力が大量にまとまって届く環境（低速な SSH/mosh 接続など）で、Backspace の代わりに Ctrl+H を送信するターミナルにおいて、長押しした Backspace が無視される問題を修正
- 権限プロンプトの diff で、絵文字などの幅広いマルチコードポイント文字やタブを含む行が折り返し表示時に切り詰められていた問題を修正
- サスペンド中（Ctrl+Z）のセッションを kill すると、ターミナルが bracketed-paste モードのままカーソルが非表示になることがあった問題を修正
- stdio の MCP サーバーが `initialize` より前に `server/discover` リクエストを受け取ってしまい、遅延起動のサーバーがセッションを開くたびにバックエンドを起動させられていた問題を修正
- プロキシによる接続拒否が、プロキシ名を示さない一般的なネットワークエラーとして報告されていた問題を修正
- プロンプトキャッシュがすでに失効している場合に `/model` や `/effort` のキャッシュミス警告が表示されてしまう問題を修正
- Remote Control のタスクパネルからのタスク単位の Stop が、CLI ホストのセッションで機能しなかった問題を修正
- クライアントが有効な role を持たないユーザーメッセージを送信した場合に、リモートセッションが終了してしまう問題を修正
- `claude remote-control` で開始したリモートセッションが、起動元シェルのセッションスコープの環境変数を継承してしまっていた問題を修正
- プロセスがクラッシュした Remote Control セッションが、`claude remote-control` を再起動するまで利用不可のままになっていた問題を修正。次にメッセージを送った際に再利用できるようになった
- Claude がターン処理中に web や Desktop から送られた Remote Control メッセージが、ターン終了後にトランスクリプトから消えてしまう問題を修正
- スマートフォンや web で行った Remote Control のモデル選択が、ターミナル上の表示モデルに反映されない問題を修正
- サインイン更新が一時的なネットワーク不調で遅延した際に、Remote Control が「login expired」で切断されていた問題を修正。再試行して接続を維持するようになった
- サインアウト時に Remote Control が再接続失敗として報告していた問題を修正。サインアウトすると明確なメッセージとともにセッションが終了するようになった
- `claude remote-control`（サーバーモード）や Desktop/IDE ホストで実行しているセッションで `ListAgents`/`SendMessage` が「Remote Control is not connected」と報告していた問題を修正。Remote Control のピアを一覧・到達できるようになった
- `ListAgents` と `SendMessage` が、次のバックグラウンドセッション用にエージェントビューが事前に用意しているアイドルワーカーを露出させていた問題を修正。タスクが確保されるまで表示されないようになった
- クロスセッションメッセージング: このマシン上で受信メッセージを拒否している（例: `crossSessionInbound: "refuse"`）セッションへの送信が、サイレントな成功ではなく送信元に「refused」を報告するようになった
- クロスセッションメッセージング: 受信箱でメッセージが破棄される（レート制限またはキュー満杯）セッションへの送信が、メッセージが黙って消える代わりに送信元に通知するようになった
- 起動を改善: macOS で `claude` 単体起動が高速化
- zsh 固有のシェル条件文構文に対する Bash ツールの権限チェックを改善
- Remote Control の接続耐性を改善: ネットワークエッジ、VPN、プロキシからの一時的な HTTP 403 拒否を最大 3 分間許容し、拒否が継続する場合は拒否元を明示するようになった
- 起動時のレスポンス性を改善: 自動アップデートチェックが起動処理と CPU を奪い合う代わりに、起動の約 10 秒後に実行されるようになった
- Managed Agents 8 月 19 日リリース向けにバンドルされた `claude-api` スキルを更新: web 検索／取得のドメイン設定と、self-hosted サンドボックスでのメモリストア
- フルスクリーンでの Ctrl+L と Cmd+K を常に再描画のみに変更 — ダブルプレスによる `/clear` ショートカットは削除され、1 行の nvim ターミナルで自動的に `/clear` ループが発生しなくなった
- `claude mcp list` と `claude mcp get` が、無効化されたサーバーに対してヘルスチェック接続を行う代わりに `⊘ Disabled` と表示するように変更
- プロジェクトの `.mcp.json` にある MCP の `headersHelper`、およびプロジェクトや `--add-dir` エージェントファイル内のインライン MCP サーバーは、そのフォルダの信頼ダイアログが承認済みであることを必要とするようになった（`claude -p` でも同様）
- プロジェクトの `.mcp.json`、プラグイン、エージェントファイルからの MCP `headersHelper` は継承された認証情報の環境変数なしで実行される。user・managed・claude.ai スコープの helper は Claude の設定ディレクトリから実行される
