- 任意の `CLAUDE_CODE_PROJECT_DIR_NAME` 環境変数を追加: セッションごとに独自の設定ディレクトリを持たせるホストで、プロジェクトごとのトランスクリプトディレクトリに短い名前を指定できるようになった
- `selection:clear` キーバインドアクションを追加。キーにバインドしてアプリ内のテキスト選択をクリアできる。agents ビューでも動作する
- フッターとステータスラインに GitLab merge request バッジを追加: GitLab リモートと認証済みの `glab` CLI があるリポジトリでは、draft/pending/green の状態とともに MR `!N` が表示される
- claude.ai の使用量上限がリセットされた際、Claude Code がセッションを自動的に継続するようになった。`/config` の「Continue automatically at usage limit」で無効化できる
- Claude はアカウントのメールアドレスをユーザー識別のためだけに使用し、依頼がない限り無関係なサービスに送信しないよう指示されるようになった
- セキュリティ: リモートファイル読み取り、セッション復元、CLAUDE.md のインクルード、workflow スクリプト、ファイルアップロードが Windows の NT 名前空間（`\??\`）パスを拒否するようになり、承認前のファイルアクセスに残っていた NTLM 認証情報漏洩の経路が塞がれた
- 非常に長いセッションにおいて、会話がコンパクション済みの状態で auto mode がサンドボックス化コマンドのネットワークアクセスを繰り返しチェックして拒否していた問題を修正
- バックグラウンドサブエージェントのツール権限プロンプトに応答する際、セッションスコープの権限応答（拒否を含む）が失われていた問題を修正
- 非ストリーミングのフォールバックパス（主にサードパーティ gateway 経由）での API レスポンスに、thinking フィールドを欠いた thinking ブロックや text フィールドを欠いた text ブロックが含まれていた場合のクラッシュを修正
- 一部の特殊な Unicode シーケンスを含むメッセージで markdown のレンダリングが極端に遅くなっていた問題を修正
- セッション名が 200 文字上限に達しているか絵文字が多い場合に、`ListAgents` からコピーした宛先を `SendMessage` が拒否していた問題を修正
- 通常とは異なる userinfo を持つ git リモートのホストをリポジトリ検出が誤って読み取り、誤ったホスト向けのリンクやリポジトリ固有の動作を生成していた問題を修正
- MCP 診断が解決済みのシークレットを表示していた問題を修正: スコープ競合の警告は設定された `${VAR}` 形式を表示するようになり、接続失敗の詳細はサーバーのオリジンのみを表示するようになった
- `strictKnownMarketplaces` の許可リストが、git が実際に接続するホストと異なるホストを持つ SCP 形式の git marketplace ソースを受け入れてしまっていた問題を修正
- フルスクリーンでコピーした際に `/login` の OAuth URL などのモーダルテキストの文字が欠落していた問題を修正
- レンダリングされた markdown で `---` の水平線が次の行に食い込んでいた問題を修正
- todo/task の更新が間に挟まった場合、連続するシェルコマンドが複数の「Ran 1 shell command」行に分割されていた問題を修正
- `!` シェルコマンドの実行中に開いた `/permissions` などのダイアログが、コマンド終了時に閉じられてしまっていた問題を修正
- キューに入れられた `!` シェルコマンドを上矢印キューで編集しようとすると、プレーンテキストとしてモデルに送信されてしまっていた問題を修正
- キューに入れられたメッセージがキューに残ったままプロンプト履歴に再表示される問題、キューに入れられたメッセージを選択中の Esc がターンを中断してしまう問題、ターンの途中で送信した後も `!` モードが残り続ける問題を修正
- 「Try the new fullscreen renderer?」プロンプトを承諾すると、権限モード（`--dangerously-skip-permissions` など）、ツールの allow/deny ルール、モデルや effort フラグを引き継がずにセッションが再起動してしまっていた問題を修正
- `/tui` が再起動時に起動時の `--allowed-tools`/`--disallowed-tools` ルールを失っていた問題を修正。再起動では引き継げない制限がセッションにある場合、理由とともに切り替えを拒否するようになった
- リポジトリが存在するようになる前にディレクトリが初めて検出された場合、trust プロンプトがリポジトリ全体のスコープ警告を省略していた問題を修正
- 権限の再プロンプト中に IDE の diff タブが閉じられた際、新しいプロンプトに前回の入力で応答してしまうことがあった問題を修正
- 修正: Claude Code Desktop や VS Code がホストする Remote Control セッション中にユーザーへ送られたファイルがアップロードされるようになり、空のカードが表示される代わりにスマートフォンや web で開けるようになった
- 修正: `CLAUDE_CODE_OAUTH_TOKEN` 設定時に `/login` した後、古いトークンに関するリマインダーが Claude の自動再開ターンに漏れなくなり、ユーザーにのみ表示されるようになった
- 修正: 権限プレビューが、受信側の trust ゲートで許可されたチャンネルサーバーにのみ中継されるようになり、サーバーが明示的に指定した権限機能のオプトアウトが尊重されるようになった
- 修正: 中継された権限プレビューでの認証情報マスキングが、コマンド・パス・宛先を承認者から隠せなくなり、サイズの大きい秘密鍵ブロックはフル強度のマスキングで redact されるようになった
- 修正: 権限プレビューでマスクされるプロバイダーの API トークンが、直後にシェルの区切り文字が続く場合でもマスクされるようになった
- クロスセッションメッセージングが無効と判定された場合に、Claude Desktop のセッション間メッセージが受信側セッションで黙って破棄され、送信側のクエリが数十分「thinking」のままになっていた問題を修正
- Remote Control: このコンピューターを別の claude.ai アカウントまたは組織にサインインさせた場合、数時間後に紛らわしい HTTP 404 を出す代わりに、数秒以内に実行中のセッションを停止し理由を表示するようになった
- Claude Code Desktop または VS Code から開始した Remote Control セッションが、権限モード（および claude.ai/code ではモードも）の変化に応じてスマートフォンや claude.ai/code を最新の状態に保つようになった
- Remote Control: スマートフォンまたは claude.ai/code で行われた effort の選択が、ターミナルおよび Desktop/VS Code ホストのセッションにも適用されるようになり、セッションが接続中のクライアントに effort レベルを公開するようになった
- `SendMessage` と `ListAgents` は、アカウントのセッション一覧が長すぎて完全にチェックできなかった場合、未確認のセッションを存在しないものとして扱う代わりにその旨を伝えるようになった
- claude.ai のログインが優先されるべき場合、期限切れの Anthropic プロファイル認証情報から `/login` へ誘導されるようになった
- トランスクリプトを改善: 自分のプロンプトが、返信と同様にハイライトされたコードブロック・インラインコード・リストを含む markdown としてレンダリングされるようになった
- 「API returned an empty or malformed response」エラーを改善し、実際に返ってきた内容（コンテンツタイプ、ボディの種類、サイズ、リクエスト ID）と元のストリーミングリクエストが失敗した理由を表示するようになった
- 自動生成されるセッションタイトルを改善し、依頼内容を言い換えた文（例: "Fix the login button on mobile"）ではなく、短く具体的な名前（例: "Login button bug"）になるようにした
- 組み込みの `claude-api` スキルを読み込む際のコンテキストコストを、参照ドキュメントをオンデマンドで読み込むことで ~200k トークン以上から ~25k トークンに削減
- Claude が作業中でも `/permissions` を開けるようになった。ルールの変更は現在のターンの残りに適用される
- Claude が作業中でも `/add-dir <path>` を使えるようになった。フルスクリーン TUI では `/add-dir`、`/autocompact`、`/theme`、`/help`、`/config`、`/advisor` のダイアログがターンの途中でも開くようになった
- `/goal` は、ターンが復旧不能なエラー（認証の失効、クレジット残高の枯渇、コンテキストオーバーフローなど）で終了した際、armed のままにせず通知とともに自らクリアされるようになった
- `/goal`: バックグラウンドタスクにより goal が 30 分以上待機状態になった場合、Claude が無期限に待つ代わりにタスクの状況を確認するようになった（`CLAUDE_CODE_GOAL_CHECKIN_MINUTES=0` でオプトアウト可能）
- `claude setup-token` が、予期しない追加の引数を黙って無視する代わりに拒否するようになった
- フルスクリーンモードでの Esc の挙動を変更し、マウスのテキスト選択をクリアしなくなった: 通常どおり中断または閉じる動作を行い、選択状態はハイライトされたまま残る
- auto mode が Agent ツール呼び出しごとに表示していた冗長な「Allowed by auto mode classifier」の行を削除
- `/config` から「Default teammate model」設定を削除。agent-team のチームメイトは、spawn 時に指定がない限りリーダーのモデルを使用するようになった
- 実行中ツールヘッダーの経過時間カウンターを暗くし、太字のカウントと視覚的に競合しないようにした
- ターンの合間に配信されるバックグラウンドタスク通知が、ターン中の配信と同様に `<system-reminder>` タグ内でモデルに送信されるようになった
- Mantle: メインループのモデルが既に選択されている場合、起動時の admin-pin 可用性チェックをスキップするようにした
- Windows: `~/.claude.json` が読み取り専用の場合に、起動時にリネームの再試行を繰り返してスタックしなくなった
